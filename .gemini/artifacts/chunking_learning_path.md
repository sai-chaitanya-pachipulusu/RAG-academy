## Path Options for Users

### Path 1: Core Fundamentals → Production

```
fixed-size → overlapping → sentence → paragraph → recursive → section → semantic → agentic
```

### Path 2: Quick to Semantic (for those who want AI-powered quickly)

```
fixed-size → overlapping → sentence → semantic
```

### Path 3: Structure-First

```
fixed-size → overlapping → paragraph → recursive → section → hierarchical
```

### Path 4: Domain-Specific (Legal/Financial)

```
fixed-size → ... → section-based → legal-clause-chunking
fixed-size → ... → section-based → table-aware → financial-statement-chunking
```
