## Core idea

### What is RAG-Fusion?

RAG-Fusion combines two powerful ideas:
1. **Multi-query generation**: Generate query variations to improve recall.
2. **Reciprocal Rank Fusion**: Merge results from all queries.

```
Original Query
      ↓
Generate N Query Variations
      ↓
[Query 1] [Query 2] [Query 3] [Query N]
    ↓         ↓         ↓         ↓
Retrieve   Retrieve   Retrieve   Retrieve
    ↓         ↓         ↓         ↓
    └─────────┴─────────┴─────────┘
                   ↓
            RRF Fusion
                   ↓
           Final Results
```

### RAG-Fusion implementation

```python
class RAGFusion:
    def __init__(
        self,
        retriever,
        generator,
        num_queries: int = 4,
        fusion_k: int = 60,
    ):
        self.retriever = retriever
        self.generator = generator
        self.num_queries = num_queries
        self.fusion_k = fusion_k
    
    def retrieve(self, query: str, top_k: int = 10) -> List[Dict]:
        """
        RAG-Fusion retrieval.
        """
        # Step 1: Generate query variations
        queries = self.generate_queries(query)
        
        # Step 2: Retrieve for each query
        all_results = []
        for q in queries:
            results = self.retriever.retrieve(q, k=50)
            all_results.append(results)
        
        # Step 3: Fuse with RRF
        fused = self.rrf_fusion(all_results)
        
        return fused[:top_k]
    
    def generate_queries(self, query: str) -> List[str]:
        """
        Generate query variations using LLM.
        """
        prompt = f"""Generate {self.num_queries - 1} different versions of this search query.
Each version should:
- Preserve the original intent
- Use different words or phrasings
- Potentially explore different aspects of the question

Original query: {query}

Variations (one per line):
1."""
        
        response = self.generator.generate(prompt)
        variations = [line.strip() for line in response.split('\n') if line.strip()]
        
        # Include original + variations
        return [query] + variations[:self.num_queries - 1]
    
    def rrf_fusion(self, result_lists: List[List[Dict]]) -> List[Dict]:
        """
        Reciprocal Rank Fusion across all result lists.
        """
        scores = defaultdict(float)
        doc_lookup = {}
        
        for results in result_lists:
            for rank, doc in enumerate(results, start=1):
                doc_id = doc["id"]
                scores[doc_id] += 1.0 / (self.fusion_k + rank)
                doc_lookup[doc_id] = doc
        
        # Sort by fused score
        sorted_ids = sorted(scores.keys(), key=lambda x: scores[x], reverse=True)
        
        return [doc_lookup[doc_id] for doc_id in sorted_ids]
```

### Multi-source retrieval

Retrieve from multiple heterogeneous sources:

```python
class MultiSourceRetriever:
    def __init__(self, sources: Dict[str, Retriever]):
        self.sources = sources
    
    def retrieve(
        self,
        query: str,
        top_k: int = 10,
        source_weights: Dict[str, float] = None,
    ) -> List[Dict]:
        """
        Retrieve from multiple sources and merge.
        """
        source_weights = source_weights or {s: 1.0 for s in self.sources}
        
        # Retrieve from each source
        all_results = []
        for source_name, retriever in self.sources.items():
            results = retriever.retrieve(query, k=50)
            
            # Add source metadata
            for doc in results:
                doc["source"] = source_name
            
            all_results.append((results, source_weights.get(source_name, 1.0)))
        
        # Weighted fusion
        return self.weighted_rrf_fusion(all_results, top_k)
    
    def weighted_rrf_fusion(
        self,
        weighted_results: List[Tuple[List[Dict], float]],
        top_k: int,
        k: int = 60,
    ) -> List[Dict]:
        """
        RRF fusion with source weights.
        """
        scores = defaultdict(float)
        doc_lookup = {}
        
        for results, weight in weighted_results:
            for rank, doc in enumerate(results, start=1):
                doc_id = doc["id"]
                scores[doc_id] += weight * (1.0 / (k + rank))
                doc_lookup[doc_id] = doc
        
        sorted_ids = sorted(scores.keys(), key=lambda x: scores[x], reverse=True)
        return [doc_lookup[doc_id] for doc_id in sorted_ids[:top_k]]

        "code_search": 0.8,
        "slack_history": 0.5,  # Lower weight for chat
    }
)
```

### Source-aware context building

```python
def build_context_with_sources(docs: List[Dict], max_tokens: int = 4000) -> str:
    """
    Build context with source attribution.
    """
    context_parts = []
    current_tokens = 0
    
    for doc in docs:
        source = doc.get("source", "unknown")
        text = doc["text"]
        
        # Format with source
        formatted = f"[Source: {source}]\n{text}\n"
        tokens = count_tokens(formatted)
        
        if current_tokens + tokens > max_tokens:
            break
        
        context_parts.append(formatted)
        current_tokens += tokens
    
    return "\n---\n".join(context_parts)
```

### When to use fusion

| Scenario | Use Fusion? | Why |
|----------|-------------|-----|
| Short/ambiguous queries | ✓ Yes | Query variations improve recall |
| Multiple data sources | ✓ Yes | Need to search across sources |
| Specific factual queries | ~ Maybe | May add noise |
| High-volume, latency-critical | ✗ No | Multiple retrievals = more latency |

## Failure modes

1. **Query variation noise**: Bad variations hurt results.
2. **Over-fusion**: Too many sources dilute relevance.
3. **Weight tuning**: Wrong weights harm quality.
4. **Latency multiplication**: N queries = N× retrieval time.

## Production defaults

- **Query variations**: 3-4 (including original).
- **RRF k**: 60 (standard).
- **Source weights**: Start equal, tune with evaluation data.
- **Parallel retrieval**: Run queries in parallel to reduce latency.

```python
# Production: parallel RAG-Fusion
import asyncio

async def parallel_rag_fusion(query: str, retriever, num_queries: int = 4) -> List[Dict]:
    queries = generate_queries(query, num_queries)
    
    # Parallel retrieval
    tasks = [retriever.retrieve_async(q, k=50) for q in queries]
    all_results = await asyncio.gather(*tasks)
    
    return rrf_fusion(all_results)
```
