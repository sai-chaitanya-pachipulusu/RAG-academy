## Core idea

Evaluating RAG systems requires measuring **retrieval quality**, **generation quality**, and their **interaction**. Traditional metrics (BLEU, ROUGE) fail to capture what matters for RAG. Modern evaluation uses LLM-as-judge and specialized RAG metrics.

## The evaluation hierarchy

```
┌────────────────────────────────────────────────────────────┐
│                    SYSTEM LEVEL                            │
│  User satisfaction, task completion, business metrics      │
├────────────────────────────────────────────────────────────┤
│                   COMPONENT LEVEL                          │
│  ┌──────────────┐ ┌──────────────┐ ┌──────────────┐      │
│  │  Retrieval   │ │  Generation  │ │  End-to-End  │      │
│  │  - Recall@K  │ │  - Faithful  │ │  - Correct   │      │
│  │  - MRR       │ │  - Relevant  │ │  - Complete  │      │
│  │  - nDCG      │ │  - Coherent  │ │  - Useful    │      │
│  └──────────────┘ └──────────────┘ └──────────────┘      │
├────────────────────────────────────────────────────────────┤
│                    UNIT LEVEL                              │
│  Chunking quality, embedding similarity, latency           │
└────────────────────────────────────────────────────────────┘
```

## Failure modes

- **Retrieval-generation disconnect**: Great retrieval but poor generation (or vice versa)
- **Golden set bias**: Evaluating only on easy, well-defined questions
- **LLM judge bias**: Judge model favors verbose or confident-sounding answers
- **Metric gaming**: Optimizing for metrics that don't reflect user value

```python
def evaluate_rag_response(query, retrieved_contexts, generated_answer, ground_truth):
    """
    Comprehensive RAG evaluation using RAGAS metrics.

    Returns dict with scores from 0-1 for each metric.
    """
    return {
        # Retrieval metrics
        "context_precision": context_precision(
            question=query,
            contexts=retrieved_contexts,
            ground_truth=ground_truth
        ),
        "context_recall": context_recall(
            question=query,
            contexts=retrieved_contexts,
            ground_truth=ground_truth
        ),

        # Generation metrics
        "faithfulness": faithfulness(
            question=query,
            contexts=retrieved_contexts,
            answer=generated_answer
        ),
        "answer_relevancy": answer_relevancy(
            question=query,
            answer=generated_answer
        ),
    }
```

### Metric definitions

| Metric                | Measures                             | Formula                                          |
| --------------------- | ------------------------------------ | ------------------------------------------------ |
| **Context Precision** | Retrieved chunks relevance to answer | (relevant chunks) / (total retrieved)            |
| **Context Recall**    | Coverage of ground truth             | (GT sentences in context) / (total GT sentences) |
| **Faithfulness**      | Answer grounded in context           | (supported claims) / (total claims)              |
| **Answer Relevancy**  | Answer addresses the question        | Semantic similarity(answer, question)            |

### ARES: Automated RAG Evaluation System

[ARES](https://arxiv.org/abs/2311.09476) from Stanford/UC Berkeley provides automated evaluation with statistical guarantees:

**Three-Stage Pipeline:**

1. **Synthetic Dataset Generation**: Use LLMs to create question-answer pairs from your corpus
2. **LLM Judge Training**: Fine-tune lightweight models for context relevance, faithfulness, and relevancy
3. **Prediction-Powered Inference (PPI)**: Use small human-annotated set to provide confidence intervals

```python
class ARESEvaluator:
    """
    ARES-style evaluation with confidence intervals.
    """
    def __init__(self, judge_models, human_validation_set):
        self.judges = judge_models  # Fine-tuned classifiers
        self.validation_set = human_validation_set  # 50-200 examples

    def evaluate_with_confidence(self, rag_outputs: List[Dict]) -> Dict:
        """
        Evaluate RAG outputs with PPI confidence intervals.

        Returns metrics with 95% confidence bounds.
        """
        # Score all outputs with LLM judges
        judge_scores = {
            "context_relevance": [self.judges["relevance"].score(o) for o in rag_outputs],
            "faithfulness": [self.judges["faithful"].score(o) for o in rag_outputs],
            "answer_relevance": [self.judges["answer_rel"].score(o) for o in rag_outputs],
        }

        # Apply PPI rectifier using human validation set
        for metric, scores in judge_scores.items():
            human_labels = [v[metric] for v in self.validation_set]
            judge_on_validation = [self.judges[metric.split("_")[0]].score(v) for v in self.validation_set]

            # Calculate rectifier (difference between judge and human)
            rectifier = np.mean(human_labels) - np.mean(judge_on_validation)

            # Apply to full dataset
            corrected_mean = np.mean(scores) + rectifier

            # Confidence interval via PPI
            se = self._ppi_standard_error(scores, human_labels, judge_on_validation)

            judge_scores[metric] = {
                "mean": corrected_mean,
                "ci_lower": corrected_mean - 1.96 * se,
                "ci_upper": corrected_mean + 1.96 * se,
            }

        return judge_scores
```

**Key Advantage**: ARES requires only 50-200 human-annotated examples to provide reliable confidence intervals for thousands of RAG outputs, making it practical for production evaluation.

### LLM-as-Judge implementation

```python
from openai import OpenAI

def llm_judge_faithfulness(context: str, answer: str) -> dict:
    """
    Use LLM to judge if answer is faithful to context.
    Returns score and reasoning.
    """
    client = OpenAI()

    prompt = f"""You are evaluating whether an answer is faithful to the given context.

Context:
{context}

Answer:
{answer}

Evaluate faithfulness on a scale of 1-5:
1: Answer contradicts or ignores the context
2: Answer mostly unsupported by context
3: Answer partially supported by context
4: Answer mostly supported by context
5: Answer fully grounded in context

Respond in JSON format:
{{"score": <1-5>, "reasoning": "<explanation>", "unsupported_claims": [<list of claims not in context>]}}
"""

    response = client.chat.completions.create(
        model="gpt-4-turbo",
        messages=[{"role": "user", "content": prompt}],
        response_format={"type": "json_object"},
    )

    return json.loads(response.choices[0].message.content)


def llm_judge_relevancy(question: str, answer: str) -> dict:
    """
    Use LLM to judge if answer is relevant to question.
    """
    client = OpenAI()

    prompt = f"""You are evaluating whether an answer is relevant to the question.

Question: {question}

Answer: {answer}

Evaluate relevancy on a scale of 1-5:
1: Answer doesn't address the question at all
2: Answer tangentially related but misses the point
3: Answer partially addresses the question
4: Answer mostly addresses the question
5: Answer fully and directly addresses the question

Respond in JSON format:
{{"score": <1-5>, "reasoning": "<explanation>", "missing_aspects": [<what the answer should have covered>]}}
"""

    response = client.chat.completions.create(
        model="gpt-4-turbo",
        messages=[{"role": "user", "content": prompt}],
        response_format={"type": "json_object"},
    )

    return json.loads(response.choices[0].message.content)
```

```python
def robust_llm_judge(question, answer, context):
    """
    Multiple strategies to reduce LLM judge bias.
    """
    # Strategy 1: Multiple judges
    judges = ["gpt-4", "claude-3-opus", "gemini-pro"]
```

### Continuous evaluation pipeline

```python
class RAGEvaluationPipeline:
    def __init__(self, rag_system, eval_dataset):
        self.rag = rag_system
        self.dataset = eval_dataset
        self.metrics_history = []

    def run_evaluation(self):
        """Run full evaluation suite."""
        results = []

        for example in self.dataset:
            # Get RAG response
            response = self.rag.query(example["question"])

            # Evaluate
            metrics = {
                "retrieval": self.eval_retrieval(
                    response["contexts"],
                    example["relevant_contexts"]
                ),
                "generation": self.eval_generation(
                    response["answer"],
                    response["contexts"],
                    example["ground_truth"]
                ),
                "end_to_end": self.eval_e2e(
                    response["answer"],
                    example["ground_truth"]
                ),
            }
            results.append(metrics)

        # Aggregate
        aggregated = self.aggregate_metrics(results)
        self.metrics_history.append({
            "timestamp": datetime.now(),
            "metrics": aggregated,
        })

        # Alert on regression
        self.check_regressions(aggregated)

        return aggregated

    def check_regressions(self, current_metrics):
        """Alert if metrics drop below thresholds."""
        thresholds = {
            "retrieval.recall@10": 0.8,
            "generation.faithfulness": 0.85,
            "end_to_end.correctness": 0.75,
        }

        for metric, threshold in thresholds.items():
            value = get_nested(current_metrics, metric)
            if value < threshold:
                alert(f"REGRESSION: {metric} = {value} < {threshold}")
```

```python
def create_golden_set(raw_queries, num_samples=100):
    """
    Create a golden evaluation set with human-verified ground truth.
    """
    golden_set = []

    for query in sample(raw_queries, num_samples):
        # Get expert annotation
```
