## Cost Components

```
Total RAG Cost = Embedding + Storage + Retrieval + Generation + Infrastructure
```

| Component        | % of Total | Optimization Lever           |
| ---------------- | ---------- | ---------------------------- |
| Generation (LLM) | 60-80%     | Context length, model choice |

| Storage          | 5-10%      | Quantization, pruning        |
| Retrieval        | 2-5%       | Approximation, caching       |
| Infrastructure   | 5-10%      | Serverless, scaling          |

### Formula

```python
def calculate_embedding_cost(
    num_documents: int,
    avg_tokens_per_doc: int,
    price_per_million: float
) -> float:
    """Calculate embedding cost."""
    total_tokens = num_documents * avg_tokens_per_doc
    return (total_tokens / 1_000_000) * price_per_million

# Example: 100K documents, 500 tokens each, text-embedding-3-small
cost = calculate_embedding_cost(100_000, 500, 0.02)
# = $1.00 to embed 100K documents!
```

### RAG Generation Formula

```python
def calculate_generation_cost(
    num_queries: int,
    avg_context_tokens: int,  # Retrieved chunks
    avg_query_tokens: int,
    avg_output_tokens: int,
    input_price_per_k: float,
    output_price_per_k: float
) -> float:
    """Calculate total generation cost."""
    input_tokens = num_queries * (avg_context_tokens + avg_query_tokens)
    output_tokens = num_queries * avg_output_tokens

    input_cost = (input_tokens / 1000) * input_price_per_k
    output_cost = (output_tokens / 1000) * output_price_per_k

    return input_cost + output_cost

# Example: 10K queries, 800 context tokens, 50 query tokens, 200 output
# Using GPT-4o
cost = calculate_generation_cost(10_000, 800, 50, 200, 0.005, 0.015)
# = $42.50 + $30.00 = $72.50
```

### 2. Caching (80%+ savings on repeated queries)

```python
cache = {}
def cached_rag(query):
    key = hash(query)
    if key in cache:
        return cache[key]  # No LLM cost!
    result = rag_pipeline(query)
    cache[key] = result
    return result
```

## ROI Calculator

```python
def calculate_rag_roi(
    manual_query_cost: float,  # Cost of human answering
    rag_cost_per_query: float,
    queries_per_month: int,
    accuracy_rate: float  # % of queries RAG handles correctly
) -> dict:
    """Calculate ROI of RAG implementation."""

    manual_total = manual_query_cost * queries_per_month
    rag_total = rag_cost_per_query * queries_per_month

    # Queries still needing human = (1 - accuracy) * queries
    human_escalation = (1 - accuracy_rate) * queries_per_month * manual_query_cost

    total_with_rag = rag_total + human_escalation
    savings = manual_total - total_with_rag
    roi = (savings / rag_total) * 100

    return {
        "monthly_savings": savings,
        "roi_percent": roi,
        "break_even_queries": rag_total / (manual_query_cost - rag_cost_per_query)
    }

# Example: $5/query manual, $0.05/query RAG, 10K queries, 90% accuracy
roi = calculate_rag_roi(5.0, 0.05, 10_000, 0.90)
# Monthly savings: ~$44,500, ROI: ~8,900%
```
