| Format           | Library             | Complexity  | Notes                      |
| ---------------- | ------------------- | ----------- | -------------------------- |
| **PDF**          | PyMuPDF, pdfplumber | Medium-High | Tables, images, OCR needed |

## PDF Parsing Strategies

### Strategy 1: Text-based PDFs

```python
import pymupdf  # PyMuPDF

def extract_text_pdf(path: str) -> str:
    doc = pymupdf.open(path)
    text = ""
    for page in doc:
        text += page.get_text()
    return text
```

### Strategy 2: Scanned PDFs (OCR)

```python
import pytesseract
from pdf2image import convert_from_path

def ocr_pdf(path: str) -> str:
    images = convert_from_path(path)
    text = ""
    for img in images:
        text += pytesseract.image_to_string(img)
    return text
```

### Strategy 3: Table Extraction

```python
import pdfplumber

def extract_tables(path: str):
    with pdfplumber.open(path) as pdf:
        tables = []
        for page in pdf.pages:
            for table in page.extract_tables():
                tables.append(table)
    return tables
```

## Table Extraction Best Practices

### Decision Tree

```
Is the PDF text-based?
├── YES → Use pdfplumber or camelot
└── NO (scanned)
    └── Use Document AI or unstructured

Is the table simple (no merged cells)?
├── YES → Row-based chunking works
└── NO → Flatten to JSON or markdown
```

### Chunking Strategies for Tables

| Strategy       | When to Use            | Example                               |
| -------------- | ---------------------- | ------------------------------------- |
| **Row-based**  | Simple data tables     | Each row → chunk with headers         |
| **Cell-based** | Wide tables            | "Revenue Q1: $1M" as individual facts |
| **Full table** | Small reference tables | Keep table intact as one chunk        |
| **JSON**       | Structured queries     | Convert to searchable objects         |

## Production Tips

### Quality Checklist

- [ ] Test with real documents (not just samples)
- [ ] Handle encoding issues (UTF-8, Latin-1)
- [ ] Check for password-protected files
- [ ] Validate table extraction accuracy
- [ ] Monitor OCR confidence scores

### Common Pitfalls

| Issue           | Solution                            |
| --------------- | ----------------------------------- |
| Garbled text    | Try different PDF libraries         |
| Missing tables  | Use vision-based extraction         |
| Bad OCR         | Increase DPI, preprocess images     |
| Lost formatting | Extract to HTML first, then convert |
