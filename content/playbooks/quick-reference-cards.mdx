## Similarity Metrics

| Metric      | Formula              | When to Use            |
| ----------- | -------------------- | ---------------------- |
| Cosine      | dot(a,b) / (‖a‖·‖b‖) | Normalized embeddings  |
| Dot Product | Σ(aᵢ·bᵢ)             | Pre-normalized vectors |
| Euclidean   | √Σ(aᵢ-bᵢ)²           | Clustering, spatial    |

```python
# Cosine similarity
def cosine_similarity(a, b):
    dot = sum(x*y for x,y in zip(a,b))
    norm_a = sum(x*x for x in a) ** 0.5
    norm_b = sum(x*x for x in b) ** 0.5
    return dot / (norm_a * norm_b)
```

## Retrieval Patterns

### Basic Retrieval

```python
docs = retriever.search(query, k=5)
```

### Hybrid (Dense + Sparse)

```python
dense_results = dense_retriever.search(query, k=10)
sparse_results = bm25.search(query, k=10)
merged = reciprocal_rank_fusion(dense_results, sparse_results)
```

### Multi-Query

```python
queries = [original, rephrased_1, rephrased_2]
all_docs = []
for q in queries:
    all_docs.extend(retriever.search(q, k=3))
unique_docs = deduplicate(all_docs)
```

## Key Metrics

| Metric            | What it Measures               | Target |
| ----------------- | ------------------------------ | ------ |
| Recall@k          | % of relevant docs in top-k    | >80%   |
| MRR               | Rank of first relevant doc     | >0.7   |
| Faithfulness      | Response grounded in context   | >90%   |
| Context Precision | Relevant docs / Retrieved docs | >70%   |
| Latency (P95)     | Response time                  | <2s    |

## Performance Tips

```python
# 1. Batch embeddings
vectors = embed_batch(texts)  # Not one-by-one

# 2. Async retrieval
results = await asyncio.gather(
    retriever.search(query1),
    retriever.search(query2),
)

# 3. Cache frequent queries
@lru_cache(maxsize=1000)
def cached_search(query_hash):
    return retriever.search(query)

# 4. Pre-filter before vector search
docs = retriever.search(
    query,
    filter={"category": "support"}
)
```

## Common Errors

| Error          | Cause          | Fix                       |
| -------------- | -------------- | ------------------------- |
| Empty results  | Bad embeddings | Check embedding model     |
| Wrong answers  | Poor chunking  | Adjust chunk size/overlap |
| Hallucinations | Weak prompt    | Add "only use context"    |
| Slow queries   | No index       | Add ANN index             |
| High cost      | No caching     | Add semantic cache        |
