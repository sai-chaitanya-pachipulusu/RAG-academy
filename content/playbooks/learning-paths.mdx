# RAG Learning Paths

Choose your learning path based on your goals and experience level.

---

## Path 1: Beginner to Practitioner (2-3 weeks)

Perfect for developers new to RAG who want to build their first working system.

### Week 1: Foundations & Data Layer

```
📚 Foundation Challenges (Complete in order):
   1. dot-product → 2. cosine-similarity → 3. euclidean-distance
   4. dense-vector-class → 5. vector-normalization

📄 Data Layer Challenges:
   1. simple-chunking → 2. overlap-chunking → 3. metadata-tagging
   4. stable-chunk-ids → 5. sentence-chunking
```

### Week 2: Retrieval & Reranking

```
🔍 Retrieval Challenges:
   1. basic-retrieval → 2. embed-and-search → 3. bm25-from-scratch
   4. similarity-threshold → 5. rrf-fusion

📊 Reranking Challenges:
   1. rerank-cascade → 2. mmr-diversity → 3. exact-dedup
```

### Week 3: End-to-End Pipeline

```
🔗 Pipeline Challenges:
   1. prompt-template → 2. citation-range-validator
   3. refusal-policy → 4. rag-pipeline-generator

📖 Playbooks to Read:
   - Chunking Strategies Deep Dive
   - Embedding Selection Guide
```

**Outcome:** You can build a complete RAG pipeline from scratch.
