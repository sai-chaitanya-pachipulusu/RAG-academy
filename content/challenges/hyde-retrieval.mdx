# HyDE: Hypothetical Document Embeddings

**Hypothetical Document Embeddings (HyDE)** from [Gao et al., 2022](https://arxiv.org/abs/2212.10496) improves zero-shot dense retrieval by generating a hypothetical document that would answer the query, then using that document's embedding for retrieval.

## The Problem

Dense retrievers embed queries and documents into the same vector space. But queries are short questions while documents are long statements - this creates a vocabulary and style mismatch.

```
Query: "What causes inflation?"
→ Embedding focuses on question words

Document: "Inflation occurs when the general price level rises due to..."
→ Embedding focuses on statement/explanation words
```

## The Solution: HyDE

Instead of embedding the question directly:

1. Generate a **hypothetical document** that would answer the question
2. Embed that hypothetical document
3. Search for **similar real documents**

The hypothetical document, even if factually imperfect, captures the form and vocabulary of relevant real documents.

## Hints

<details>
<summary>Hint 1: Prompt Design</summary>

The prompt should instruct the LLM to:

- Write as an authoritative source
- Not mention the question itself
- Provide informational text directly

Example structure:

```
"Write a passage that answers: {query}
Write as if from an encyclopedia or textbook.
Do not say 'the answer is' - just provide the information."
```

def retrieve(self, query, k=5):
    hypothetical = self.generate_hypothetical_document(query)
    embedding = self.embedder.embed(hypothetical)
    return self.vector_store.search_by_vector(embedding, k)

## Extensions

1. **Multi-HyDE**: Generate multiple hypotheticals and fuse results with RRF
2. **Hybrid HyDE**: Combine HyDE retrieval with direct query retrieval
3. **Quality filter**: Detect when HyDE generates poor hypotheticals and fall back

## Why This Works

The hypothetical document acts as a "translation" from question-space to document-space. Even if the generated facts are wrong, the vocabulary and sentence structure match real documents better than the original question.

| Method | Query Embedding             | Document Match               |
| ------ | --------------------------- | ---------------------------- |
| Direct | "What causes inflation?"    | Mismatch with document style |
| HyDE   | "Inflation is caused by..." | Matches document vocabulary  |
