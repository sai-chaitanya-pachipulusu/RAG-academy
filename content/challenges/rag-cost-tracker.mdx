# RAG Cost Tracker

Build a cost tracking system for RAG API usage.

## Why This Matters

LLM costs can explode unexpectedly. Real-time cost visibility and budget alerts prevent overruns.

### Cost Explosion Scenarios

| Scenario | Normal Cost | Exploded Cost | Factor |
|----------|-------------|---------------|--------|
| Retry storm | $500/day | $12,000/day | 24x |
| Infinite loop | $100/day | $8,000/day | 80x |
| Bot traffic flood | $1,000/day | $50,000/day | 50x |
| Prompt injection attack | $200/day | $15,000/day | 75x |

### Real-World Cost Monitoring

**Companies**: Helicone, Langfuse, OpenMeter, Portkey

**Use Cases**:
- Budget management and allocation
- Cost attribution by user/team/feature
- Anomaly detection for cost spikes
- Usage-based billing for customers

## Key Concepts

### Pricing Tiers (Per 1K Tokens)

| Model | Input | Output | Typical Query |
|-------|-------|--------|---------------|
| GPT-4o | $2.50 | $10.00 | $0.05-0.15 |
| GPT-4o-mini | $0.15 | $0.60 | $0.003-0.01 |
| Claude 3.5 Sonnet | $3.00 | $15.00 | $0.06-0.20 |
| Claude 3.5 Haiku | $0.25 | $1.25 | $0.005-0.02 |

### Budget Alert Thresholds

```
┌─────────────────────────────────────────┐
│           Budget: $1000/day             │
├─────────────────────────────────────────┤
│  🟢 OK:        < $800  (80%)           │
│  🟡 Warning:   $800-$990 (80-99%)      │
│  🔴 Critical:  $990-$1000 (99-100%)    │
│  🚨 Exceeded:  > $1000 (100%+)         │
└─────────────────────────────────────────┘
```

from dataclasses import dataclass, field
from typing import Dict, List, Optional, Callable

    WARNING = "warning"
    CRITICAL = "critical"
    EXCEEDED = "exceeded"

@dataclass
class PricingTier:
    """Pricing for a specific model."""
    model: str
    input_cost_per_1k: float  # USD per 1K input tokens
    output_cost_per_1k: float  # USD per 1K output tokens

@dataclass
class UsageRecord:
    """Single API usage record."""
    timestamp: datetime
    model: str
    input_tokens: int
    output_tokens: int
    cost: float
    user_id: Optional[str] = None
    request_id: Optional[str] = None

@dataclass
class BudgetAlert:
    """Budget alert notification."""
    level: AlertLevel
    current_cost: float
    budget: float
    percentage: float
    message: str
    timestamp: datetime

# Default pricing (as of 2024)

## Example Usage

```python
# Initialize tracker
tracker = RAGCostTracker(
    daily_budget=100.0,
    warning_threshold=0.8,
    critical_threshold=0.95
)

# Set up alert handler
def on_alert(alert: BudgetAlert):
    print(f"🚨 {alert.level.value.upper()}: {alert.message}")
    if alert.level == AlertLevel.EXCEEDED:
        # Send Slack notification, page on-call, etc.
        send_emergency_alert(alert)

tracker.register_alert_callback(on_alert)

# Record usage
cost = tracker.record_usage(
    model="gpt-4o",
    input_tokens=2000,
    output_tokens=500,
    user_id="user_123"
)
print(f"Request cost: ${cost:.4f}")

# Check budget status
alert = tracker.check_budget()
print(f"Daily spend: ${alert.current_cost:.2f} / ${alert.budget:.2f}")

# Check if we can afford another request
if tracker.should_allow_request(estimated_cost=0.50):
    # Proceed with request
    pass
else:
    # Queue for tomorrow or use cheaper model
    print("Budget limit reached!")

# Get breakdowns
print("By model:", tracker.get_cost_by_model())
print("By user:", tracker.get_cost_by_user())

def calculate_cost(self, model, input_tokens, output_tokens):
    if model not in self.pricing:
        raise ValueError(f"Unknown model: {model}")
    
    tier = self.pricing[model]
    input_cost = (input_tokens / 1000) * tier.input_cost_per_1k
    output_cost = (output_tokens / 1000) * tier.output_cost_per_1k
    
    return input_cost + output_cost
```

def check_budget(self):
    percentage = self._daily_cost / self.daily_budget
    
    if percentage >= 1.0:
        level = AlertLevel.EXCEEDED
    elif percentage >= self.critical_threshold:
        level = AlertLevel.CRITICAL
    elif percentage >= self.warning_threshold:
        level = AlertLevel.WARNING
    else:
        level = AlertLevel.OK
    
    return BudgetAlert(
        level=level,
        current_cost=self._daily_cost,
        budget=self.daily_budget,
        percentage=percentage,
        message=f"Daily spend at {percentage:.1%}",
        timestamp=datetime.now()
    )

### Middleware Pattern

```python
class CostTrackingMiddleware:
    def __init__(self, tracker: RAGCostTracker):
        self.tracker = tracker
    
    async def __call__(self, request, call_next):
        # Pre-request budget check
        if not self.tracker.should_allow_request():
            return JSONResponse(
                status_code=429,
                content={"error": "Daily budget exceeded"}
            )
        
        response = await call_next(request)
        
        # Post-request cost tracking
        if response.status_code == 200:
            self.tracker.record_usage(
                model=request.state.model,
                input_tokens=response.state.input_tokens,
                output_tokens=response.state.output_tokens,
                user_id=request.state.user_id
            )
        
        return response
```
