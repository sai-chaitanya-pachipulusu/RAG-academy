## Why Sentence-Aware Chunking Matters in Production

Cutting text mid-sentence creates chunks with incomplete ideas. Sentence-aware chunking produces more coherent chunks that embed better and retrieve more accurately. This leads to:

- **Better embeddings**: Complete thoughts capture meaning
- **Improved retrieval**: Chunks match queries more precisely
- **Higher quality answers**: LLM receives complete context
- **Better citations**: Sentence boundaries are natural quote boundaries

### Real-World Scenario

**Fixed-size chunking (bad):**
```
Chunk 1: "Machine learning is a subset of artificial intelligence that enables systems to learn from data. Deep learning is"
Chunk 2: "a type of machine learning that uses neural networks with multiple layers."
```
Problem: "Deep learning is" is incomplete; meaning split across chunks.

**Sentence-aware chunking (good):**
```
Chunk 1: "Machine learning is a subset of artificial intelligence that enables systems to learn from data."
Chunk 2: "Deep learning is a type of machine learning that uses neural networks with multiple layers."
```
Each chunk is a complete, coherent unit.

## The Mathematical Foundation

### Sentence Boundary Detection

```
Sentences end with: . ! ?
But not in:
- Abbreviations: "Dr.", "Mr.", "Inc.", "e.g.", "i.e."
- Decimal numbers: "3.14"
- Ellipses: "..."
- URLs: "example.com"
```

### Chunking Algorithm

```
1. Split text into sentences
2. Group sentences into chunks of maxSentences
3. Support sentence-level overlap for context
4. Track positions for citations
```

### Overlap Strategies

| Strategy | Description | Use Case |
|----------|-------------|----------|
| **No overlap** | Distinct sentences | Maximum efficiency |
| **1 sentence** | Last sentence of prev = first of next | Context continuity |
| **Sliding window** | Overlap of N sentences | Maximum context |

| **Abbreviations** | "Dr. Smith arrived." | Abbreviation list |

### Semantic Coherence

Sentence boundaries often align with semantic boundaries:

```
Sentence: Complete proposition or idea
Paragraph: Collection of related sentences
Document: Collection of paragraphs

Chunking at sentence boundaries preserves semantic units.
```

### Comparison with Fixed-Size

| Aspect | Fixed-Size | Sentence-Aware |
|--------|-----------|----------------|
| **Speed** | Faster | Slower (parsing) |
| **Coherence** | May split ideas | Preserves ideas |
| **Size variance** | Fixed | Variable |
| **Token efficiency** | Predictable | May waste space |

## Production Considerations

### Token Budget Management

Sentences vary in length:

```typescript
// Strategy: Target token count, adjust sentence count
function getSentencesForBudget(
  sentences: string[],
  targetTokens: number
): string[] {
  let totalTokens = 0;
  const selected = [];
  
  for (const sentence of sentences) {
    const tokens = estimateTokens(sentence);
    if (totalTokens + tokens > targetTokens) break;
    selected.push(sentence);
    totalTokens += tokens;
  }
  
  return selected;
}
```

## Common Pitfalls

- **Splitting on `.` inside abbreviations**: "Dr. Smith" → wrong split
- **Creating single-sentence chunks that are too small**: Balance size vs coherence
- **Not handling quotes**: `"He said." She replied.`
- **Unicode sentence endings**: Different languages use different characters
- **Losing whitespace**: Preserve original spacing
