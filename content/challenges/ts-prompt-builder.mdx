## Why this matters in production

How you format context in the prompt directly impacts answer quality and citation accuracy. A well-structured prompt template is essential for production RAG.

## What you're implementing

- Assemble system prompt, context, and query.
- Support citation formats: numbered, inline, none.
- Include source attribution for traceability.

## Common pitfalls

- Not separating context clearly from the question.
- Missing the system prompt for behavior control.
