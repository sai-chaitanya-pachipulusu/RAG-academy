## Overview

RAPTOR (Recursive Abstractive Processing for Tree-Organized Retrieval) builds a tree of document summaries at multiple levels of abstraction. When retrieving, it traverses the tree to find the most relevant nodes at the right level of detail.

## How It Works

1. **Embed** all documents
2. **Cluster** embeddings using Gaussian Mixture Models
3. **Summarize** each cluster into a higher-level node
4. **Repeat** recursively until a single root node remains
5. **Retrieve** by traversing from root to leaves based on query similarity

- Handles queries at different levels of granularity

- Set max depth based on document collection size
