# Ranker Distillation

Distill knowledge from large cross-encoder rankers to efficient bi-encoders, achieving 90%+ quality with 100x faster inference.

## The Problem

Cross-encoder rankers are accurate but slow:
- Concatenate query + document → BERT → score
- 100ms+ per document pair
- Can't scale to thousands of candidates

**Bi-encoders** are fast but less accurate:
- Encode query and document separately
- 1ms per document after caching
- Quality gap vs cross-encoders

**Solution**: Distill cross-encoder knowledge into bi-encoder.

## Your Task

Implement ranker distillation:

## Algorithm Details

### Teacher Score Generation

```python
def get_teacher_scores(self, 
                      queries: List[str], 
                      documents: List[str]) -> torch.Tensor:
    """Get scores from cross-encoder teacher."""
    with torch.no_grad():
        # Cross-encoder: concat query and doc
        pairs = [[q, d] for q, d in zip(queries, documents)]
        scores = self.teacher.predict(pairs, show_progress_bar=False)
        
    return torch.tensor(scores, dtype=torch.float32)
```

### Student Score Generation

```python
def get_student_scores(self,
                      queries: List[str],
                      documents: List[str]) -> torch.Tensor:
    """Get scores from bi-encoder student."""
    # Encode separately
    query_embeddings = self.student.encode(
        queries, 
        convert_to_tensor=True,
        show_progress_bar=False
    )
    doc_embeddings = self.student.encode(
        documents,
        convert_to_tensor=True,
        show_progress_bar=False
    )
    
    # Cosine similarity
    scores = torch.nn.functional.cosine_similarity(
        query_embeddings, 
        doc_embeddings
    )
    
    return scores
```

### Distillation Loss

```python
def distillation_loss(self,
                     teacher_scores: torch.Tensor,
                     student_scores: torch.Tensor) -> torch.Tensor:
    """
    Compute KL divergence between teacher and student distributions.
    """
    # Apply temperature scaling
    teacher_probs = F.softmax(teacher_scores / self.temperature, dim=0)
    student_log_probs = F.log_softmax(
        student_scores / self.temperature, 
        dim=0
    )
    
    # KL divergence
    kd_loss = F.kl_div(
        student_log_probs, 
        teacher_probs, 
        reduction='batchmean'
    ) * (self.temperature ** 2)
    
    return kd_loss
```

### Training Step

```python
def train_step(self,
              queries: List[str],
              documents: List[str],
              labels: torch.Tensor,
              optimizer: torch.optim.Optimizer) -> dict:
    """Single training step."""
    self.student.train()
    
    # Get teacher scores (no grad)
    teacher_scores = self.get_teacher_scores(queries, documents)
    
    # Get student scores
    student_scores = self.get_student_scores(queries, documents)
    
    # Compute losses
    kd_loss = self.distillation_loss(teacher_scores, student_scores)
    rank_loss = self.ranking_loss(student_scores, labels)
    
    # Combined loss
    total_loss = self.alpha * kd_loss + (1 - self.alpha) * rank_loss
    
    # Backward
    optimizer.zero_grad()
    total_loss.backward()
    optimizer.step()
    
    return {
        "total_loss": total_loss.item(),
        "kd_loss": kd_loss.item(),
        "rank_loss": rank_loss.item()
    }
```

## Temperature Scaling

Temperature controls the "softness" of target distributions:

| Temperature | Effect | Use Case |
|-------------|--------|----------|
| T < 1 | Harder targets | Confident teacher |
| T = 1 | Standard softmax | Balanced |
| T > 1 | Softer targets | Uncertain teacher, more gradient signal |

Typical values: T = 2-5 for ranking distillation.

## Evaluation Criteria

1. **Distillation Quality**: Student mimics teacher scores
2. **Ranking Performance**: NDCG/MAP on test set
3. **Speed**: 100x faster than teacher
4. **Generalization**: Performance on unseen queries
