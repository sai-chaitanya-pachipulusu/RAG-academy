# Query Entity Extraction

## Why Entities Matter

**Query**: "What was Apple's revenue in 2024?"

Entities:

- **Organization**: Apple
- **Date**: 2024

Now you can:

1. Filter to Apple-related documents
2. Filter to 2024 documents
3. THEN do vector search

This is WAY more efficient than searching all documents!

---

## The Hybrid Approach

```python
def smart_retrieve(query: str):
    # Step 1: Extract entities
    entities = extract_query_entities(query)

    # Step 2: Build metadata filter
    filters = {}
    if entities["organization"]:
        filters["company"] = entities["organization"][0]
    if entities["date"]:
        filters["year"] = entities["date"][0]

    # Step 3: Filtered vector search
    return vector_db.search(
        query=query,
        filter=filters,  # Much smaller search space!
        top_k=5
    )
```

## Entity Types

| Type         | Examples     | Detection        |
| ------------ | ------------ | ---------------- |
| Person       | "Elon Musk"  | Two capitals     |
| Organization | "Apple Inc"  | Company suffixes |
| Date         | "2024", "Q1" | Regex patterns   |
| Location     | "New York"   | Known places     |
| Product      | "iPhone"     | Domain knowledge |

```python
import spacy
nlp = spacy.load("en_core_web_sm")
doc = nlp(query)
entities = [(ent.text, ent.label_) for ent in doc.ents]
```
