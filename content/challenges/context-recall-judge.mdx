# Context Recall Evaluator

**Faithfulness** checks if the answer comes from the context. **Recall** checks if the context contains all the facts.

### The RAG Triad

| Metric       | Question                                   |
| ------------ | ------------------------------------------ |
| Faithfulness | Is the answer grounded in context?         |
| Relevance    | Does the answer address the query?         |
| **Recall**   | Does the context contain all needed facts? |

### Why Recall Matters

High faithfulness + low recall = **incomplete answers**.

The model might truthfully say "Paris is the capital" but miss "It has the Eiffel Tower" because that fact wasn't retrieved.

### Your Task

Implement a recall scorer:

1. Extract significant words from ground truth.
2. Check how many appear in the retrieved contexts.
3. Return: `matched / total`.

### Use Cases

- Evaluating chunking strategies.
- Comparing embedding models.
- A/B testing retrieval parameters.
