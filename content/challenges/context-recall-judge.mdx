## The RAG Triad

| Metric       | Question                                   |
| ------------ | ------------------------------------------ |
| Faithfulness | Is the answer grounded in context?         |
| Relevance    | Does the answer address the query?         |
| **Recall**   | Does the context contain all needed facts? |

## Why Recall Matters

High faithfulness + low recall = **incomplete answers**.

The model might truthfully say "Paris is the capital" but miss "It has the Eiffel Tower" because that fact wasn't retrieved.

## Complexity Analysis

| Operation | Time Complexity | Space Complexity |
|-----------|-----------------|------------------|
| Fact extraction | O(F × L) | O(F) |
| Context matching | O(F × C × L) | O(1) |
| Overall | O(F × C × L) | O(F) |

Where F = facts, C = contexts, L = average length

## Implementation

```python
from typing import List, Set, Dict
import re

class ContextRecallEvaluator:
    """
    Evaluate context recall: what fraction of ground-truth facts
    are present in the retrieved contexts.
    """
    
    def __init__(self):
        pass
    
    def extract_facts(self, ground_truth: str) -> List[str]:
        """
        Extract atomic facts from ground truth answer.
        
        In production, use an LLM for this. Here we use simple
        sentence splitting as a baseline.
        """
        # Simple sentence tokenization
        sentences = re.split(r'[.!?]+', ground_truth)
        facts = [s.strip() for s in sentences if len(s.strip()) > 10]
        return facts
    
    def fact_in_contexts(self, fact: str, contexts: List[str]) -> bool:
        """
        Check if a fact is supported by any context.
        
        In production, use semantic similarity or LLM verification.
        Here we use keyword matching as a baseline.
        """
        fact_words = set(fact.lower().split())
        
        for context in contexts:
            context_words = set(context.lower().split())
            # Simple overlap check
            overlap = len(fact_words & context_words)
            if overlap >= len(fact_words) * 0.5:  # 50% word overlap
                return True
        
        return False
    
    def evaluate(
        self,
        ground_truth: str,
        contexts: List[str]
    ) -> Dict:
        """
        Compute context recall score.
        
        Args:
            ground_truth: The ideal complete answer
            contexts: Retrieved contexts provided to the model
        
        Returns:
            Dict with score and details
        """
        facts = self.extract_facts(ground_truth)
        
        if not facts:
            return {
                "score": 1.0,
                "facts_found": 0,
                "total_facts": 0,
                "missing_facts": []
            }
        
        found_facts = []
        missing_facts = []
        
        for fact in facts:
            if self.fact_in_contexts(fact, contexts):
                found_facts.append(fact)
            else:
                missing_facts.append(fact)
        
        score = len(found_facts) / len(facts)
        
        return {
            "score": score,
            "facts_found": len(found_facts),
            "total_facts": len(facts),
            "missing_facts": missing_facts
        }
```

## Production Considerations

1. **Use LLM for fact extraction**: Simple splitting misses complex facts
2. **Semantic matching**: Keyword overlap fails on paraphrases
3. **Threshold tuning**: Balance precision/recall of fact detection
4. **Multi-hop facts**: Track facts requiring multiple contexts
