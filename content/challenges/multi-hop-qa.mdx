# Multi-Hop Question Answering

Some questions can't be answered from a single document. They require "hopping" between multiple sources to connect information.

**Your task**: Build a multi-hop RAG system that can answer questions requiring 2-3 document lookups.

3. **Reasonable depth**: Find answer within 3 hops
4. **Answer extraction**: Extract specific answer from context

```python
def _build_entity_index(self) -> Dict[str, List[str]]:
    index = {}
    for doc in self.documents:
        for entity in doc.entities:
            if entity not in index:
                index[entity] = []
            index[entity].append(doc.id)
    return index
```

```python
def extract_entities(self, text: str) -> List[str]:
    found = []
    for entity in self.entity_index.keys():
        if entity.lower() in text.lower():
            found.append(entity)
    return found
```

<details>
<summary>Hint 3: Hopping logic</summary>

```python
def hop(self, current_docs, question, visited):
    new_docs = []
    
    for doc in current_docs:
        # Find entities we haven't explored yet
        for entity in doc.entities:
            # Get docs containing this entity
            connected_docs = self.find_documents_by_entity(entity)
            
            for connected in connected_docs:
                if connected.id not in visited:
                    visited.add(connected.id)
                    new_docs.append(connected)
    
    return new_docs
```

## Bonus: Graph-Based Approach

For complex multi-hop, model documents as a graph:

```python
import networkx as nx

def build_knowledge_graph(documents: List[Document]) -> nx.Graph:
    G = nx.Graph()
    
    # Add document nodes
    for doc in documents:
        G.add_node(doc.id, type="document", content=doc.content)
    
    # Add entity nodes and edges
    for doc in documents:
        for entity in doc.entities:
            if not G.has_node(entity):
                G.add_node(entity, type="entity")
            G.add_edge(doc.id, entity)
    
    return G

def graph_based_hop(G, start_docs, target_entity):
    """Find path from start docs to target entity."""
    for doc_id in start_docs:
        try:
            path = nx.shortest_path(G, doc_id, target_entity)
            return path
        except nx.NetworkXNoPath:
            continue
    return None
```
