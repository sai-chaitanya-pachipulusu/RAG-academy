# Faithfulness Judge

<Callout title="Goal" variant="info">
  Build an automated "Faithfulness Judge" to detect hallucinations in RAG responses.
</Callout>

## The "Hallucination" Problem

LLMs are prone to "hallucinating" — generating facts that sound plausible but aren't supported by the retrieved context. Verifying every response manually is impossible at scale.

**Faithfulness Evaluation** (a core part of the RAGAS framework) uses an LLM to:

1. Break the answer down into individual claims
2. Check if each claim is supported by the context
3. Calculate a score: $\text{Faithfulness} = \frac{\text{Claims Supported}}{\text{Total Claims}}$

### Why Faithfulness Matters

| Metric | Impact | Target |
|--------|--------|--------|
| Low faithfulness | User distrust, misinformation | >90% |
| High faithfulness | Reliable, trustworthy AI | >95% |

## The Theory

### Faithfulness Formula

$$\text{Faithfulness} = \frac{\sum_{i=1}^{N} \mathbb{1}[\text{claim}_i \text{ supported}]}{N}$$

Where:
- $N$ = Total number of claims extracted
- $\mathbb{1}[\cdot]$ = Indicator function (1 if supported, 0 otherwise)

### Claim Verification Logic

```
For each claim:
    IF claim in context OR context entails claim:
        → SUPPORTED
    ELSE IF claim contradicts context:
        → CONTRADICTED (hallucination)
    ELSE:
        → NOT_FOUND (unverifiable)
```

## Your Task

Implement a heuristic-based judge that checks for "alignment" between an answer's claims and the provided context.

```python
from typing import List, Dict, Tuple, Optional
from dataclasses import dataclass
from enum import Enum
import re

class ClaimVerdict(Enum):
    """Verdict for claim verification."""
    SUPPORTED = "supported"
    CONTRADICTED = "contradicted"
    NOT_FOUND = "not_found"

@dataclass
class Claim:
    """A factual claim extracted from a response."""
    text: str
    verdict: ClaimVerdict
    evidence: Optional[str] = None
    confidence: float = 0.0

@dataclass
class FaithfulnessResult:
    """Complete faithfulness evaluation result."""
    score: float  # 0-1
    claims: List[Claim]
    supported_count: int
    contradicted_count: int
    not_found_count: int
    has_hallucination: bool

class FaithfulnessJudge:
    """
    Automated judge for evaluating RAG response faithfulness.
    
    Based on RAGAS framework: https://docs.ragas.io/
    
    Usage:
        >>> judge = FaithfulnessJudge(similarity_threshold=0.7)
        >>> result = judge.evaluate(
        ...     answer="Paris is the capital of France with 2M people.",
        ...     context="Paris is the capital of France. Population: 2.1M (2020)."
        ... )
        >>> result.score
        1.0
    """
    
    def __init__(
        self,
        similarity_threshold: float = 0.7,
        use_semantic_similarity: bool = True
    ):
        """
        Initialize the faithfulness judge.
        
        Args:
            similarity_threshold: Minimum similarity to consider claim supported
            use_semantic_similarity: Use embeddings vs lexical matching
        """
        self.similarity_threshold = similarity_threshold
        self.use_semantic_similarity = use_semantic_similarity
    
    def extract_claims(self, answer: str) -> List[str]:
        """
        Extract factual claims from an answer.
        
        Simple heuristic: sentences with numbers, dates, or specific facts.
        
        Args:
            answer: Generated answer
            
        Returns:
            List of claim strings
        """
        # Split into sentences
        sentences = re.split(r'[.!?]+', answer)
        claims = []
        
        for sent in sentences:
            sent = sent.strip()
            if not sent:
                continue
            
            # Heuristic: claims often contain numbers, dates, or specific terms
            has_number = bool(re.search(r'\d', sent))
            has_date = bool(re.search(r'\b(19|20)\d{2}\b', sent))  # Years
            has_specific = any(word in sent.lower() for word in [
                'is', 'are', 'was', 'were', 'has', 'have', 'percent', '%',
                'million', 'billion', 'founder', 'ceo', 'headquarters'
            ])
            
            if has_number or has_date or has_specific:
                claims.append(sent)
        
        return claims
    
    def lexical_similarity(self, claim: str, context: str) -> float:
        """
        Calculate lexical similarity between claim and context.
        
        Uses Jaccard similarity of word sets.
        """
        claim_words = set(claim.lower().split())
        context_words = set(context.lower().split())
        
        if not claim_words:
            return 0.0
        
        intersection = claim_words & context_words
        union = claim_words | context_words
        
        return len(intersection) / len(union)
    
    def verify_claim(
        self, 
        claim: str, 
        context: str
    ) -> Tuple[ClaimVerdict, float, Optional[str]]:
        """
        Verify if a claim is supported by the context.
        
        Args:
            claim: The claim to verify
            context: Source context
            
        Returns:
            (verdict, confidence, evidence)
        """
        # Check for direct substring match
        if claim.lower() in context.lower():
            return ClaimVerdict.SUPPORTED, 1.0, claim
        
        # Check similarity
        similarity = self.lexical_similarity(claim, context)
        
        if similarity >= self.similarity_threshold:
            return ClaimVerdict.SUPPORTED, similarity, None
        
        # Check for contradiction (simplified: negation detection)
        claim_negated = self._is_negated(claim)
        context_negated = self._is_negated(context)
        
        if claim_negated != context_negated and similarity > 0.5:
            return ClaimVerdict.CONTRADICTED, similarity, None
        
        return ClaimVerdict.NOT_FOUND, similarity, None
    
    def _is_negated(self, text: str) -> bool:
        """Check if text contains negation."""
        negation_words = ['not', 'no', 'never', "n't", 'without', 'neither', 'nor']
        return any(word in text.lower() for word in negation_words)
    
    def evaluate(self, answer: str, context: str) -> FaithfulnessResult:
        """
        Evaluate faithfulness of an answer against context.
        
        Args:
            answer: Generated answer
            context: Retrieved context
            
        Returns:
            FaithfulnessResult with score and claim details
        """
        # Extract claims
        claims_text = self.extract_claims(answer)
        
        if not claims_text:
            # No verifiable claims = perfect faithfulness (vacuously true)
            return FaithfulnessResult(
                score=1.0,
                claims=[],
                supported_count=0,
                contradicted_count=0,
                not_found_count=0,
                has_hallucination=False
            )
        
        # Verify each claim
        claims = []
        supported = 0
        contradicted = 0
        not_found = 0
        
        for claim_text in claims_text:
            verdict, confidence, evidence = self.verify_claim(claim_text, context)
            
            claim = Claim(
                text=claim_text,
                verdict=verdict,
                evidence=evidence,
                confidence=confidence
            )
            claims.append(claim)
            
            if verdict == ClaimVerdict.SUPPORTED:
                supported += 1
            elif verdict == ClaimVerdict.CONTRADICTED:
                contradicted += 1
            else:
                not_found += 1
        
        # Calculate score
        total = len(claims)
        score = supported / total if total > 0 else 1.0
        
        return FaithfulnessResult(
            score=score,
            claims=claims,
            supported_count=supported,
            contradicted_count=contradicted,
            not_found_count=not_found,
            has_hallucination=contradicted > 0
        )

# Pre-configured judges
STRICT_JUDGE = FaithfulnessJudge(similarity_threshold=0.8)
BALANCED_JUDGE = FaithfulnessJudge(similarity_threshold=0.7)
PERMISSIVE_JUDGE = FaithfulnessJudge(similarity_threshold=0.5)
```

## Example Usage

```python
# Initialize judge
judge = FaithfulnessJudge(similarity_threshold=0.7)

# Test cases
test_cases = [
    {
        "answer": "Paris is the capital of France with 2M people.",
        "context": "Paris is the capital of France. Population: 2.1M (2020).",
        "expected_score": 1.0
    },
    {
        "answer": "Paris is the capital of Germany.",
        "context": "Paris is the capital of France.",
        "expected_score": 0.0
    },
    {
        "answer": "The company was founded in 2010 by John Smith.",
        "context": "The company was founded in 2010. The CEO is John Smith.",
        "expected_score": 0.5  # Partial match
    }
]

for test in test_cases:
    result = judge.evaluate(test["answer"], test["context"])
    
    print(f"Answer: {test['answer']}")
    print(f"Score: {result.score:.2f}")
    print(f"Claims: {len(result.claims)}")
    for claim in result.claims:
        print(f"  - {claim.verdict.value}: {claim.text[:50]}...")
    print()
```

## Testing

```python
def test_faithfulness_judge():
    judge = FaithfulnessJudge(similarity_threshold=0.7)
    
    # Test 1: Perfect faithfulness
    result = judge.evaluate(
        "Paris is the capital of France.",
        "Paris is the capital of France."
    )
    assert result.score == 1.0
    assert result.supported_count == 1
    print("✓ Perfect faithfulness")
    
    # Test 2: Complete hallucination
    result = judge.evaluate(
        "Paris is the capital of Germany.",
        "Paris is the capital of France."
    )
    assert result.score == 0.0
    assert result.contradicted_count == 1
    print("✓ Contradiction detected")
    
    # Test 3: Partial faithfulness
    result = judge.evaluate(
        "Paris is the capital of France with 10M people.",
        "Paris is the capital of France."
    )
    assert 0 < result.score < 1
    print("✓ Partial faithfulness")
    
    # Test 4: No claims
    result = judge.evaluate(
        "That's a great question!",
        "Any context"
    )
    assert result.score == 1.0  # Vacuously true
    print("✓ No claims handling")
    
    # Test 5: Multiple claims
    result = judge.evaluate(
        "Paris is the capital. Berlin is the capital of Germany.",
        "Paris is the capital of France. Berlin is the capital of Germany."
    )
    assert len(result.claims) == 2
    print("✓ Multiple claims")
    
    print("\n✓ All faithfulness judge tests passed!")

test_faithfulness_judge()
```

## Production Considerations

### Integration with RAG Pipeline

```python
class FaithfulRAGPipeline:
    """RAG pipeline with faithfulness checking."""
    
    def __init__(self, retriever, generator, judge, min_faithfulness=0.8):
        self.retriever = retriever
        self.generator = generator
        self.judge = judge
        self.min_faithfulness = min_faithfulness
    
    def query(self, query: str) -> dict:
        # Retrieve
        docs = self.retriever.retrieve(query)
        context = "\n".join(docs)
        
        # Generate
        answer = self.generator.generate(query, context)
        
        # Evaluate faithfulness
        result = self.judge.evaluate(answer, context)
        
        # Handle low faithfulness
        if result.score < self.min_faithfulness:
            return {
                "answer": answer,
                "faithfulness": result.score,
                "warning": "Low faithfulness - please verify",
                "claims": result.claims
            }
        
        return {
            "answer": answer,
            "faithfulness": result.score,
            "verified": True
        }
```
