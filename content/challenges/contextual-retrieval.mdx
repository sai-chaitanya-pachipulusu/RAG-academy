## The "Lost Context" Problem

When you chunk a document, each chunk loses its context:

```
Original Document: "Q3 2024 Financial Report for Acme Corp..."

Chunk 47: "Revenue increased by 15% compared to the previous quarter."
```

**Problem**: Chunk 47 doesn't say WHICH company, WHICH quarter, or WHICH year. The embedding captures "revenue increased 15%" but misses the crucial context.

## Contextual Retrieval Solution

**Before embedding**, prepend a brief context to each chunk:

```
Contextualized Chunk 47:
"This chunk is from Acme Corp's Q3 2024 Financial Report, specifically the Revenue section.

Revenue increased by 15% compared to the previous quarter."
```

Now the embedding captures both the content AND its context.

## The Algorithm

```python
def contextualize_chunk(chunk: str, document: dict, chunk_index: int) -> str:
    """
    Prepend contextual header to a chunk before embedding.

    Args:
        chunk: The raw chunk text
        document: Full document metadata (title, source, section headers)
        chunk_index: Position of this chunk in the document

    Returns:
        Contextualized chunk ready for embedding
    """
    # Option 1: Manual template (fast, deterministic)
    context = f"""Document: {document['title']}
Source: {document['source']}
Section: {document.get('current_section', 'General')}
Chunk {chunk_index} of {document['total_chunks']}

"""
    return context + chunk


def contextualize_with_llm(chunk: str, document_text: str) -> str:
    """
    Use an LLM to generate situating context (higher quality, slower).

    This is Anthropic's recommended approach for maximum retrieval improvement.
    """
    prompt = f"""Here is a chunk from a larger document:

<chunk>
{chunk}
</chunk>

<document>
{document_text[:2000]}  # First 2000 chars for context
</document>

Write a short 1-2 sentence context that situates this chunk within the document.
Include key identifiers (dates, names, section) that help understand what this chunk refers to.
Do not summarize the chunk content itself.

Context:"""

    return llm.generate(prompt) + "\n\n" + chunk
```

## Implementation Options

### Option 1: Template-Based (Fast, ~0ms per chunk)

```python
CONTEXT_TEMPLATE = """Document: {title}
Type: {doc_type}
Section: {section_path}
"""

def fast_contextualize(chunk: str, metadata: dict) -> str:
    header = CONTEXT_TEMPLATE.format(**metadata)
    return header + chunk
```

**Pros**: No LLM cost, instant, deterministic
**Cons**: May miss nuanced context

### Option 2: LLM-Generated (Slow, ~200ms per chunk)

```python
def llm_contextualize(chunk: str, doc_context: str) -> str:
    prompt = f"Situate this chunk: {chunk[:500]}..."
    return claude_generate(prompt) + "\n\n" + chunk
```

**Pros**: Highest quality context
**Cons**: Adds indexing cost (~$1.50 per 1M tokens for Claude Haiku)

### Option 3: Hybrid (Recommended)

```python
def smart_contextualize(chunk: str, metadata: dict, doc_text: str) -> str:
    # Use template for structured docs (manuals, reports)
    if metadata.get('is_structured'):
        return template_contextualize(chunk, metadata)

    # Use LLM for unstructured docs (articles, emails)
    return llm_contextualize(chunk, doc_text)
```

## Implementation

```python
from typing import List, Dict, Optional, Callable
import json

class ContextualRetriever:
    """
    Implements Contextual Retrieval: prepend context to chunks
    before embedding to improve retrieval quality.
    """
    
    def __init__(
        self,
        embed_fn: Callable[[str], List[float]],
        use_llm: bool = False,
        llm_fn: Optional[Callable[[str], str]] = None
    ):
        self.embed_fn = embed_fn
        self.use_llm = use_llm
        self.llm_fn = llm_fn
    
    def generate_context(
        self,
        chunk: str,
        document: Dict,
        chunk_index: int
    ) -> str:
        """Generate context header for a chunk."""
        if self.use_llm and self.llm_fn:
            return self._llm_context(chunk, document)
        else:
            return self._template_context(chunk, document, chunk_index)
    
    def _template_context(
        self,
        chunk: str,
        document: Dict,
        chunk_index: int
    ) -> str:
        """Generate context using template."""
        return f"""Document: {document.get('title', 'Unknown')}
Source: {document.get('source', 'Unknown')}
Section: {document.get('section', 'General')}
Chunk: {chunk_index + 1} of {document.get('total_chunks', '?')}

"""
    
    def _llm_context(self, chunk: str, document: Dict) -> str:
        """Generate context using LLM."""
        prompt = f"""Here is a chunk from a document:

Chunk:
{chunk[:500]}

Document excerpt:
{document.get('text', '')[:1000]}

Write 1-2 sentences situating this chunk within the document.
Include key identifiers (company, date, section).

Context:"""
        
        return self.llm_fn(prompt) + "\n\n"
    
    def process_document(
        self,
        document: Dict,
        chunks: List[str]
    ) -> List[Dict]:
        """
        Process all chunks of a document with contextual retrieval.
        
        Args:
            document: Document metadata and text
            chunks: List of chunk texts
        
        Returns:
            List of contextualized chunks with embeddings
        """
        document['total_chunks'] = len(chunks)
        results = []
        
        for i, chunk in enumerate(chunks):
            # Generate context
            context = self.generate_context(chunk, document, i)
            
            # Create contextualized chunk
            contextualized = context + chunk
            
            # Embed
            embedding = self.embed_fn(contextualized)
            
            results.append({
                'original_chunk': chunk,
                'contextualized': contextualized,
                'context': context,
                'embedding': embedding,
                'chunk_index': i,
                'document_id': document.get('id')
            })
        
        return results
```

class ContextualIndexer:
    def __init__(self, use_llm: bool = False):
        self.use_llm = use_llm
        self.embedder = get_embedder()

    def index_document(self, doc: Document) -> List[Chunk]:

                'metadata': {...}
            })

        return contextualized

## When NOT to Use Contextual Retrieval

- **Homogeneous corpus**: All docs about the same topic
- **Already contextualized**: Chunks include headers naturally
- **Extreme latency sensitivity**: Can't afford indexing overhead
- **Ephemeral data**: Content changes too fast to re-index
