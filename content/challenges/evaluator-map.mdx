## When Precision@K Isn't Enough

Precision@K treats all positions equally. But in search, **rank matters**:

- Relevant doc at position 1 is better than at position 5
- We want to reward systems that return relevant docs earlier

**MAP** combines precision at every relevant position, then averages.

## The Formulas

### Average Precision (AP) for a single query

```
AP = (1/R) × Σᵢ (Precision@i × rel(i))
```

Where:

- `R` = total number of relevant documents
- `Precision@i` = precision at position i
- `rel(i)` = 1 if document at position i is relevant, 0 otherwise

### Mean Average Precision (MAP) across queries

```
MAP = (1/|Q|) × Σⱼ AP(qⱼ)
```

## The Algorithm

```python
def average_precision(
    retrieved: list[str],
    relevant: set[str]
) -> float:
    """
    Compute Average Precision for a single query.
    
    Time Complexity: O(N) where N = number retrieved
    Space Complexity: O(1) additional
    
    Args:
        retrieved: Ordered list of retrieved document IDs
        relevant: Set of ground-truth relevant document IDs
    
    Returns:
        AP score between 0.0 and 1.0
    """
    if not relevant:
        return 0.0
    
    relevant_found = 0
    precision_sum = 0.0
    
    for i, doc_id in enumerate(retrieved, start=1):
        if doc_id in relevant:
            relevant_found += 1
            precision_at_i = relevant_found / i
            precision_sum += precision_at_i
    
    return precision_sum / len(relevant)


def mean_average_precision(
    queries: list[tuple[list[str], set[str]]]
) -> float:
    """
    Compute Mean Average Precision across multiple queries.
    
    Time Complexity: O(Q × N) where Q = queries, N = retrieved per query
    Space Complexity: O(1) additional
    
    Args:
        queries: List of (retrieved_docs, relevant_docs) tuples
    
    Returns:
        MAP score between 0.0 and 1.0
    """
    if not queries:
        return 0.0
    
    ap_scores = [average_precision(r, rel) for r, rel in queries]
    return sum(ap_scores) / len(ap_scores)
```

## Complexity Analysis

| Operation | Time Complexity | Space Complexity |
|-----------|-----------------|------------------|
| AP computation | O(N) | O(1) |
| MAP computation | O(Q × N) | O(1) |

Where N is the number of retrieved documents and Q is the number of queries.

## Worked Example

**Query**: "HNSW algorithm complexity"
**Relevant docs**: {A, C, E} (R=3)
**Retrieved order**: [A, B, C, D, E, F, G, H, I, J]

| Position | Doc | Relevant? | Precision@i | Contribution |
| -------- | --- | --------- | ----------- | ------------ |
| 1        | A   | ✅ Yes    | 1/1 = 1.00  | 1.00         |
| 2        | B   | ❌ No     | 1/2 = 0.50  | 0.00         |
| 3        | C   | ✅ Yes    | 2/3 = 0.67  | 0.67         |
| 4        | D   | ❌ No     | 2/4 = 0.50  | 0.00         |
| 5        | E   | ✅ Yes    | 3/5 = 0.60  | 0.60         |
| 6-10     | ... | ❌ No     | ...         | 0.00         |

**AP = (1.00 + 0.67 + 0.60) / 3 = 0.757**

## Edge Cases (Critical for Implementation)

| Scenario                         | Handling                            |
| -------------------------------- | ----------------------------------- |
| No relevant docs in corpus (R=0) | AP = 0.0 (avoid division by zero)   |
| Relevant doc not retrieved       | Contributes 0 to AP sum             |
| Empty retrieval list             | AP = 0.0                            |
| All retrieved docs relevant      | AP = 1.0                            |
| Relevant docs at end of list     | Low AP (penalized for late ranking) |

## MAP vs Other Metrics

| Metric      | Multi-relevant? | Position-aware? | Best for                          |
| ----------- | --------------- | --------------- | --------------------------------- |
| Recall@K    | ✅              | ❌              | "Did we find them?"               |
| Precision@K | ✅              | ❌              | "How clean is top-K?"             |
| MRR         | ❌ (first only) | ✅              | Single-answer QA                  |
| nDCG        | ✅ (graded)     | ✅              | Graded relevance                  |
| **MAP**     | ✅ (binary)     | ✅              | Binary relevance, ranking quality |
