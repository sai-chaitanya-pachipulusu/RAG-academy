## Why F1-Score?

Precision and Recall are often in tension:

- **High Precision, Low Recall**: Retrieve few docs, but all are relevant (missing evidence)
- **High Recall, Low Precision**: Retrieve many docs, but most are irrelevant (context pollution)

**F1-Score** balances both with a single metric.

## The Formula

$$
F_1 = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}
$$

Or equivalently:

$$
F_1 = \frac{2 \times TP}{2 \times TP + FP + FN}
$$

Where:

- TP = True Positives (relevant docs retrieved)
- FP = False Positives (irrelevant docs retrieved)
- FN = False Negatives (relevant docs missed)

## The Algorithm

```python
def f1_at_k(
    retrieved: list[str],
    relevant: set[str],
    k: int
) -> float:
    """
    Compute F1 score for top-K retrieval.
    
    Time Complexity: O(K) where K = cutoff
    Space Complexity: O(1) additional
    
    Args:
        retrieved: Ordered list of retrieved doc IDs
        relevant: Set of relevant doc IDs
        k: Cutoff position
    
    Returns:
        F1 score between 0.0 and 1.0
    """
    top_k = set(retrieved[:k])
    
    true_positives = len(top_k & relevant)
    false_positives = len(top_k - relevant)
    false_negatives = len(relevant - top_k)
    
    precision = true_positives / (true_positives + false_positives) if top_k else 0.0
    recall = true_positives / (true_positives + false_negatives) if relevant else 0.0
    
    if precision + recall == 0:
        return 0.0
    
    return 2 * precision * recall / (precision + recall)
```

| Operation | Time Complexity | Space Complexity |
|-----------|-----------------|------------------|
| F1@K computation | O(K) | O(1) |

## Why Harmonic Mean?

The harmonic mean penalizes extreme imbalances:

| Precision | Recall | Arithmetic Mean | **F1 (Harmonic)** |
| --------- | ------ | --------------- | ----------------- |
| 1.0       | 1.0    | 1.00            | **1.00**          |
| 0.9       | 0.1    | 0.50            | **0.18**          |
| 0.5       | 0.5    | 0.50            | **0.50**          |
| 0.8       | 0.8    | 0.80            | **0.80**          |

Notice: With 0.9 precision and 0.1 recall, the F1 is only 0.18 — the harmonic mean penalizes the low recall!

## Worked Example

**Relevant docs**: {A, B, C, D, E} (5 relevant)
**Retrieved top-5**: [A, B, X, Y, Z]

- TP = 2 (A, B are relevant and retrieved)
- FP = 3 (X, Y, Z are irrelevant but retrieved)
- FN = 3 (C, D, E are relevant but missed)

```
Precision@5 = 2/5 = 0.40
Recall@5 = 2/5 = 0.40
F1@5 = 2 × (0.40 × 0.40) / (0.40 + 0.40) = 0.40
```
