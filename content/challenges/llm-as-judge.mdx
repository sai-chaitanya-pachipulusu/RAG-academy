<Callout title="Goal" variant="info">
  LLM-as-a-Judge is the technique of using a powerful LLM to automatically evaluate 
  the quality of RAG outputs. Instead of manually reviewing thousands of responses, 
  you automate evaluation with scoring rubrics and prompt engineering.
</Callout>

## Theory

### Evaluation Prompt Structure

```
CONTEXT: {retrieved_context}
QUESTION: {user_query}
ANSWER: {generated_answer}
RUBRIC: {scoring_criteria}
OUTPUT: Numeric score with reasoning
```

### Multi-Judge Aggregation

```
final_score = weighted_average(judge_1, judge_2, ..., judge_n)
```

### Visual Intuition

Think of LLM-as-a-Judge like having an expert reviewer who:
1. Reads the source context (like fact-checking)
2. Reads the question and answer
3. Scores against specific criteria
4. Provides explanations for the score

## Why It Matters

Manual evaluation doesn't scale. One human can review ~100 conversations/day.
LLM-as-a-Judge can evaluate thousands in minutes, enabling:
- Regression testing on every deployment
- A/B testing at scale
- Continuous quality monitoring

## Common Mistakes

- Using vague rubrics without specific criteria
- Not validating judge outputs against human labels
- Ignoring judge model biases (e.g., verbosity preference)

## Interview Tips

- Mention that you calibrate LLM judges against human evaluations
- Discuss using multiple judges and consensus for robustness
- Reference the RAGAS framework as a production solution

Where L = prompt + response length

## Implementation

```python
import json
from typing import Dict, Callable, Optional

class LLMJudge:
    """
    LLM-as-a-Judge for automated RAG evaluation.
    
    Evaluates:
    - Faithfulness: Is the answer grounded in context?
    - Relevancy: Does the answer address the question?
    """
    
    def __init__(self, model_fn: Callable[[str], str]):
        """
        Initialize the judge with a model function.
        
        Args:
            model_fn: A function that takes a prompt string and returns a response string.
                     The response should be valid JSON with "score" and "reasoning" keys.
        """
        self.model_fn = model_fn
    
    def _create_faithfulness_prompt(self, context: str, answer: str) -> str:
        """Create the prompt for faithfulness evaluation."""
        return f"""You are an impartial judge evaluating if an AI answer is faithful to its source.

CONTEXT (the only source of truth):
{context}

AI ANSWER:
{answer}

TASK:
Evaluate how well the answer is supported by the context.
- 1.0 = Every claim is directly supported by the context
- 0.7 = Most claims are supported, with minor unsupported additions
- 0.5 = Mix of supported and unsupported claims
- 0.3 = Few claims are supported by the context
- 0.0 = Answer contradicts or is not grounded in context

Respond with JSON only: {{"score": X.X, "reasoning": "your explanation"}}"""
    
    def _create_relevancy_prompt(self, question: str, answer: str) -> str:
        """Create the prompt for relevancy evaluation."""
        return f"""You are an impartial judge evaluating if an AI answer addresses the user's question.

USER QUESTION:
{question}

AI ANSWER:
{answer}

TASK:
Evaluate how well the answer addresses the specific question asked.
- 1.0 = Directly and completely answers the question
- 0.7 = Mostly answers but missing some details
- 0.5 = Partially addresses the question
- 0.3 = Tangentially related but doesn't really answer
- 0.0 = Does not address the question at all

Respond with JSON only: {{"score": X.X, "reasoning": "your explanation"}}"""
    
    def _parse_response(self, response: str) -> Dict:
        """Parse the LLM response into a structured dict."""
        try:
            result = json.loads(response)
            # Validate expected keys
            if "score" not in result:
                result["score"] = 0.5
            if "reasoning" not in result:
                result["reasoning"] = "No reasoning provided"
            # Clamp score to valid range
            result["score"] = max(0.0, min(1.0, float(result["score"])))
            return result
        except (json.JSONDecodeError, ValueError):
            return {"score": 0.5, "reasoning": "Failed to parse LLM response"}
    
    def score_faithfulness(self, context: str, answer: str) -> Dict:
        """Score how well the answer is grounded in the context."""
        prompt = self._create_faithfulness_prompt(context, answer)
        response = self.model_fn(prompt)
        return self._parse_response(response)
    
    def score_relevancy(self, question: str, answer: str) -> Dict:
        """Score how well the answer addresses the question."""
        prompt = self._create_relevancy_prompt(question, answer)
        response = self.model_fn(prompt)
        return self._parse_response(response)
    
    def evaluate(
        self,
        question: str,
        context: str,
        answer: str
    ) -> Dict:
        """Complete evaluation with all metrics."""
        faithfulness = self.score_faithfulness(context, answer)
        relevancy = self.score_relevancy(question, answer)
        
        overall_score = (faithfulness["score"] + relevancy["score"]) / 2
        
        return {
            "faithfulness": faithfulness,
            "relevancy": relevancy,
            "overall_score": overall_score
        }
```

## Extensions

Once you've implemented the basic judge, consider these enhancements:

1. **Multi-Judge Consensus**: Use multiple LLMs and average their scores
2. **Confidence Intervals**: Track variance across multiple evaluations
3. **Custom Rubrics**: Add domain-specific scoring criteria
4. **Batch Evaluation**: Process multiple test cases efficiently
5. **Human Calibration**: Compare LLM scores against human labels
