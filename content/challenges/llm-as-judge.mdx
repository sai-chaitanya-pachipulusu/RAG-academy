# LLM as a Judge

Build an automated evaluation system that uses a large language model to score RAG outputs for faithfulness, relevancy, and completeness.

## Problem Statement

You're building a production RAG system that handles thousands of queries daily. You need to:

1. Automatically score whether answers are faithful to the retrieved context
2. Check if answers actually address the user's question
3. Detect when the model hallucinates or makes unsupported claims

Manual review is impossible at scale. Implement an `LLMJudge` class that automates this evaluation.

```python
import json

class LLMJudge:
    def __init__(self, model_fn):
        self.model_fn = model_fn

    def _create_faithfulness_prompt(self, context: str, answer: str) -> str:
        return f"""You are an impartial judge evaluating if an AI answer is faithful to its source.

CONTEXT (the only source of truth):
{context}

AI ANSWER:
{answer}

TASK:
Evaluate how well the answer is supported by the context.
- 1.0 = Every claim is directly supported by the context
- 0.7 = Most claims are supported, with minor unsupported additions
- 0.5 = Mix of supported and unsupported claims
- 0.3 = Few claims are supported by the context
- 0.0 = Answer contradicts or is not grounded in context

Respond with JSON only: {{"score": X.X, "reasoning": "your explanation"}}"""

    def _create_relevancy_prompt(self, question: str, answer: str) -> str:
        return f"""You are an impartial judge evaluating if an AI answer addresses the user's question.

USER QUESTION:
{question}

AI ANSWER:
{answer}

TASK:
Evaluate how well the answer addresses the specific question asked.
- 1.0 = Directly and completely answers the question
- 0.7 = Mostly answers but missing some details
- 0.5 = Partially addresses the question
- 0.3 = Tangentially related but doesn't really answer
- 0.0 = Does not address the question at all

Respond with JSON only: {{"score": X.X, "reasoning": "your explanation"}}"""

    def _parse_response(self, response: str) -> dict:
        try:
            result = json.loads(response)
            # Validate expected keys
            if "score" not in result:
                result["score"] = 0.5
            if "reasoning" not in result:
                result["reasoning"] = "No reasoning provided"
            # Clamp score to valid range
            result["score"] = max(0.0, min(1.0, float(result["score"])))
            return result
        except (json.JSONDecodeError, ValueError):
            return {"score": 0.5, "reasoning": "Failed to parse LLM response"}

    def score_faithfulness(self, context: str, answer: str) -> dict:
        prompt = self._create_faithfulness_prompt(context, answer)
        response = self.model_fn(prompt)
        return self._parse_response(response)

    def score_relevancy(self, question: str, answer: str) -> dict:
        prompt = self._create_relevancy_prompt(question, answer)
        response = self.model_fn(prompt)
        return self._parse_response(response)

    def evaluate(self, question: str, context: str, answer: str) -> dict:
        faithfulness = self.score_faithfulness(context, answer)
        relevancy = self.score_relevancy(question, answer)

        overall_score = (faithfulness["score"] + relevancy["score"]) / 2

        return {
            "faithfulness": faithfulness,
            "relevancy": relevancy,
            "overall_score": overall_score
        }
```

## Extensions

Once you've implemented the basic judge, consider these enhancements:

1. **Multi-Judge Consensus**: Use multiple LLMs and average their scores
2. **Confidence Intervals**: Track variance across multiple evaluations
3. **Custom Rubrics**: Add domain-specific scoring criteria
4. **Batch Evaluation**: Process multiple test cases efficiently
5. **Human Calibration**: Compare LLM scores against human labels
