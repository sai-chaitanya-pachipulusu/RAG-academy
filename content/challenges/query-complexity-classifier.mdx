# Query Complexity Classifier

Not all queries need the same treatment. Simple lookups, complex reasoning, and ambiguous questions each need different handling.

**Your task**: Build a query classifier that categorizes questions by complexity.

## Requirements

1. **Accuracy**: At least 80% correct on test examples
2. **Confidence scores**: Return meaningful confidence (0.0-1.0)
3. **Reasoning**: Explain why each classification was made
4. **Rule-based**: Use patterns (no ML model needed)

## Classification Guidelines

### NO_RETRIEVAL
- Math operations (`\d+ [+\-*/] \d+`)
- Greetings (`^(hi|hello|hey)`)
- General knowledge (capitals, definitions)
- Common acronym expansions

### SIMPLE
- Single entity lookup ("What is X?", "Who is Y?")
- Direct questions about one topic
- "How do I..." questions with clear subject

### COMPLEX
- Comparisons ("compare", "vs", "difference between")
- Analysis ("analyze", "explain why", "factors")
- Multi-part questions ("and", "also")
- Trends and patterns ("over time", "trends")
- Pros/cons evaluations

### AMBIGUOUS
- Very short (< 3 words) without clear meaning
- Pronouns without context ("it", "that", "this")
- Vague references ("the thing", "the document")

def _build_patterns(self):
    # NO_RETRIEVAL patterns
    self.no_retrieval_patterns = [
        r"^\d+\s*[+\-*/]\s*\d+",       # Math
        r"^(hi|hello|hey|greetings)",  # Greetings
        r"what (is|does) .+ stand for", # Acronyms
        r"^(what is|define|explain) (a|an|the)? ?\w+$",  # Simple definitions
    ]
    
    # COMPLEX patterns
    self.complex_patterns = [
        r"compare|comparison|versus|vs\.?",
        r"analyze|analysis|explain why",
        r"(pros? and cons?|advantages? and disadvantages?)",
        r"(trends?|patterns?|over time)",
        r"(factors?|reasons?|causes?) .*(led to|behind|for)",
        r"summarize .* and .*(identify|find)",
    ]
    
    # AMBIGUOUS patterns

        r"^(it|this|that|those|these)$",
        r"^.{1,3}$",  # Very short

def classify(self, query: str) -> ClassificationResult:
    query = query.strip()
    query_lower = query.lower()
    
    # Check ambiguous first (short queries)
    is_amb, amb_conf, amb_reason = self._check_ambiguous(query)
    if is_amb and amb_conf > 0.7:
        return ClassificationResult(
            QueryComplexity.AMBIGUOUS, amb_conf, amb_reason
        )
    
    # Check no_retrieval
    is_no_ret, no_ret_conf, no_ret_reason = self._check_no_retrieval(query)
    if is_no_ret and no_ret_conf > 0.6:
        return ClassificationResult(
            QueryComplexity.NO_RETRIEVAL, no_ret_conf, no_ret_reason
        )
    
    # Check complex
    is_complex, complex_conf, complex_reason = self._check_complex(query)
    if is_complex and complex_conf > 0.5:
        return ClassificationResult(
            QueryComplexity.COMPLEX, complex_conf, complex_reason
        )
    
    # Default to simple
    return ClassificationResult(
        QueryComplexity.SIMPLE, 0.7, "Default classification for clear questions"
    )
