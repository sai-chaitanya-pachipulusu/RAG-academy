# Section-Based Chunking: Respecting Document Structure

## The Metadata Opportunity

Technical documents, papers, and manuals have **explicit structure**:

- `# Main Title`
- `## Chapter`
- `### Section`
- `#### Subsection`

These headers DESCRIBE their content. That's invaluable metadata!

---

## The Insight

A chunk's section header tells you what it's about before you even read it:

```
Chunk from "## Error Handling" → Likely about errors
Chunk from "## Getting Started" → Likely introductory
```

This metadata improves both retrieval and reranking.

---

## The Algorithm

```python
def section_chunk(markdown):
    """
    Chunk markdown by section headers with breadcrumb tracking.
    
    Time Complexity: O(L) where L = number of lines
    Space Complexity: O(N) for output
    
    Args:
        markdown: Markdown text with headers
        
    Returns:
        List of chunks with metadata including breadcrumbs
    """
    chunks = []
    header_stack = []  # Track nested headers
    current_content = []
    
    for line in markdown.split('\n'):
        if line.startswith('#'):
            # Flush previous section
            if current_content:
                chunks.append({
                    'text': '\n'.join(current_content),
                    'header': header_stack[-1] if header_stack else 'Document',
                    'breadcrumb': ' > '.join(header_stack)
                })
            
            # Update header tracking
            level = len(line) - len(line.lstrip('#'))
            title = line.lstrip('# ').strip()
            
            # Pop headers of same or higher level
            while header_stack and get_level(header_stack[-1]) >= level:
                header_stack.pop()
            header_stack.append(title)
            
            current_content = [line]
        else:
            current_content.append(line)
    
    return chunks
```

---

## The Breadcrumb Pattern

For a deeply nested section:

```markdown
# User Guide

## Installation

### Prerequisites

This section covers what you need before installing.
```

The chunk would have:

```python
{
    'text': '### Prerequisites\nThis section covers...',
    'header': 'Prerequisites',
    'breadcrumb': 'User Guide > Installation > Prerequisites'
}
```

---

## Enhanced Retrieval

With section metadata, you can:

1. **Filter by section**: Only search in "API Reference"
2. **Boost by section**: Weight "FAQ" higher for questions
3. **Generate citations**: "From: User Guide > Installation"

---

## ⚖️ Tradeoffs

### Pros

- ✅ Rich semantic metadata
- ✅ Natural content boundaries
- ✅ Enables section-level filtering
- ✅ Better citations

### Cons

- ❌ Only works for structured documents
- ❌ Requires consistent header usage
- ❌ Some sections may be too long/short
