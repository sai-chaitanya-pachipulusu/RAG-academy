# Parent Document Tokenizer

Implement token-based parent document retrieval that uses small windows for precise matching and expands to larger parent windows for rich LLM context.

## The Context vs Precision Trade-off

- **Small chunks (128 tokens)**: Great for retrieval precision. The vector is focused.
- **Large chunks (1024 tokens)**: Great for LLM comprehension. The model sees surrounding context.

**Parent Document Retrieval** gives you the best of both worlds.

1. **Chunk** your documents into small pieces (child chunks) using token boundaries
2. **Link** each child to its parent (a larger window around it)
3. **Index** the **children**
4. When a child is hit, retrieve and send the **parent**

## Example

```python
# Initialize tokenizer
tokenizer = ParentDocumentTokenizer(
    child_size=128,    # Small for precise retrieval
    parent_size=512,   # 4x larger for context
    overlap=32         # Overlap for continuity
)

# Process document
doc = """
The quick brown fox jumps over the lazy dog. The fox was very quick and agile.
It jumped high into the air and landed gracefully. The dog didn't even notice.
The fox continued on its journey through the forest...
"""

result = tokenizer.process_document("doc_1", doc)

print(f"Created {len(result['children'])} child chunks")
print(f"Created {len(result['parents'])} parent windows")

# Child chunks (for indexing/retrieval)
for child in result['children'][:2]:
    print(f"Child {child['id']}: {len(child['tokens'])} tokens")
    print(f"  Text: {child['text'][:50]}...")

# When child is retrieved, get parent
child_id = result['children'][0]['id']
parent = tokenizer.get_parent_for_child(child_id, result)
print(f"Parent for {child_id}:")
print(f"  Size: {len(parent['tokens'])} tokens")
print(f"  Text: {parent['text'][:100]}...")
```

## Algorithm Details

### Tokenization

```python
def tokenize(self, text: str) -> list[int]:
    """Tokenize text using tiktoken or provided tokenizer."""
    if self.tokenizer is None:
        import tiktoken
        self.tokenizer = tiktoken.get_encoding("cl100k_base")
    
    return self.tokenizer.encode(text)

def detokenize(self, tokens: list[int]) -> str:
    """Convert tokens back to text."""
    return self.tokenizer.decode(tokens)
```

### Child Chunk Creation

```python
def create_child_chunks(self, text: str) -> list[dict]:
    """Create overlapping child chunks."""
    tokens = self.tokenize(text)
    chunks = []
    
    start = 0
    chunk_id = 0
    
    while start < len(tokens):
        end = min(start + self.child_size, len(tokens))
        
        chunk_tokens = tokens[start:end]
        chunk_text = self.detokenize(chunk_tokens)
        
        chunks.append({
            "id": f"child_{chunk_id}",
            "text": chunk_text,
            "tokens": chunk_tokens,
            "start_idx": start,
            "end_idx": end
        })
        
        # Move with overlap
        start = end - self.overlap
        chunk_id += 1
        
        # Avoid infinite loop at end
        if end == len(tokens):
            break
    
    return chunks
```

### Parent Window Creation

```python
def create_parent_windows(self, child_chunks: list[dict], 
                         full_text: str) -> list[dict]:
    """Create parent windows centered on child chunks."""
    all_tokens = self.tokenize(full_text)
    parents = []
    
    for i, child in enumerate(child_chunks):
        # Calculate parent window around child
        child_center = (child["start_idx"] + child["end_idx"]) // 2
        
        parent_start = max(0, child_center - self.parent_size // 2)
        parent_end = min(len(all_tokens), parent_start + self.parent_size)
        
        # Adjust if at document end
        if parent_end == len(all_tokens):
            parent_start = max(0, parent_end - self.parent_size)
        
        parent_tokens = all_tokens[parent_start:parent_end]
        parent_text = self.detokenize(parent_tokens)
        
        parent_id = f"parent_{i}"
        
        parents.append({
            "id": parent_id,
            "text": parent_text,
            "tokens": parent_tokens,
            "start_idx": parent_start,
            "end_idx": parent_end,
            "child_ids": [child["id"]]  # Link to child
        })
    
    return parents
```

### Full Pipeline

```python
def process_document(self, doc_id: str, text: str) -> dict:
    """Process document into parent-child structure."""
    # Create children
    children = self.create_child_chunks(text)
    
    # Create parents
    parents = self.create_parent_windows(children, text)
    
    # Build mappings
    child_to_parent = {}
    parent_to_children = {}
    
    for parent in parents:
        parent_to_children[parent["id"]] = parent["child_ids"]
        for child_id in parent["child_ids"]:
            child_to_parent[child_id] = parent["id"]
    
    return {
        "doc_id": doc_id,
        "children": children,
        "parents": parents,
        "mappings": {
            "child_to_parent": child_to_parent,
            "parent_to_children": parent_to_children
        }
    }
```

## Token Size Guidelines

| Use Case | Child Size | Parent Size | Ratio | Overlap |
|----------|-----------|-------------|-------|---------|
| General QA | 128 | 512 | 4x | 32 |
| Code | 256 | 1024 | 4x | 64 |
| Legal | 256 | 1024 | 4x | 64 |
| Medical | 128 | 512 | 4x | 32 |
| Research | 256 | 2048 | 8x | 64 |

## Evaluation Criteria

1. **Token Boundary Respect**: No split words
2. **Coverage**: All text included in chunks
3. **Mapping Accuracy**: Correct child→parent links
4. **Overlap**: Proper continuity between children

## Test Cases

```python
def test_token_boundaries():
    """Ensure no words are split."""
    tokenizer = ParentDocumentTokenizer(child_size=10)
    
    text = "The quick brown fox jumps"
    chunks = tokenizer.create_child_chunks(text)
    
    # Reconstruct should match original
    reconstructed = ""
    for chunk in chunks:
        reconstructed += chunk["text"]
    
    assert text in reconstructed

def test_parent_expansion():
    """Test parent is larger than child."""
    tokenizer = ParentDocumentTokenizer(child_size=50, parent_size=200)
    
    text = " ".join([f"word{i}" for i in range(100)])
    result = tokenizer.process_document("doc_1", text)
    
    for child in result["children"]:
        parent = tokenizer.get_parent_for_child(child["id"], result)
        assert len(parent["tokens"]) >= len(child["tokens"])

def test_overlap():
    """Test consecutive chunks have overlap."""
    tokenizer = ParentDocumentTokenizer(child_size=50, overlap=10)
    
    text = " ".join([f"word{i}" for i in range(100)])
    chunks = tokenizer.create_child_chunks(text)
    
    if len(chunks) > 1:
        # Some overlap should exist
        overlap = set(chunks[0]["tokens"]) & set(chunks[1]["tokens"])
        assert len(overlap) > 0
```

## Comparison: Chunking Strategies

| Strategy | Precision | Context | Storage | Best For |
|----------|-----------|---------|---------|----------|
| Fixed | Medium | Medium | Low | Simple docs |
| Parent-Document | High | High | Medium | Production RAG |
| Hierarchical | High | Very High | High | Complex docs |
| Semantic | Very High | Medium | Medium | Thematic queries |
