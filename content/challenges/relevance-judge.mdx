## The Problem: Answer Drift

Sometimes an LLM gets distracted by interesting but irrelevant facts in the retrieved context. It might provide a great summary of a document that has nothing to do with the original prompt.

## Complexity Analysis

| Operation | Time Complexity | Space Complexity |
|-----------|-----------------|------------------|
| Keyword overlap | O(Q + A) | O(Q) |
| Semantic similarity | O(d) | O(d) |
| LLM evaluation | O(L³) | O(L) |

Where Q = query length, A = answer length, d = embedding dim, L = total length

## Implementation

```python
from typing import Dict, List, Set
import re

class RelevanceEvaluator:
    """
    Evaluate answer relevance: how well does the answer
    address the user's specific question.
    """
    
    def __init__(self):
        pass
    
    def extract_keywords(self, text: str) -> Set[str]:
        """Extract meaningful keywords from text."""
        # Simple keyword extraction (stop word removal)
        stop_words = {
            'the', 'a', 'an', 'is', 'are', 'was', 'were', 'be', 'been',
            'being', 'have', 'has', 'had', 'do', 'does', 'did', 'will',
            'would', 'could', 'should', 'may', 'might', 'must', 'shall',
            'can', 'need', 'dare', 'ought', 'used', 'to', 'of', 'in',
            'for', 'on', 'with', 'at', 'by', 'from', 'as', 'into',
            'through', 'during', 'before', 'after', 'above', 'below',
            'between', 'under', 'and', 'but', 'or', 'yet', 'so',
            'if', 'because', 'although', 'though', 'while', 'where',
            'when', 'that', 'which', 'who', 'whom', 'whose', 'what',
            'this', 'these', 'those', 'i', 'you', 'he', 'she', 'it',
            'we', 'they', 'me', 'him', 'her', 'us', 'them'
        }
        
        words = re.findall(r'\b[a-zA-Z]+\b', text.lower())
        return {w for w in words if w not in stop_words and len(w) > 2}
    
    def keyword_overlap_score(self, query: str, answer: str) -> float:
        """
        Compute relevance based on keyword overlap.
        Simple baseline approach.
        """
        query_keywords = self.extract_keywords(query)
        answer_keywords = self.extract_keywords(answer)
        
        if not query_keywords:
            return 1.0
        
        overlap = len(query_keywords & answer_keywords)
        return overlap / len(query_keywords)
    
    def evaluate(self, query: str, answer: str) -> Dict:
        """
        Compute relevance score.
        
        Args:
            query: User's question
            answer: Generated answer
        
        Returns:
            Dict with score and details
        """
        score = self.keyword_overlap_score(query, answer)
        
        query_keywords = self.extract_keywords(query)
        answer_keywords = self.extract_keywords(answer)
        matched = query_keywords & answer_keywords
        missing = query_keywords - answer_keywords
        
        return {
            "score": score,
            "query_keywords": list(query_keywords),
            "matched_keywords": list(matched),
            "missing_keywords": list(missing),
            "method": "keyword_overlap"
        }
```

## Real-World Evaluation

In production, we use **LLM-as-a-Judge** (like RAGAS or Arize Phoenix) where a stronger model (e.g., GPT-4) is prompted to grade the relevance of a smaller model's output. This creates a feedback loop for continuous prompt and retrieval optimization.

### Production Implementation

```python
def llm_relevance_score(query: str, answer: str, judge_fn) -> Dict:
    """
    Use LLM to evaluate relevance.
    
    More accurate than keyword matching but more expensive.
    """
    prompt = f"""Rate how well this answer addresses the query.
    Score 0-10 where 10 = perfectly addresses.
    
    Query: {query}
    Answer: {answer}
    
    Respond with JSON: {{"score": X, "reasoning": "..."}}"""
```

## Best Practices

1. **Hybrid approach**: Use keyword matching for filtering, LLM for final scoring
2. **Threshold tuning**: Adjust based on your use case (strict vs lenient)
3. **Multi-turn tracking**: Track relevance across conversation turns
4. **Human validation**: Periodically verify automated scores
