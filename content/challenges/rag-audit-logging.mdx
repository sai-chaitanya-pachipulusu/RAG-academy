# RAG Audit Logging

Implement an audit logging system that tracks all RAG operations for compliance, debugging, and quality analysis.

## Why This Matters

Audit logs are critical for:
- **Compliance**: GDPR, HIPAA, SOC 2 require data access tracking
- **Debugging**: Reconstruct what happened for failed queries
- **Quality Analysis**: Understand retrieval vs generation issues
- **Security**: Detect unauthorized access or prompt injection
- **Cost Attribution**: Track usage by user/team/feature

## Real-World Application

**Companies:** Fintech, Healthcare, Enterprise SaaS
**Regulations:** GDPR Article 30, HIPAA 164.308, SOC 2 CC7.2
**Use Cases:**
- Customer support ticket auditing
- Financial advice compliance
- Healthcare data access tracking
- Security incident investigation

## Key Concepts

### The Four Ws of Audit Logging

| Field | Description | Example |
|-------|-------------|---------|
| **Who** | Identity requesting | `user_id: "user_123"` |
| **What** | Action performed | `action: "rag_query"` |
| **When** | Timestamp with timezone | `timestamp: "2024-01-15T10:30:00Z"` |
| **Why** | Context/justification | `session_id: "sess_456"` |

### PII Handling

```python
import hashlib
from typing import Optional

def hash_pii(value: str, salt: str = "") -> str:
    """Hash personally identifiable information."""
    return hashlib.sha256(f"{value}{salt}".encode()).hexdigest()[:16]

def redact_sensitive(query: str) -> str:
    """Redact sensitive patterns (emails, SSNs, etc.)."""
    import re
    # Redact emails
    query = re.sub(r'\S+@\S+\.\S+', '[EMAIL_REDACTED]', query)
    # Redact SSNs
    query = re.sub(r'\d{3}-\d{2}-\d{4}', '[SSN_REDACTED]', query)
    return query
```

## Audit Log Schema

```python
from dataclasses import dataclass, field
from typing import List, Dict, Optional
from datetime import datetime
import uuid

@dataclass
class AuditLogEntry:
    """Complete audit record for a RAG operation."""
    
    # Identification
    log_id: str = field(default_factory=lambda: str(uuid.uuid4()))
    timestamp: datetime = field(default_factory=datetime.utcnow)
    
    # Actor
    user_id: Optional[str] = None
    session_id: Optional[str] = None
    api_key_id: Optional[str] = None
    ip_address: Optional[str] = None
    
    # Action
    action: str = ""  # "rag_query", "index_update", "feedback"
    
    # Query details
    query: str = ""
    query_hash: str = ""  # For deduplication
    
    # Retrieval details
    retrieved_doc_ids: List[str] = field(default_factory=list)
    retrieval_scores: List[float] = field(default_factory=list)
    num_docs_retrieved: int = 0
    
    # Generation details
    context_used: str = ""
    response: str = ""
    response_hash: str = ""
    model_used: str = ""
    
    # Performance
    latency_ms: float = 0.0
    tokens_in: int = 0
    tokens_out: int = 0
    
    # Metadata
    metadata: Dict = field(default_factory=dict)
    tags: List[str] = field(default_factory=list)
    
    # Quality
    user_feedback: Optional[str] = None  # "thumbs_up", "thumbs_down"
    
    # Status
    success: bool = True
    error_message: Optional[str] = None
```

### Storage Backends

```python
from abc import ABC, abstractmethod
from typing import List

class AuditStorage(ABC):
    """Abstract storage backend for audit logs."""
    
    @abstractmethod
    def write(self, entry: AuditLogEntry):
        """Write a log entry."""
        pass
    
    @abstractmethod
    def query(self, filters: Dict, limit: int = 100) -> List[AuditLogEntry]:
        """Query log entries."""
        pass

class FileAuditStorage(AuditStorage):
    """Simple file-based storage."""
    
    def __init__(self, filepath: str):
        self.filepath = filepath
    
    def write(self, entry: AuditLogEntry):
        import json
        with open(self.filepath, 'a') as f:
            f.write(json.dumps(entry.__dict__, default=str) + '\n')

class S3AuditStorage(AuditStorage):
    """S3-based storage for scalability."""
    
    def __init__(self, bucket: str, prefix: str = "audit/"):
        self.bucket = bucket
        self.prefix = prefix
```
