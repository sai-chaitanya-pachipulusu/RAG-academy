## The Limitation of Syntax

ALL previous methods use **syntactic rules**:

- Characters, sentences, paragraphs, headers

But meaning doesn't always follow syntax!

```
"The cat sat on the mat. Global warming threatens species."
```

These two sentences have NO syntactic separator indicating a topic change. But semantically, they're completely unrelated.

## The AI Insight

**Embeddings capture meaning**. If we embed consecutive sentences and measure similarity:

- High similarity → Same topic, keep together
- Low similarity → Topic change, place boundary here

## The Algorithm

```python
def semantic_chunk(text, threshold=0.5):
    """
    Chunk text based on semantic similarity between sentences.
    
    Time Complexity: O(S × d²) where S = sentences, d = embedding dim
    Space Complexity: O(S × d) for embeddings
    
    Args:
        text: Input text
        threshold: Similarity threshold for splitting (0-1)
        
    Returns:
        List of semantically coherent chunks
    """
    sentences = split_sentences(text)
    embeddings = [embed(s) for s in sentences]
    
    chunks = []
    current = [sentences[0]]
    
    for i in range(1, len(sentences)):
        similarity = cosine_similarity(embeddings[i-1], embeddings[i])
        
        if similarity < threshold:
            # Topic change - start new chunk
            chunks.append(' '.join(current))
            current = []
        
        current.append(sentences[i])
    
    chunks.append(' '.join(current))
    return chunks
```

## The Power of Similarity

```
Sentence 1: "Machine learning uses neural networks."
Sentence 2: "Deep learning is a subset of ML."
Similarity: 0.85 → Same chunk

Sentence 2: "Deep learning is a subset of ML."
Sentence 3: "The weather in Paris is nice today."
Similarity: 0.12 → NEW CHUNK
```

## Complexity Analysis

| Operation | Time Complexity | Space Complexity |
|-----------|-----------------|------------------|
| Sentence splitting | O(N) | O(S) |
| Embedding | O(S × d²) | O(S × d) |
| Similarity computation | O(S) | O(1) |
| **Total** | **O(S × d²)** | **O(S × d)** |

Where S = sentences, d = embedding dim, N = characters

## Implementation

```python
from typing import List, Callable
import numpy as np

class SemanticChunker:
    """
    Chunk documents based on semantic similarity between sentences.
    
    Places boundaries where topic changes are detected.
    """
    
    def __init__(
        self,
        embed_fn: Callable[[str], np.ndarray],
        threshold: float = 0.5,
        min_chunk_size: int = 2,
        max_chunk_size: int = 10
    ):
        """
        Args:
            embed_fn: Function to embed text
            threshold: Similarity threshold for splitting (0-1)
            min_chunk_size: Minimum sentences per chunk
            max_chunk_size: Maximum sentences per chunk
        """
        self.embed_fn = embed_fn
        self.threshold = threshold
        self.min_chunk_size = min_chunk_size
        self.max_chunk_size = max_chunk_size
    
    def split_sentences(self, text: str) -> List[str]:
        """Split text into sentences."""
        import re
        sentences = re.split(r'(?<=[.!?])\s+', text)
        return [s.strip() for s in sentences if s.strip()]
    
    def cosine_similarity(self, a: np.ndarray, b: np.ndarray) -> float:
        """Compute cosine similarity."""
        return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b) + 1e-8)
    
    def chunk(self, text: str) -> List[str]:
        """
        Chunk text based on semantic similarity.
        
        Algorithm:
        1. Split into sentences
        2. Embed each sentence
        3. Compare consecutive sentences
        4. Split when similarity < threshold
        """
        sentences = self.split_sentences(text)
        
        if not sentences:
            return []
        
        if len(sentences) == 1:
            return sentences
        
        # Embed all sentences
        embeddings = [self.embed_fn(s) for s in sentences]
        
        chunks = []
        current_chunk = [sentences[0]]
        current_size = 1
        
        for i in range(1, len(sentences)):
            # Compute similarity with previous sentence
            similarity = self.cosine_similarity(embeddings[i-1], embeddings[i])
            
            # Decide whether to split
            should_split = (
                similarity < self.threshold and
                current_size >= self.min_chunk_size
            ) or current_size >= self.max_chunk_size
            
            if should_split:
                # Start new chunk
                chunks.append(' '.join(current_chunk))
                current_chunk = [sentences[i]]
                current_size = 1
            else:
                # Add to current chunk
                current_chunk.append(sentences[i])
                current_size += 1
        
        # Add final chunk
        if current_chunk:
            chunks.append(' '.join(current_chunk))
        
        return chunks
```

## ⚖️ Tradeoffs

### Pros

- ✅ Discovers implicit topic boundaries
- ✅ Works on unstructured content
- ✅ 30-50% better retrieval on messy documents

### Cons

- ❌ Requires embedding at chunking time
- ❌ Slower and more expensive
- ❌ Threshold tuning required

## Threshold Tuning

| Threshold | Behavior                        |
| --------- | ------------------------------- |
| 0.3       | Many small chunks (sensitive)   |
| 0.5       | Balanced (default)              |
| 0.7       | Few large chunks (conservative) |

**Tip**: Start at 0.5, adjust based on your content.

## Cost Considerations

For 10,000 sentences:

- **Embedding cost**: ~$0.30 (OpenAI ada-002)
- **Time**: ~30 seconds

This is at chunking time, not query time. Usually acceptable.
