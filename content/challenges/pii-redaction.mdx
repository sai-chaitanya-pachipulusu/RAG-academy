# PII Redaction

<Callout title="Goal" variant="warning">
  Redact common PII patterns from context **before** sending anything to an LLM.
</Callout>

## Why This Matters in Production

Even if a user is authorized, you often need to avoid sending raw PII to third-party model providers like OpenAI, Anthropic, or Google. This is critical for:

| Risk | Consequence | Mitigation |
|------|-------------|------------|
| Data residency violations | Legal penalties | Redact before cross-border transfer |
| Training data contamination | PII in model outputs | Never send raw PII to APIs |
| Insider access | Employee exposure | Tokenization with vault |
| Audit failures | Compliance issues | Immutable redaction logs |

## Theory: Redaction Strategies

### Irreversible Redaction

Simple replacement with no recovery possible:

```python
def irreversible_redact(text: str, entities: List[dict]) -> str:
    """
    Permanently replace PII with [REDACTED:type].
    
    Time: O(n * m) where n=text length, m=entities
    Space: O(n)
    """
    # Sort by position (reverse to maintain indices)
    sorted_entities = sorted(entities, key=lambda x: x['start'], reverse=True)
    
    result = text
    for entity in sorted_entities:
        pii_type = entity['type']
        start, end = entity['start'], entity['end']
        result = result[:start] + f"[REDACTED:{pii_type}]" + result[end:]
    
    return result
```

### Reversible Tokenization

Replace PII with tokens that can be restored:

```python
import hashlib
import secrets
from typing import Dict, Tuple

def reversible_tokenize(
    text: str, 
    entities: List[dict],
    secret_key: str
) -> Tuple[str, Dict[str, str]]:
    """
    Replace PII with reversible tokens.
    
    Returns:
        (tokenized_text, token_map)
    
    Security: Tokens are deterministic for same value, 
    but require secret_key to reverse.
    """
    token_map = {}
    sorted_entities = sorted(entities, key=lambda x: x['start'], reverse=True)
    
    result = text
    for entity in sorted_entities:
        value = entity['value']
        pii_type = entity['type']
        start, end = entity['start'], entity['end']
        
        # Create deterministic token
        token_input = f"{secret_key}:{pii_type}:{value}"
        token = hashlib.sha256(token_input.encode()).hexdigest()[:12]
        token_key = f"[TOKEN:{pii_type}:{token}]"
        
        token_map[token_key] = value
        result = result[:start] + token_key + result[end:]
    
    return result, token_map

def detokenize(text: str, token_map: Dict[str, str]) -> str:
    """Restore original values from tokens."""
    result = text
    for token, value in token_map.items():
        result = result.replace(token, value)
    return result
```

## Example Usage

```python
# Sample document with PII
document = """
Customer Support Request

From: Sarah Johnson <sarah.johnson@company.com>
Phone: (555) 123-4567
SSN: 123-45-6789 for verification

Issue: My account ending in 4532 is locked.
Please call me back ASAP.
"""

# 1. Irreversible redaction (for external LLMs)
result = redact_text(document, RedactionMode.IRREVERSIBLE)
print("Irreversible:")
print(result.text)
# Output: "From: Sarah Johnson <[REDACTED:email]>..."

# 2. Reversible tokenization (for internal use)
pipeline = RedactionPipeline(
    mode=RedactionMode.REVERSIBLE,
    secret_key="my-secret-key-123"
)
result = pipeline.process(
    text=document,
    user_id="agent-001",
    operation="support_ticket"
)
print("\nReversible:")
print(result.text)
print("Token map:", result.token_map)

# Restore original
detokenized = detokenize(result.text, result.token_map)
print("\nRestored:", detokenized[:50])
```
