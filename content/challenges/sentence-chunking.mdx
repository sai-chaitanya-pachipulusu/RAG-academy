## The Problem with Character Chunking

Character-based chunking can split words and sentences in half, destroying semantic coherence:

```
"Dr. Smith works at NASA. He leads the AI team."

# Character split at position 25:
Chunk 1: "Dr. Smith works at NASA."
Chunk 2: " He leads the AI team."
# ✅ Fine - at sentence boundary

# Character split at position 20:
Chunk 1: "Dr. Smith works at N"
Chunk 2: "ASA. He leads the AI team."
# ❌ Broken - split in middle of "NASA"
```

## Theoretical Foundation

### Sentence Boundary Detection

Sentences typically end with punctuation followed by whitespace:
- **Period (.)**: Standard sentence ending
- **Exclamation (!)**: Emphatic ending
- **Question mark (?)**: Interrogative ending

**Edge Cases to Handle**:
- Abbreviations: "Dr.", "Mr.", "e.g.", "i.e."
- Decimal numbers: "3.14", "v2.0"
- Ellipses: "..."
- Quotes: `"He said." She replied.`

### Semantic Coherence

Sentence boundaries align with **propositional boundaries** — discrete units of meaning:

| Chunking Method | Semantic Coherence | Embedding Quality |
|----------------|-------------------|-------------------|
| Character (100) | Low (mid-word splits) | Poor |
| Character (500) | Medium | Fair |
| Sentence (3 sent) | High | Good |
| Paragraph | Very High | Best (if not too long) |

**Trade-off**: Longer chunks = better context, but may exceed token limits.

## Production Implementations

### LlamaIndex SentenceSplitter

```python
from llama_index.core.node_parser import SentenceSplitter

splitter = SentenceSplitter(
    chunk_size=1024,  # Target token size
    chunk_overlap=20,  # Sentence overlap
)
nodes = splitter.get_nodes_from_documents(documents)
```

### LangChain RecursiveCharacterTextSplitter

```python
from langchain.text_splitter import RecursiveCharacterTextSplitter

splitter = RecursiveCharacterTextSplitter(
    separators=["\n\n", "\n", ". ", " ", ""],
    chunk_size=1000,
    chunk_overlap=200,
)
chunks = splitter.split_text(text)
```

### spaCy Sentence Detection

```python
import spacy

nlp = spacy.load("en_core_web_sm")
doc = nlp(text)
sentences = [sent.text for sent in doc.sents]
```

## Advanced Considerations

### Sentence Complexity

Not all sentences are equal:

| Sentence Type | Avg Tokens | Chunking Strategy |
|--------------|------------|-------------------|
| Simple | 10-15 | Group 3-5 sentences |
| Complex | 20-30 | Group 2-3 sentences |
| Technical | 30-50 | Group 1-2 sentences |

### Multi-language Support

Different languages have different sentence structures:

- **English**: Clear punctuation boundaries
- **Chinese**: No spaces, uses punctuation heavily
- **Japanese**: Topic markers (は、が) help identify clauses
- **German**: Long compound sentences common
