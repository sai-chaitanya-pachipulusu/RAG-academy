# RAG Usage Dashboard Metrics

Build metrics collection for a RAG usage dashboard.

## Why This Matters

"What gets measured gets managed." Visibility into cost, latency, and quality enables optimization. Production RAG systems require comprehensive observability to maintain reliability, debug failures, and optimize costs. Without metrics, you're flying blind.

## What You'll Learn

- Metrics aggregation patterns
- Percentile calculations (P50, P95, P99)
- Cost estimation and tracking
- Time-series analysis
- Health check implementation

## Real-World Application

**Companies:** Datadog, New Relic, Langfuse, Helicone
**Use Cases:**
- Cost optimization and budgeting
- Performance monitoring and alerting
- SLA tracking and compliance
- Capacity planning
- Debugging production issues

## The Seven Golden Signals of RAG

| Signal | Metric | Target | Alert Threshold |
|--------|--------|--------|-----------------|
| **Latency** | End-to-end response time | < 2s | P95 > 3s |
| **Traffic** | Queries per minute (QPM) | — | Spike detection |
| **Errors** | Failure rate | < 1% | > 5% |
| **Saturation** | Queue depth | < 10 | > 50 |
| **Cost** | $ per 1K queries | < $10 | > $20 |
| **Quality** | Answer relevance score | > 0.8 | < 0.6 |
| **Coverage** | Retrieved doc recall | > 0.7 | < 0.5 |

### Rolling Time Windows

```python
from collections import deque
import time

class RollingWindowMetrics:
    """Metrics aggregated over a rolling time window."""
    
    def __init__(self, window_seconds: float = 300.0):
        self.window_seconds = window_seconds
        self.metrics: deque = deque()
    
    def add(self, metric: RAGMetrics):
        """Add a metric and remove expired ones."""
        now = time.time()
        cutoff = now - self.window_seconds
        
        # Remove expired metrics
        while self.metrics and self.metrics[0].timestamp < cutoff:
            self.metrics.popleft()
        
        self.metrics.append(metric)
    
    def get_summary(self) -> Dict:
        """Get aggregated statistics."""
        if not self.metrics:
            return {}
        
        latencies = [m.total_latency_ms for m in self.metrics]
        costs = [m.estimated_cost_usd for m in self.metrics]
        
        return {
            "count": len(self.metrics),
            "avg_latency_ms": sum(latencies) / len(latencies),
            "p50_latency_ms": self._percentile(latencies, 50),
            "p95_latency_ms": self._percentile(latencies, 95),
            "p99_latency_ms": self._percentile(latencies, 99),
            "total_cost_usd": sum(costs),
            "error_rate": sum(1 for m in self.metrics if not m.success) / len(self.metrics),
        }
    
    @staticmethod
    def _percentile(values: List[float], p: float) -> float:
        """Calculate percentile using nearest-rank method."""
        if not values:
            return 0.0
        sorted_vals = sorted(values)
        k = (len(sorted_vals) - 1) * p / 100
        f = int(k)
        c = f + 1 if f + 1 < len(sorted_vals) else f
        return sorted_vals[f] + (k - f) * (sorted_vals[c] - sorted_vals[f])
```

## Summary Statistics

Key metrics to track:

| Metric | Formula | Why It Matters |
|--------|---------|----------------|
| Total requests | `count(metrics)` | Traffic volume |
| Success rate | `successes / total` | Reliability |
| Avg/P95 latency | Percentile(latencies) | User experience |
| Token usage | `sum(tokens)` | Cost tracking |
| Estimated cost | `calculated from tokens` | Budget management |

### Percentile Calculation

```python
def calculate_percentiles(values: List[float]) -> Dict[str, float]:
    """Calculate key percentiles for latency distribution."""
    if not values:
        return {}
    
    sorted_vals = sorted(values)
    n = len(sorted_vals)
    
    def percentile(p: float) -> float:
        """Nearest-rank percentile."""
        idx = int((p / 100) * (n - 1))
        return sorted_vals[idx]
    
    return {
        "p50": percentile(50),  # Median
        "p90": percentile(90),  # 90% of queries
        "p95": percentile(95),  # 95% of queries
        "p99": percentile(99),  # Worst 1%
        "min": sorted_vals[0],
        "max": sorted_vals[-1],
    }
```
