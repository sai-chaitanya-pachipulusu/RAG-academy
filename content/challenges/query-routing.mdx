# Query Routing

**Difficulty**: Tier 3 - Post-Retrieval  
**Prerequisites**: Intent Classification, Multiple Retrievers  
**Time Estimate**: 4-5 hours

## Objective

Implement intelligent query routing to direct queries to the optimal retrieval pipeline based on query characteristics, improving both efficiency and answer quality.

## Purpose

Not all queries need the same retrieval approach. Routing directs queries to specialized pipelines—structured DB for entity lookups, vector search for semantic queries, web search for real-time info—maximizing efficiency and accuracy.

### Real-World Impact
- **Enterprise search**: 40% latency reduction by routing to appropriate index
- **Customer support**: Entity queries → CRM, how-to → knowledge base
- **Research platforms**: Academic papers vs. web sources
- **E-commerce**: Product search vs. FAQ vs. reviews

## The Problem

**One-Size-Fits-All Issues:**

| Query Type | Wrong Approach | Problem |
|------------|---------------|---------|
| "What is account #12345?" | Vector search | Imprecise, slow |
| "Explain machine learning" | Exact match | No results |
| "Latest news on Acme" | Static index | Stale information |
| "Hi, how are you?" | Full retrieval | Wasted compute |

**Query Routing Solution:**
```
Query → Classify → Route → Retrieve → Generate
         │           │
         ▼           ▼
    "Entity"    →  SQL Database
    "Concept"   →  Vector Store
    "Realtime"  →  Web Search
    "Chitchat"  →  No retrieval
```

### Router Types

**1. LLM-Based Router**
- Pros: Flexible, handles novel queries
- Cons: Latency, cost
- Best for: Complex classification, low volume

**2. Classifier-Based Router**
- Pros: Fast, cheap, deterministic
- Cons: Requires training data
- Best for: High volume, stable query patterns

**3. Semantic Router**
- Pros: No training required, intuitive
- Cons: Requires good examples
- Best for: Medium volume, clear categories

**4. Rule-Based Router**
- Pros: Fastest, fully deterministic
- Cons: Brittle, requires maintenance
- Best for: Clear patterns, edge cases

## Challenges

### Challenge 1: Rule-Based Router

Implement pattern-based routing.

**Acceptance Criteria:**
- Route entity queries (IDs, emails) to SQL
- Route "how to" queries to knowledge base
- Route "latest/current" to web search
- Handle greetings without retrieval
- > 80% accuracy on test set

**Example Patterns:**
```python
ROUTING_RULES = [
    # Entity patterns
    (r'\b\d{4,}\b', 'sql'),  # Account numbers
    (r'[\w.-]+@[\w.-]+', 'sql'),  # Emails
    
    # Procedural patterns
    (r'^(how (do|can|to)|steps?\s+(to|for))', 'knowledge_base'),
    
    # Realtime patterns
    (r'\b(latest|current|today|now|recent)\b', 'web_search'),
    
    # Conversational
    (r'^(hi|hello|hey|how are you)\b', 'no_retrieval'),
]
```

### Challenge 2: Semantic Router

Route based on similarity to example queries.

**Acceptance Criteria:**
- Embed query and example queries
- Route to category with highest max similarity
- Configurable similarity threshold
- Handle "unknown" when below threshold
- > 85% accuracy on test set

**Implementation:**
```python
class SemanticRouter:
    def __init__(self, embedder):
        self.embedder = embedder
        self.routes = {}  # route_name -> example embeddings
        
    def add_route(self, name: str, examples: List[str]):
        embeddings = self.embedder.encode(examples)
        self.routes[name] = embeddings
        
    def route(self, query: str, threshold: float = 0.5) -> Tuple[str, float]:
        query_emb = self.embedder.encode([query])[0]
        
        best_route = None
        best_score = threshold
        
        for route_name, embeddings in self.routes.items():
            similarities = query_emb @ embeddings.T
            max_sim = similarities.max()
            
            if max_sim > best_score:
                best_score = max_sim
                best_route = route_name
                
        return best_route or 'unknown', best_score
```

### Challenge 3: Hybrid Router

Combine multiple routing strategies.

**Acceptance Criteria:**
- Rule-based for clear patterns (fast path)
- Semantic for ambiguous queries
- LLM for edge cases
- Confidence-based fallback chain
- > 90% accuracy on test set

**Cascade:**
```
Query → Rules (confidence > 0.9) → Route
    ↓
    Semantic (confidence > 0.8) → Route
    ↓
    LLM (always) → Route
```

## Starter Code

```python
from typing import List, Dict, Tuple, Optional, Callable
from dataclasses import dataclass
from enum import Enum
import re
import numpy as np

class QueryCategory(Enum):
    ENTITY = "entity"
    FACTUAL = "factual"
    ANALYTICAL = "analytical"
    PROCEDURAL = "procedural"
    REALTIME = "realtime"
    CONVERSATIONAL = "conversational"
    UNKNOWN = "unknown"

@dataclass
class RouteResult:
    """Result of query routing."""
    category: QueryCategory
    confidence: float
    method: str
    metadata: Dict

class QueryRouter:
    """Base class for query routers."""
    
    def route(self, query: str) -> RouteResult:
        raise NotImplementedError

class RuleBasedRouter(QueryRouter):
    """Route based on regex patterns."""
    
    def __init__(self):
        self.rules = [
            # Entity patterns
            (r'\b\d{6,}\b', QueryCategory.ENTITY, 0.9),  # Account numbers
            (r'[\w.-]+@[\w.-]+\.\w+', QueryCategory.ENTITY, 0.95),  # Emails
            (r'\b[A-Z]{2,6}-\d{3,}\b', QueryCategory.ENTITY, 0.9),  # Ticket IDs
            
            # Procedural patterns
            (r'^(how (do|can|to)|steps?\s+(to|for)|guide\s+to)\b', 
             QueryCategory.PROCEDURAL, 0.85),
            
            # Realtime patterns
            (r'\b(latest|current|today|now|recent|news|update)\b', 
             QueryCategory.REALTIME, 0.8),
            
            # Analytical patterns
            (r'\b(compare|vs|versus|difference|better|best|analysis)\b',
             QueryCategory.ANALYTICAL, 0.75),
            
            # Conversational
            (r'^(hi|hello|hey|how are you|good morning|good afternoon)\b',
             QueryCategory.CONVERSATIONAL, 0.95),
            
            # Factual (default)
            (r'\b(what|who|when|where|why|explain|define)\b',
             QueryCategory.FACTUAL, 0.6),
        ]
        
    def route(self, query: str) -> RouteResult:
        """Route based on first matching rule."""
        query_lower = query.lower()
        
        for pattern, category, confidence in self.rules:
            if re.search(pattern, query_lower):
                return RouteResult(
                    category=category,
                    confidence=confidence,
                    method='rule_based',
                    metadata={'matched_pattern': pattern}
                )
                
        return RouteResult(
            category=QueryCategory.UNKNOWN,
            confidence=0.0,
            method='rule_based',
            metadata={'matched_pattern': None}
        )

class SemanticRouter(QueryRouter):
    """Route based on semantic similarity to examples."""
    
    def __init__(self, embedder, threshold: float = 0.5):
        self.embedder = embedder
        self.threshold = threshold
        self.routes: Dict[QueryCategory, np.ndarray] = {}
        
    def add_examples(self, category: QueryCategory, 
                    examples: List[str]):
        """Add example queries for a category."""
        embeddings = self.embedder.encode(examples)
        self.routes[category] = embeddings
        
    def route(self, query: str) -> RouteResult:
        """Route to category with highest similarity."""
        query_emb = self.embedder.encode([query])[0]
        
        best_category = QueryCategory.UNKNOWN
        best_score = self.threshold
        all_scores = {}
        
        for category, embeddings in self.routes.items():
            similarities = np.dot(embeddings, query_emb)
            max_sim = float(np.max(similarities))
            all_scores[category.value] = max_sim
            
            if max_sim > best_score:
                best_score = max_sim
                best_category = category
                
        return RouteResult(
            category=best_category,
            confidence=best_score,
            method='semantic',
            metadata={'all_scores': all_scores}
        )

class LLMRouter(QueryRouter):
    """Route using LLM classification."""
    
    def __init__(self, llm_client, model: str = "gpt-3.5-turbo"):
        self.llm = llm_client
        self.model = model
        
    def route(self, query: str) -> RouteResult:
        """Use LLM to classify query."""
        prompt = f"""Classify this query into exactly one category:

Categories:
- ENTITY: Specific entities, IDs, account numbers
- FACTUAL: Definitions, explanations, known facts
- ANALYTICAL: Comparisons, analysis, reasoning
- PROCEDURAL: How-to, step-by-step instructions
- REALTIME: Current events, latest information
- CONVERSATIONAL: Greetings, chitchat, no info needed

Query: {query}

Respond with only the category name:"""

        try:
            response = self.llm.chat.completions.create(
                model=self.model,
                messages=[{"role": "user", "content": prompt}],
                temperature=0.0,
                max_tokens=20
            )
            
            category_str = response.choices[0].message.content.strip().upper()
            
            # Parse category
            try:
                category = QueryCategory[category_str]
                confidence = 0.9  # LLM is generally confident
            except KeyError:
                category = QueryCategory.UNKNOWN
                confidence = 0.0
                
            return RouteResult(
                category=category,
                confidence=confidence,
                method='llm',
                metadata={'raw_response': category_str}
            )
            
        except Exception as e:
            return RouteResult(
                category=QueryCategory.UNKNOWN,
                confidence=0.0,
                method='llm_failed',
                metadata={'error': str(e)}
            )

class HybridRouter(QueryRouter):
    """Combine multiple routing strategies."""
    
    def __init__(self,
                 rule_router: RuleBasedRouter = None,
                 semantic_router: SemanticRouter = None,
                 llm_router: LLMRouter = None):
        self.rule_router = rule_router or RuleBasedRouter()
        self.semantic_router = semantic_router
        self.llm_router = llm_router
        
    def route(self, query: str, 
             use_llm: bool = True) -> RouteResult:
        """
        Route with cascading fallback.
        
        1. Try rule-based (fastest)
        2. Try semantic if available
        3. Fall back to LLM if needed
        """
        # Stage 1: Rule-based
        result = self.rule_router.route(query)
        if result.confidence >= 0.9:
            return result
            
        # Stage 2: Semantic
        if self.semantic_router:
            semantic_result = self.semantic_router.route(query)
            if semantic_result.confidence >= 0.8:
                return semantic_result
                
        # Stage 3: LLM
        if use_llm and self.llm_router:
            return self.llm_router.route(query)
            
        # Return best non-LLM result
        if self.semantic_router:
            semantic = self.semantic_router.route(query)
            if semantic.confidence > result.confidence:
                return semantic
                
        return result

class RoutedRAGSystem:
    """RAG system with query routing."""
    
    def __init__(self, router: QueryRouter):
        self.router = router
        self.retrievers = {}
        
    def add_retriever(self, category: QueryCategory, 
                     retriever: Callable):
        """Register retriever for a category."""
        self.retrievers[category] = retriever
        
    def query(self, query: str) -> Dict:
        """
        Execute routed query.
        """
        # Route query
        route_result = self.router.route(query)
        
        # Get appropriate retriever
        retriever = self.retrievers.get(route_result.category)
        
        if retriever is None:
            # Default to vector search
            retriever = self.retrievers.get(QueryCategory.FACTUAL)
            
        # Execute retrieval
        if route_result.category == QueryCategory.CONVERSATIONAL:
            # No retrieval needed
            context = []
        else:
            context = retriever(query)
            
        return {
            'query': query,
            'route': route_result,
            'context': context,
        }
```

## Advanced Techniques

### 1. Multi-Route Retrieval

Retrieve from multiple sources and fuse:

```python
def multi_route_retrieve(query: str, 
                        routes: List[QueryCategory],
                        weights: Dict[QueryCategory, float]) -> List:
    """
    Retrieve from multiple routes and combine results.
    """
    all_results = []
    
    for route in routes:
        retriever = self.retrievers[route]
        results = retriever(query)
        
        # Apply route weight
        weight = weights.get(route, 1.0)
        for r in results:
            r['score'] *= weight
            r['source_route'] = route
            
        all_results.extend(results)
    
    # Re-rank combined results
    all_results.sort(key=lambda x: x['score'], reverse=True)
    return all_results[:10]
```

### 2. Adaptive Routing

Learn optimal routes from feedback:

```python
class AdaptiveRouter:
    def __init__(self, base_router):
        self.base_router = base_router
        self.route_performance = defaultdict(lambda: {'success': 0, 'total': 0})
        
    def update_performance(self, query: str, route: str, success: bool):
        """Update route performance metrics."""
        self.route_performance[route]['total'] += 1
        if success:
            self.route_performance[route]['success'] += 1
            
    def get_best_route(self, query: str) -> str:
        """Select route with best historical performance."""
        candidates = self.base_router.get_candidate_routes(query)
        
        best_route = None
        best_rate = 0
        
        for route in candidates:
            stats = self.route_performance[route]
            if stats['total'] > 0:
                success_rate = stats['success'] / stats['total']
                if success_rate > best_rate:
                    best_rate = success_rate
                    best_route = route
                    
        return best_route or candidates[0]
```

```python
def decompose_and_route(query: str) -> List[RouteResult]:
    """
    Break complex query into parts and route each.
    
    "Compare Apple and Microsoft earnings in 2024"
    → ["Apple earnings 2024", "Microsoft earnings 2024", "comparison"]
    """
    # Extract entities
    entities = extract_entities(query)
    
    if len(entities) > 1 and 'compare' in query.lower():
        # Create sub-queries
        sub_queries = [f"{entity} earnings 2024" for entity in entities]
        
        # Route each
        results = []
        for sq in sub_queries:
            results.append(router.route(sq))
            
        return results
    else:
        return [router.route(query)]
```

### 2. A/B Testing Routes

```python
class RouteABTest:
    def __init__(self, variant_a: QueryRouter, variant_b: QueryRouter):
        self.variants = {'A': variant_a, 'B': variant_b}
        
    def route(self, query: str) -> Tuple[RouteResult, str]:
        """Route with variant assignment."""
        variant = 'A' if hash(query) % 2 == 0 else 'B'
        result = self.variants[variant].route(query)
        return result, variant
        
    def log_outcome(self, variant: str, query: str, 
                   success: bool, latency: float):
        """Log for comparison."""
        metrics.counter(f'route_{variant}.query')
        if success:
            metrics.counter(f'route_{variant}.success')
        metrics.histogram(f'route_{variant}.latency', latency)
```

### 3. Fallback Chain

```python
def route_with_fallback(query: str) -> RouteResult:
    """
    Try multiple routing strategies with fallback.
    """
    # Try fast rule-based
    result = rule_router.route(query)
    if result.confidence > 0.8:
        return result
        
    # Try semantic
    result = semantic_router.route(query)
    if result.confidence > 0.7:
        return result
        
    # Fall back to LLM
    return llm_router.route(query)
```
