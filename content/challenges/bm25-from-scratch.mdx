## Why this matters in production

Dense embeddings are great for semantics, but they routinely miss:

- acronyms and abbreviations (API, SDK, RAG)
- IDs (`api_key`, SKU numbers, invoice IDs, UUIDs)
- exact phrases and proper nouns
- rare domain terminology

BM25 (sparse retrieval) is the "boring baseline" that keeps production systems honest.

## Algorithm Overview

### Offline (Indexing)

1. **Tokenize** all documents
2. Compute **df(t)** — document frequency for each token (how many docs contain it)
3. Compute **avgdl** — average document length across corpus
4. Store the inverted index: token → list of (doc_id, tf)

### Online (Query Time)

1. **Tokenize** the query
2. For each doc, compute BM25 score using the formula below
3. Return top-k candidates

## The Algorithm

```python
import math
from collections import defaultdict
from typing import List, Dict, Tuple

class BM25Index:
    """
    BM25 sparse retrieval index.
    
    Time Complexity:
    - Indexing: O(N × avg_doc_length) to tokenize and build inverted index
    - Search: O(|Q| × avg_df) where |Q| = query terms, avg_df = avg document frequency
    
    Space Complexity: O(V + N × avg_doc_length) where V = vocabulary size
    """
    
    def __init__(self, k1: float = 1.5, b: float = 0.75):
        """
        Args:
            k1: Term frequency saturation (1.2-2.0)
            b: Length normalization (0.0-1.0)
        """
        self.k1 = k1
        self.b = b
        
        self.documents = {}
        self.doc_lengths = {}
        self.inverted_index = defaultdict(list)  # term -> [(doc_id, tf)]
        self.doc_freqs = defaultdict(int)  # term -> df
        self.avgdl = 0.0
        self.N = 0
    
    def _tokenize(self, text: str) -> List[str]:
        """Simple tokenization (can be replaced with better tokenizer)."""
        return text.lower().split()
    
    def add_document(self, doc_id: int, text: str):
        """Add a document to the index."""
        tokens = self._tokenize(text)
        self.documents[doc_id] = text
        self.doc_lengths[doc_id] = len(tokens)
        
        # Count term frequencies
        tf = defaultdict(int)
        for token in tokens:
            tf[token] += 1
        
        # Update inverted index
        for token, count in tf.items():
            self.inverted_index[token].append((doc_id, count))
            self.doc_freqs[token] += 1
        
        # Update stats
        self.N += 1
        self.avgdl = sum(self.doc_lengths.values()) / self.N
    
    def _idf(self, term: str) -> float:
        """
        Compute IDF with smoothing.
        
        IDF(t) = ln(1 + (N - df(t) + 0.5) / (df(t) + 0.5))
        """
        df = self.doc_freqs.get(term, 0)
        if df == 0:
            return 0.0
        return math.log(1 + (self.N - df + 0.5) / (df + 0.5))
    
    def _score_document(self, doc_id: int, query_terms: List[str]) -> float:
        """
        Compute BM25 score for a document.
        
        Score = Σ IDF(t) × (tf × (k1 + 1)) / (tf + k1 × (1 - b + b × |d|/avgdl))
        """
        score = 0.0
        doc_len = self.doc_lengths[doc_id]
        
        # Build tf dict for this document
        doc_tf = defaultdict(int)
        for term, tf in self.inverted_index.items():
            for d, count in tf:
                if d == doc_id:
                    doc_tf[term] = count
        
        for term in query_terms:
            tf = doc_tf.get(term, 0)
            if tf == 0:
                continue
            
            idf = self._idf(term)
            
            # Length normalization
            norm = 1 - self.b + self.b * (doc_len / self.avgdl)
            
            # TF saturation
            tf_component = (tf * (self.k1 + 1)) / (tf + self.k1 * norm)
            
            score += idf * tf_component
        
        return score
    
    def search(self, query: str, k: int = 10) -> List[Tuple[int, float]]:
        """
        Search for top-k documents.
        
        Time Complexity: O(|Q| × avg_df × scoring_cost)
        """
        query_terms = self._tokenize(query)
        
        # Find candidate documents (union of docs containing any query term)
        candidates = set()
        for term in query_terms:
            for doc_id, _ in self.inverted_index.get(term, []):
                candidates.add(doc_id)
        
        # Score candidates
        scores = []
        for doc_id in candidates:
            score = self._score_document(doc_id, query_terms)
            scores.append((doc_id, score))
        
        # Return top k
        scores.sort(key=lambda x: x[1], reverse=True)
        return scores[:k]
```

## Complexity Analysis

| Aspect | Complexity | Notes |
|--------|------------|-------|
| Indexing | O(N × L) | N docs, L avg length |
| Search | O(\|Q\| × D) | Q query terms, D avg df |
| Space | O(V + N × L) | V vocabulary size |
| Recall | High | Exact term matching |

## The BM25 Formula

### IDF (Inverse Document Frequency)

This version is the **Robertson-Sparck Jones IDF** with +0.5 smoothing (stable, commonly used):

$$
\text{idf}(t) = \ln\left(1 + \frac{N - \text{df}(t) + 0.5}{\text{df}(t) + 0.5}\right)
$$

Where:

- `N` = total number of documents
- `df(t)` = number of documents containing term `t`

### Term Frequency + Length Normalization

$$
\text{BM25}(q, d) = \sum_{t \in q} \text{idf}(t) \cdot \frac{\text{tf} \cdot (k_1 + 1)}{\text{tf} + k_1 \cdot \left(1 - b + b \cdot \frac{|d|}{\text{avgdl}}\right)}
$$

Where:

- `tf` = frequency of term t in document d
- `|d|` = document length (token count)
- `avgdl` = average document length
- `k1` = term frequency saturation (default: 1.2-2.0)
- `b` = length normalization (default: 0.75)

## Parameter Tuning Guide

| Parameter | Range   | Effect                                   |
| --------- | ------- | ---------------------------------------- |
| **k1**    | 1.2-2.0 | Higher = more weight to repeated terms   |
| **b**     | 0.0-1.0 | Higher = more penalty for long documents |

**Defaults**: `k1=1.5, b=0.75` work well for most corpora.

## Edge Cases (Critical)

| Scenario                 | Handling                                            |
| ------------------------ | --------------------------------------------------- |
| Query term not in corpus | Contributes 0 to score (IDF undefined → treat as 0) |
| Empty document           | Score = 0 (no terms to match)                       |
| Empty query              | Return empty results                                |
| All docs same length     | Length normalization has no effect (b irrelevant)   |
| Single-word docs         | Can have inflated scores (tune b lower)             |
| Very rare terms          | High IDF, but not infinite (smoothing handles it)   |
| Stop words               | Often removed, but BM25 handles them gracefully     |
