# Financial Analyst Agent

Build an agentic RAG system that can analyze financial data, retrieve market information, and generate investment insights.

## Requirements

1. Parse financial documents (10-K, earnings reports)
2. Retrieve relevant market data
3. Calculate financial metrics
4. Generate analysis with citations
