## Project Overview

Financial analysis requires synthesizing multiple data types:
- **Quantitative data**: Prices, volumes, market cap, ratios
- **Qualitative data**: Analyst notes, news sentiment, market trends
- **Historical context**: Past performance, similar patterns

This project builds an agent that mimics how professional analysts work—gathering data from multiple sources and synthesizing actionable insights.

### What You'll Build

A Crypto Analyst Agent that:
1. **Fetches live market data** (prices, trading volumes)
2. **Retrieves analyst research** from a knowledge base
3. **Performs multi-step reasoning** to connect data points
4. **Generates structured analysis** with confidence scores
5. **Provides cited recommendations** (buy/hold/sell)

```python
def get_price(ticker: str) -> dict:
    """
    Fetch current market data for a cryptocurrency.
    
    In production, this would call:
    - CoinGecko API (free tier available)
    - CoinMarketCap API
    - Binance/FTX exchange APIs
    - Bloomberg Terminal API (institutional)
    
    Args:
        ticker: Cryptocurrency symbol (BTC, ETH, etc.)
        
    Returns:
        Dictionary with price, volume, and market data
    """
    data = MARKET_DATA.get(ticker.upper())
    if not data:
        return {"error": f"No data available for {ticker}"}
    return {
        "ticker": ticker.upper(),
        "price": data["price"],
        "change_24h": data["change_24h"],
        "volume_24h": data["volume_24h"],
        "market_cap": data["market_cap"],
    }

def retrieve_notes(ticker: str) -> list:
    """
    Retrieve analyst research notes for a cryptocurrency.
    
    In production, this would query:
    - Vector database of research reports
    - Internal analyst notes
    - SEC filings (for stocks)
    - News sentiment analysis
    
    Args:
        ticker: Cryptocurrency symbol
        
    Returns:
        List of relevant research notes
    """
    return [n for n in RESEARCH_DB if n["ticker"] == ticker.upper()]

def calculate_metrics(price_data: dict) -> dict:
    """
    Calculate derived metrics from price data.
    
    Args:
        price_data: Raw market data
        
    Returns:
        Dictionary with calculated metrics
    """
    price = price_data.get("price", 0)
    volume = price_data.get("volume_24h", 0)
    market_cap = price_data.get("market_cap", 1)
    
    return {
        "volume_to_mcap_ratio": volume / market_cap,
        "price_change_pct": price_data.get("change_24h", 0),
        "is_positive_change": price_data.get("change_24h", 0) > 0,
    }
```

### The Analysis Agent

```python
def crypto_analysis(ticker: str) -> dict:
    """
    Generate comprehensive crypto analysis combining market data and research.
    
    This is a multi-step agent that:
    1. Fetches current market data
    2. Retrieves relevant analyst notes
    3. Calculates derived metrics
    4. Synthesizes an investment thesis
    5. Assigns confidence and recommendation
    
    Args:
        ticker: Cryptocurrency symbol to analyze
        
    Returns:
        Structured analysis with thesis, confidence, and sources
    """
    # Step 1: Fetch market data
    market_data = get_price(ticker)
    if "error" in market_data:
        return {
            "analysis": f"Unable to analyze {ticker}: {market_data['error']}",
            "confidence": 0.0,
            "recommendation": "unknown",
            "sources": []
        }
    
    # Step 2: Retrieve research notes
    notes = retrieve_notes(ticker)
    
    # Step 3: Calculate metrics
    metrics = calculate_metrics(market_data)
    
    # Step 4: Synthesize analysis
    price = market_data["price"]
    price_str = f"Current {ticker.upper()} price: ${price:,}"
    
    # Build analysis based on available data
    analysis_parts = [price_str]
    
    if notes:
        # Combine analyst insights
        note_texts = [n["note"] for n in notes]
        analysis_parts.append("Analyst perspective: " + " ".join(note_texts))
        
        # Determine sentiment from notes
        sentiments = [n["sentiment"] for n in notes]
        dominant_sentiment = max(set(sentiments), key=sentiments.count)
    else:
        dominant_sentiment = "neutral"
    
    # Add metric-based observations
    if metrics["is_positive_change"]:
        analysis_parts.append(f"Up {metrics['price_change_pct']}% in the last 24h.")
    else:
        analysis_parts.append(f"Down {abs(metrics['price_change_pct'])}% in the last 24h.")
    
    # Step 5: Generate recommendation
    recommendation = generate_recommendation(dominant_sentiment, metrics)
    
    # Step 6: Calculate confidence
    confidence = calculate_confidence(notes, market_data)
    
    return {
        "analysis": " ".join(analysis_parts),
        "metrics": metrics,
        "recommendation": recommendation,
        "confidence": confidence,
        "sources": ["Market Data API"] + [f"Analyst Note: {n['date']}" for n in notes]
    }

def generate_recommendation(sentiment: str, metrics: dict) -> str:
    """Generate buy/hold/sell recommendation based on analysis."""
    if sentiment == "bullish" and metrics["is_positive_change"]:
        return "buy"
    elif sentiment == "bearish" and not metrics["is_positive_change"]:
        return "sell"
    else:
        return "hold"

def calculate_confidence(notes: list, market_data: dict) -> float:
    """Calculate confidence score based on data quality and quantity."""
    base_confidence = 0.5
    
    # Increase confidence with more research
    if len(notes) > 0:
        base_confidence += 0.1 * min(len(notes), 3)
    
    # Increase confidence if we have full market data
    if all(k in market_data for k in ["price", "volume_24h", "change_24h"]):
        base_confidence += 0.2
    
    return min(base_confidence, 0.95)
```

### Risk Management & Compliance

```python
class FinancialAnalysisGuardrails:
    """Safety checks for financial analysis."""
    
    def validate_analysis(self, analysis: dict) -> tuple[bool, str]:
        """
        Ensure analysis meets compliance requirements.
        
        Returns:
            (is_valid, reason_if_invalid)
        """
        # Check confidence threshold
        if analysis["confidence"] < 0.3:
            return False, "Confidence too low for recommendation"
        
        # Ensure proper disclaimer
        if "not financial advice" not in analysis["analysis"].lower():
            analysis["analysis"] += "\n\nDisclaimer: This is not financial advice."
        
        # Verify sources are cited
        if not analysis.get("sources"):
            return False, "Analysis must cite sources"
        
        return True, ""
    
    def add_disclaimer(self, analysis: str) -> str:
        """Add required regulatory disclaimer."""
        disclaimer = """
        \n\n---
        **Disclaimer**: This analysis is for informational purposes only and does not 
        constitute financial advice. Cryptocurrency investments carry significant risk 
        including potential loss of capital. Past performance does not guarantee future 
        results. Consult a qualified financial advisor before making investment decisions.
        """
        return analysis + disclaimer
```

class Backtester:
    """Validate analysis quality against historical data."""
    
    def backtest_strategy(self, ticker: str, start_date: str, end_date: str) -> dict:
        """
        Test analysis accuracy on historical data.
        
        Returns:
            Performance metrics for the strategy
        """
        historical_data = self.load_historical_data(ticker, start_date, end_date)
        
        correct_predictions = 0
        total_predictions = 0
        
        for day in historical_data:
            # Simulate analysis as of this day
            analysis = self.simulate_analysis(ticker, day["date"])
            
            # Check if recommendation was correct
            actual_return = day["next_day_return"]
            recommendation = analysis["recommendation"]
            
            if (recommendation == "buy" and actual_return > 0) or \
               (recommendation == "sell" and actual_return < 0) or \
               (recommendation == "hold"):
                correct_predictions += 1
            
            total_predictions += 1
        
        accuracy = correct_predictions / total_predictions if total_predictions > 0 else 0
        
        return {
            "accuracy": accuracy,
            "total_predictions": total_predictions,
            "sharpe_ratio": self.calculate_sharpe(historical_data)
        }

## Common Pitfalls

1. **Overfitting to Recent Data**
   - ❌ Making predictions based solely on 24h price action
   - ✅ Consider multiple timeframes and fundamental factors

2. **Ignoring Risk**
   - ❌ Providing recommendations without risk assessment
   - ✅ Always include volatility metrics and downside scenarios

3. **Hallucinating Data**
   - ❌ Making up price targets or analyst opinions
   - ✅ Only use retrieved data with proper attribution

4. **Missing Disclaimers**
   - ❌ Presenting analysis as definitive advice
   - ✅ Include regulatory disclaimers and risk warnings

5. **Stale Data**
   - ❌ Using cached prices without freshness checks
   - ✅ Implement real-time feeds with staleness detection
