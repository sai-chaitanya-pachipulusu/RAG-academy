# Knowledge Graph Extraction

Build the foundation of Graph RAG by extracting knowledge graph triples from text documents, enabling multi-hop reasoning and relationship discovery.

## Problem Statement

You're building a Graph RAG system that can answer complex questions like:

- "How are these two research topics connected?"
- "What patterns exist across our customer feedback?"
- "Which team dependencies create project risks?"

Traditional RAG retrieves similar documents. Graph RAG understands **relationships**.

Your first step: Extract structured knowledge (entities and relationships) from unstructured text.

## Your Task

Implement a `KnowledgeGraphExtractor` class that:

1. Extracts **entities** (people, organizations, concepts, products, etc.)
2. Identifies **relationships** between entities
3. Produces **(Subject, Predicate, Object)** triples

```python
import re
from collections import defaultdict

class KnowledgeGraphExtractor:
    def __init__(self):
        self.entity_patterns = {
            "PERSON": [
                r'\b([A-Z][a-z]+(?:\s+[A-Z][a-z]+)+)\b'
            ],
            "ORG": [
                r'\b(OpenAI|Microsoft|Google|Amazon|Meta|Anthropic)\b',
                r'the\s+([A-Z][a-z]+(?:\s+(?:team|group|department|company))?)',
            ],
            "PRODUCT": [
                r'\b(ChatGPT|GPT-\d+|Claude|Gemini|DALL-E)\b'
            ]
        }

        self.relation_patterns = [
            (r'([A-Z][a-z]+(?:\s+[A-Z][a-z]+)?)\s+works?\s+(?:at|for)\s+(\w+)', 'works_at'),
            (r'([A-Z][a-z]+(?:\s+[A-Z][a-z]+)?)\s+leads?\s+(?:the\s+)?(.+?team)', 'leads'),
            (r'([A-Z][a-z]+(?:\s+[A-Z][a-z]+)?)\s+from\s+(\w+)', 'works_at'),
            (r'(.+?team)\s+(?:recently\s+)?launched\s+(\w+)', 'launched'),
            (r'(\w+)\s+collaborates?\s+with\s+([A-Z][a-z]+)', 'collaborates_with'),
        ]

    def extract_entities(self, text: str) -> list[dict]:
        entities = []
        seen = set()

        for entity_type, patterns in self.entity_patterns.items():
            for pattern in patterns:
                matches = re.findall(pattern, text, re.IGNORECASE)
                for match in matches:
                    name = match if isinstance(match, str) else match
                    name = name.strip()
                    normalized = self.normalize_entity(name)

                    if normalized and normalized not in seen:
                        entities.append({"name": name, "type": entity_type})
                        seen.add(normalized)

        return entities

    def extract_triples(self, text: str) -> list[tuple[str, str, str]]:
        triples = []
        seen = set()

        for pattern, predicate in self.relation_patterns:
            matches = re.finditer(pattern, text, re.IGNORECASE)
            for match in matches:
                groups = match.groups()
                if len(groups) >= 2:
                    subject = groups[0].strip()
                    obj = groups[1].strip()

                    triple_key = (self.normalize_entity(subject),
                                  predicate,
                                  self.normalize_entity(obj))

                    if triple_key not in seen:
                        triples.append((subject, predicate, obj))
                        seen.add(triple_key)

        return triples

    def normalize_entity(self, entity: str) -> str:
        if not entity:
            return ""
        # Lowercase, strip whitespace, remove extra spaces
        normalized = " ".join(entity.lower().split())
        return normalized

    def build_graph(self, documents: list[str]) -> dict:
        all_nodes = {}
        all_edges = []
        edge_set = set()

        for doc in documents:
            # Extract and add entities as nodes
            for entity in self.extract_entities(doc):
                normalized = self.normalize_entity(entity["name"])
                if normalized not in all_nodes:
                    all_nodes[normalized] = {
                        "id": entity["name"],
                        "normalized_id": normalized,
                        "type": entity["type"]
                    }

            # Extract and add triples as edges
            for subj, pred, obj in self.extract_triples(doc):
                subj_norm = self.normalize_entity(subj)
                obj_norm = self.normalize_entity(obj)

                edge_key = (subj_norm, pred, obj_norm)
                if edge_key not in edge_set:
                    all_edges.append({
                        "source": subj,
                        "source_normalized": subj_norm,
                        "target": obj,
                        "target_normalized": obj_norm,
                        "relation": pred
                    })
                    edge_set.add(edge_key)

        return {
            "nodes": list(all_nodes.values()),
            "edges": all_edges
        }
```

## Extensions

After mastering basic extraction, explore these advanced topics:

1. **LLM-Based Extraction**: Use GPT-4 or Claude for more accurate extraction
2. **Coreference Resolution**: "She" → "Alice" mapping
3. **Relation Typing**: Classify relationships into categories
4. **Entity Linking**: Link to external knowledge bases (Wikidata)
5. **Community Detection**: Use Leiden algorithm to find topic clusters

## Production Notes

In production Graph RAG systems:

- **Use NER models** (spaCy, Flair) for better entity detection
- **Use LLMs** for relationship extraction with few-shot examples
- **Store in Neo4j** or similar graph database for scalable queries
- **Implement coreference** to handle pronouns ("she", "it", "the company")
- **Version your knowledge graph** for reproducibility
