# Graph Traversal for Multi-hop RAG

Implement graph traversal algorithms that enable multi-hop reasoning across entity-relationship graphs, solving questions that span multiple documents.

## The Problem

Standard RAG retrieves similar chunks. But some questions require **connected reasoning**:

| Query | Standard RAG Problem | GraphRAG Solution |
|-------|---------------------|-------------------|
| "Who founded the company that employs Alice?" | No single chunk contains this | Traverse: Alice → OpenAI → Sam Altman |
| "What drugs target proteins involved in Disease X?" | Scattered across papers | Follow protein-disease edges |
| "Which authors co-authored with both A and B?" | Requires document chaining | Graph intersection query |

## Algorithm Details

### BFS Traversal with Relevance

```python
def traverse_bfs_guided(self, start: str, query_embedding: np.ndarray, 
                        max_depth: int) -> list:
    """
    BFS that prioritizes semantically relevant paths.
    """
    from collections import deque
    
    queue = deque([(start, [], 0)])  # (entity, path, depth)
    visited = set()
    results = []
    
    while queue:
        entity, path, depth = queue.popleft()
        
        if depth > max_depth or entity in visited:
            continue
        visited.add(entity)
        
        # Score relevance to query
        entity_embedding = self.get_entity_embedding(entity)
        relevance = cosine_similarity(query_embedding, entity_embedding)
        
        results.append({
            "entity": entity,
            "path": path,
            "depth": depth,
            "relevance": relevance
        })
        
        # Add neighbors to queue
        for neighbor, relation in self.graph.get_neighbors(entity):
            if neighbor not in visited:
                new_path = path + [(entity, relation, neighbor)]
                queue.append((neighbor, new_path, depth + 1))
    
    return sorted(results, key=lambda x: x["relevance"], reverse=True)
```

### Shortest Path for Relationship Queries

```python
def find_relationship_path(self, entity_a: str, entity_b: str) -> list:
    """
    Find shortest path between two entities.
    """
    try:
        import networkx as nx
        path = nx.shortest_path(
            self.graph, 
            source=entity_a, 
            target=entity_b
        )
        return path
    except nx.NetworkXNoPath:
        return []
```

### Hybrid: Graph + Vector Retrieval

```python
def hybrid_retrieve(self, query: str, k: int = 5) -> list[str]:
    """
    Combine graph traversal with vector search.
    """
    # 1. Extract entities from query
    query_entities = self.extract_entities(query)
    
    # 2. Graph traversal for connected context
    graph_chunks = []
    for entity in query_entities:
        subgraph = self.traverse_with_query(query, [entity], max_depth=2)
        for node in subgraph:
            chunks = self.get_chunks_for_entity(node["entity"])
            graph_chunks.extend(chunks)
    
    # 3. Vector search for semantic similarity
    vector_chunks = self.vector_store.search(query, k=k)
    
    # 4. Combine and deduplicate
    all_chunks = list(set(graph_chunks + vector_chunks))
    
    # 5. Rerank by combined score
    return self.rerank(query, all_chunks, top_k=k)
```

## Complexity Analysis

| Operation | Time | Space |
|-----------|------|-------|
| BFS Traversal | O(V + E) | O(V) |
| Shortest Path | O(V + E) | O(V) |
| Guided Traversal | O(k(V + E)) | O(V) |
| Multi-hop Retrieve | O(k × depth × (V + E)) | O(V + E) |

Where:
- V = number of vertices (entities)
- E = number of edges (relationships)
- k = number of query entities
- depth = maximum traversal depth

### Production Tips

1. **Index entities** for fast lookup
2. **Cache frequent traversals** to reduce latency
3. **Limit traversal depth** to prevent explosion
4. **Use relationship weights** for better ranking
5. **Monitor path relevance** with query embeddings
