# Graph Traversal for Multi-hop RAG

## Overview

Standard RAG fails on questions that require reasoning across multiple documents, like _"Who founded the company that employs Alice?"_ This challenge teaches you to implement graph traversal algorithms that enable multi-hop reasoning.

## Why This Matters

- **Multi-hop QA**: Answer complex questions requiring document chaining
- **Knowledge Graphs**: Build and traverse entity-relationship graphs
- **Microsoft GraphRAG**: Industry-standard approach for complex reasoning

## Key Concepts

- BFS/DFS for shortest path finding
- Entity-relation modeling
- Neighbor filtering by relationship type

## Real-World Applications

Used by Microsoft's GraphRAG, Neo4j-based RAG systems, and enterprise knowledge management platforms.
