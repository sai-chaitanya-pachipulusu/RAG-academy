# Answer Relevancy Score

<Callout title="Goal" variant="info">

</Callout>

## Why Answer Relevancy Matters

An answer can be:
- **Faithful** (grounded in context) but **irrelevant** (doesn't answer the question)
- **Relevant** (answers the question) but **unfaithful** (makes things up)

Answer Relevancy ensures the RAG system actually addresses what the user asked.

### Example: Faithful but Irrelevant

```
Question: "What is the company's revenue?"
Answer: "The company was founded in 2010 by John Smith."

Analysis:
- Faithful: ✓ (fact is in context)
- Relevant: ✗ (doesn't answer about revenue)
```

## The Theory

### Core Idea

If an answer is relevant to a question, we should be able to **generate questions from the answer** that are **similar to the original question**.

### Mathematical Formula

$$\text{Answer Relevancy} = \frac{1}{N} \sum_{i=1}^{N} \cos(E_{g_i}, E_o)$$

Where:
- $E_{g_i}$ = Embedding of generated question $i$
- $E_o$ = Embedding of original question
- $N$ = Number of generated questions
- $\cos$ = Cosine similarity

### Algorithm

```
1. Generate N questions from the answer
2. Embed original question → E_o
3. For each generated question:
   a. Embed → E_g
   b. Compute cos(E_g, E_o)
4. Return mean of all similarities
```

## Implementation

### Complete Solution

```python
from typing import List, Callable
import numpy as np

def cosine_similarity(a: np.ndarray, b: np.ndarray) -> float:
    """
    Calculate cosine similarity between two vectors.
    
    Formula: cos(θ) = (A · B) / (||A|| ||B||)
    
    Args:
        a: First vector
        b: Second vector
        
    Returns:
        Cosine similarity (-1 to 1)
    """
    dot_product = np.dot(a, b)
    norm_a = np.linalg.norm(a)
    norm_b = np.linalg.norm(b)
    
    if norm_a == 0 or norm_b == 0:
        return 0.0
    
    return dot_product / (norm_a * norm_b)

def answer_relevancy(
    original_question: str,
    generated_answer: str,
    question_generator: Callable[[str], List[str]],
    embed_fn: Callable[[str], np.ndarray]
) -> float:
    """
    Calculate Answer Relevancy using embedding similarity.
    
    Based on RAGAS metric: https://docs.ragas.io/en/stable/concepts/metrics/answer_relevance.html
    """
    # Step 1: Generate questions from the answer
    generated_questions = question_generator(generated_answer)
    
    # Handle edge case: no questions generated
    if not generated_questions:
        return 0.0
    
    # Step 2: Embed the original question
    original_embedding = embed_fn(original_question)
    
    # Step 3 & 4: Embed each generated question and calculate similarity
    similarities = []
    for gen_question in generated_questions:
        gen_embedding = embed_fn(gen_question)
        sim = cosine_similarity(original_embedding, gen_embedding)
        similarities.append(sim)
    
    # Step 5: Return mean similarity
    return float(np.mean(similarities))
```

    """
    Mock question generator for testing.

        questions.append("What is the location?")
    
    # Check for time patterns
    if any(year in answer for year in ["2020", "2021", "2022", "2023", "2024"]):
        questions.append("When did this happen?")
        questions.append("What year was it?")
    
    # Check for person patterns
    if "founded by" in answer or "CEO" in answer:
        questions.append("Who founded it?")
        questions.append("Who is the CEO?")
    
    # Check for number patterns
    if any(char.isdigit() for char in answer):
        questions.append("What is the number?")
        questions.append("How many?")
    
    # Fallback
    if not questions:
        questions.append("What is this about?")
    
    return questions[:3]  # Return up to 3 questions

## Production Implementation

### Using Real LLM for Question Generation

```python
import openai

def llm_question_generator(answer: str, n_questions: int = 3) -> List[str]:
    """
    Generate questions from answer using an LLM.
    
    Args:
        answer: The generated answer
        n_questions: Number of questions to generate
        
    Returns:
        List of generated questions
    """
    prompt = f"""Given the following answer, generate {n_questions} questions that could have led to this answer.

Answer: {answer}

Questions (one per line):"""

    response = openai.ChatCompletion.create(
        model="gpt-3.5-turbo",
        messages=[{"role": "user", "content": prompt}],
        temperature=0.7
    )
    
    questions = response.choices[0].message.content.strip().split("\n")
    return [q.strip("- ") for q in questions if q.strip()][:n_questions]
```

### Complete Evaluation Pipeline

```python
class AnswerRelevancyEvaluator:
    """Production evaluator for answer relevancy."""
    
    def __init__(
        self,
        question_generator: Callable,
        embed_fn: Callable,
        threshold: float = 0.7
    ):
        self.question_generator = question_generator
        self.embed_fn = embed_fn
        self.threshold = threshold
    
    def evaluate(self, question: str, answer: str) -> dict:
        """
        Evaluate answer relevancy.
        
        Returns:
            {
                "score": float,
                "is_relevant": bool,
                "generated_questions": List[str]
            }
        """
        score = answer_relevancy(
            question,
            answer,
            self.question_generator,
            self.embed_fn
        )
        
        return {
            "score": score,
            "is_relevant": score >= self.threshold,
            "generated_questions": self.question_generator(answer)
        }
```
