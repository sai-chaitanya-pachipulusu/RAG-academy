# Challenge: Answer Relevancy Score

Implement the embedding-based **Answer Relevancy** metric from RAGAS. This metric measures how well the generated answer addresses the original question by checking if questions generated from the answer are similar to the original.

## Formula

$$\text{Answer Relevancy} = \frac{1}{N} \sum_{i=1}^{N} \cos(E_{g_i}, E_o)$$

Where:

- $E_{g_i}$ is the embedding of generated question $i$
- $E_o$ is the embedding of the original question
- $N$ is the number of generated questions

def cosine_similarity(a: np.ndarray, b: np.ndarray) -> float:
    """Reference implementation."""
    return float(np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b)))

# Mock embeddings that are predictable for testing
def deterministic_embed(text: str) -> np.ndarray:
