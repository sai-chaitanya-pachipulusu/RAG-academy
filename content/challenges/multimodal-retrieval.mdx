# Multi-Modal Retrieval (CLIP)

Implement cross-modal retrieval using CLIP to search for images using text queries and vice versa within a shared embedding space.

## The Magic of Shared Space

Modern RAG isn't limited to text. Multi-modal models like **CLIP** (Contrastive Language-Image Pre-training) allow us to embed both images and text into the **same vector space**.

Because the text "a golden retriever in a park" and an actual image of a golden retriever in a park are mapped to similar vectors, we can search for images using text queries (and vice versa).

## Algorithm Details

### CLIP-based Retrieval

```python
def text_to_image_search(self, query: str, k: int = 5) -> list[dict]:
    """Search images using text query."""
    # Encode text query
    query_embedding = self.model.encode(query, convert_to_tensor=True)
    query_embedding = query_embedding / query_embedding.norm()
    
    # Compute similarities with all images
    similarities = cosine_similarity(
        query_embedding.cpu().numpy().reshape(1, -1),
        self.image_embeddings
    )[0]
    
    # Get top-k
    top_indices = np.argsort(similarities)[-k:][::-1]
    
    results = []
    for idx in top_indices:
        results.append({
            "image": self.image_paths[idx],
            "score": float(similarities[idx]),
            "metadata": self.metadata[idx] if self.metadata else {}
        })
    
    return results
```

### Hybrid Multi-Modal Search

```python
def hybrid_search(self, text_query: str,
                 image_query: Union[str, Image.Image] = None,
                 text_weight: float = 0.5,
                 k: int = 5) -> list[dict]:
    """Combine text and image queries."""
    # Get text query embedding
    text_emb = self.model.encode(text_query, convert_to_tensor=True)
    text_emb = text_emb / text_emb.norm()
    
    if image_query is not None:
        # Get image query embedding
        if isinstance(image_query, str):
            image_query = Image.open(image_query)
        
        img_emb = self.model.encode(image_query, convert_to_tensor=True)
        img_emb = img_emb / img_emb.norm()
        
        # Combine embeddings
        combined_emb = (text_weight * text_emb + 
                       (1 - text_weight) * img_emb)
        combined_emb = combined_emb / combined_emb.norm()
    else:
        combined_emb = text_emb
    
    # Search with combined embedding
    similarities = cosine_similarity(
        combined_emb.cpu().numpy().reshape(1, -1),
        self.image_embeddings
    )[0]
    
    top_indices = np.argsort(similarities)[-k:][::-1]
    
    return [
        {
            "image": self.image_paths[i],
            "score": float(similarities[i]),
            "metadata": self.metadata[i] if self.metadata else {}
        }
        for i in top_indices
    ]
```

## Integration with RAG

```python
class MultimodalRAG:
    def __init__(self):
        self.text_retriever = TextRetriever()
        self.image_retriever = MultimodalRetriever()
        self.llm = LanguageModel()
    
    def retrieve(self, query: str, query_image=None, k: int = 5):
        """Retrieve both text and image context."""
        # Text retrieval
        text_results = self.text_retriever.search(query, k=k)
        
        # Image retrieval (if query has visual component)
        if query_image:
            image_results = self.image_retriever.hybrid_search(
                query, query_image, k=k
            )
        else:
            image_results = self.image_retriever.text_to_image_search(query, k=k)
        
        return {
            "text_context": text_results,
            "image_context": image_results
        }
    
    def generate(self, query: str, query_image=None) -> str:
        """Generate answer with multi-modal context."""
        context = self.retrieve(query, query_image)
        
        prompt = f"""Answer based on the following context:
        
Text Context:
{format_text_context(context['text_context'])}

Image Context:
{format_image_context(context['image_context'])}

Question: {query}
"""
        return self.llm.generate(prompt)
```
