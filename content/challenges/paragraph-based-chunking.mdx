# Paragraph-Based Chunking: Thematic Units

## From Sentences to Themes

Sentences are semantic units. **Paragraphs** are thematic units.

A paragraph develops ONE main idea fully. Keeping it intact preserves the complete argument.

---

## The Writer's Intent

Writers don't randomly group sentences. They use paragraphs to:

- Introduce a topic
- Develop an argument
- Present evidence
- Draw a conclusion

Splitting a paragraph destroys this logical flow.

---

## The Algorithm

```python
def paragraph_chunk(text: str, min_size: int = 100, max_size: int = 500):
    """
    Chunk text by paragraphs with size constraints.
    
    Time Complexity: O(P) where P = number of paragraphs
    Space Complexity: O(N) for output
    
    Args:
        text: Input text
        min_size: Minimum chunk size (merge small paragraphs)
        max_size: Maximum chunk size (split large paragraphs)
        
    Returns:
        List of paragraph-based chunks
    """
    # Split on paragraph boundaries
    paragraphs = text.split('\n\n')
    
    chunks = []
    current = ""
    
    for para in paragraphs:
        if len(current) + len(para) < max_size:
            current += para + "\n\n"
        else:
            if current:
                chunks.append(current.strip())
            current = para + "\n\n"
    
    if current:
        chunks.append(current.strip())
    
    return chunks
```

---

## The Merging Problem

Paragraphs vary wildly in size:

- Single-sentence paragraph: ~20 words
- Normal paragraph: 100-200 words
- Dense academic paragraph: 500+ words

**Strategy**: Merge small paragraphs, split large ones.

---

## Balancing Size

```python
# Smart paragraph chunking
def smart_paragraph_chunk(paragraphs, target_size=400):
    chunks = []
    current = ""
    
    for para in paragraphs:
        if len(para) > target_size * 1.5:
            # Split oversized paragraph by sentences
            chunks.extend(split_by_sentences(para, target_size))
        elif len(current) + len(para) > target_size:
            chunks.append(current)
            current = para
        else:
            current += "\n\n" + para
    
    return chunks
```

## ⚖️ Tradeoffs

### Pros

- ✅ Preserves thematic coherence
- ✅ Each chunk is a complete "idea"
- ✅ Natural for most document types

### Cons

- ❌ Even more variable sizes than sentences
- ❌ Some docs have poor paragraph structure
- ❌ Code and tables don't have "paragraphs"
