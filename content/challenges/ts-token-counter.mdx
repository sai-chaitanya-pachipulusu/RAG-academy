  Implement a token counter for context window management.

## Why this matters in production

Token counting is essential for context window management. Every RAG system needs to track tokens to avoid truncation and manage costs.

## What you're implementing

- Word-based estimation: count words.
- Character-based estimation: ~4 chars per token.
- Handle punctuation as additional tokens.

## Common pitfalls

- Underestimating tokens for code/technical content.
- Not accounting for prompt template overhead.
