# Gemini Grounding

<Callout title="Goal" variant="info">
  Build a grounded Q&A system using Gemini's native grounding features with real-time Google Search.
</Callout>

## Why This Matters in Production

Gemini 2.0's native grounding capability provides **real-time information** without building and maintaining your own RAG pipeline. This is transformative for:

- **News and current events**: Information changes by the minute
- **Stock prices and market data**: Real-time accuracy is critical
- **Product availability**: Inventory changes constantly
- **Weather and traffic**: Time-sensitive information
- **Breaking research**: Latest papers and discoveries

### Native Grounding vs Custom RAG

| Factor | Gemini Grounding | Custom RAG |
|--------|-----------------|------------|
| Setup time | Minutes | Days/weeks |
| Maintenance | Zero | High |
| Real-time data | ✅ Yes | ❌ No (unless constantly updated) |
| Private documents | ❌ No | ✅ Yes |
| Cost per query | $0.003-0.01 | $0.001-0.005 (infrastructure dependent) |
| Latency | 2-5s | 500ms-2s |
| Control | Limited | Full |

## The Theory

### How Gemini Grounding Works

```
User Query
    ↓
[Query Understanding] → Extract intent & entities
    ↓
[Search Query Generation] → Formulate search queries
    ↓
[Google Search API] → Retrieve real-time results
    ↓
[Result Ranking] → Score relevance & credibility
    ↓
[Grounded Generation] → Synthesize with citations
    ↓
Response + Sources
```

### Dynamic Retrieval Configuration

Gemini uses a **dynamic threshold** to decide when to search:

$$\text{Search Decision} = \begin{cases} \text{Search} & \text{if } P(\text{needs fresh info}) > \theta \\ \text{No Search} & \text{otherwise} \end{cases}$$

Where $\theta$ is configurable (default: 0.3).

### Cost Model

| Component | Cost |
|-----------|------|
| Input tokens | $0.075 / 1M tokens |
| Output tokens | $0.30 / 1M tokens |
| Search grounding | +$0.0035 / query |
| Cached context | $0.01875 / 1M tokens |

## Implementation

### Step 1: Data Structures

```python
from dataclasses import dataclass
from typing import List, Dict, Optional

@dataclass
class GroundingChunk:
    """A chunk of grounded information from search."""
    uri: str
    title: str
    snippet: str
    domain: Optional[str] = None
    
    def __post_init__(self):
        if self.domain is None and self.uri:
            from urllib.parse import urlparse
            self.domain = urlparse(self.uri).netloc

@dataclass
class GroundedResponse:
    """Complete response with grounding metadata."""
    text: str
    grounding_chunks: List[GroundingChunk]
    search_queries_used: List[str]
    confidence_score: float = 0.0
    
    def get_sources_by_domain(self) -> Dict[str, List[GroundingChunk]]:
        """Group sources by domain for analysis."""
        by_domain = {}
        for chunk in self.grounding_chunks:
            domain = chunk.domain or "unknown"
            by_domain.setdefault(domain, []).append(chunk)
        return by_domain
```

### Step 3: Gemini Grounded RAG Implementation

```python
import re
from typing import List, Dict, Tuple
from difflib import SequenceMatcher

class GeminiGroundedRAG:
    """
    Simulates Gemini's native grounding behavior.
    In production, this would use the actual Google AI API.
    """
    
    def __init__(self, mock_mode: bool = True):
        """
        Initialize Gemini grounding system.
        
        Args:
            mock_mode: Use mock results for testing (no API key needed)
        """
        self.mock_mode = mock_mode
        self.search_cache: Dict[str, List[GroundingChunk]] = {}
    
    def extract_search_queries(self, user_query: str) -> List[str]:
        """
        Extract search queries from user question.
        
        For complex questions, may generate multiple queries.
        
        Args:
            user_query: Original user question
            
        Returns:
            List of search queries
        """
        query_lower = user_query.lower()
        queries = []
        
        # Check for comparison patterns
        if "compare" in query_lower or " vs " in query_lower:
            # Extract entities to compare
            # e.g., "Compare Pinecone vs Weaviate" → ["Pinecone features", "Weaviate features"]
            entities = re.findall(r'([A-Z][a-zA-Z]+)', user_query)
            if len(entities) >= 2:
                queries.extend([f"{entity} vector database features" for entity in entities[:2]])
        
        # Check for multi-part questions
        if " and " in query_lower or " what's " in query_lower:
            # Split into sub-queries
            parts = re.split(r'\s+and\s+|\?\s+', user_query)
            for part in parts:
                part = part.strip()
                if len(part) > 10 and not part.endswith('?'):
                    part += '?'
                if len(part) > 10:
                    queries.append(part)
        
        # Default: use query as-is (cleaned up)
        if not queries:
            queries = [user_query.strip()]
        
        return queries[:3]  # Max 3 queries
    
    def search(self, query: str) -> List[GroundingChunk]:
        """
        Perform grounded search (mock or real).
        
        Args:
            query: Search query
            
        Returns:
            List of grounding chunks from search
        """
        # Check cache first
        if query in self.search_cache:
            return self.search_cache[query]
        
        if self.mock_mode:
            # Find best matching mock result using fuzzy matching
            best_match = None
            best_score = 0
            
            for mock_query, results in MOCK_SEARCH_RESULTS.items():
                score = SequenceMatcher(None, query.lower(), mock_query.lower()).ratio()
                if score > best_score:
                    best_score = score
                    best_match = results
            
            results = best_match if best_score > 0.5 else []
        else:
            # Real Gemini API call
            results = self._real_gemini_search(query)
        
        # Cache results
        self.search_cache[query] = results
        return results
    
    def _real_gemini_search(self, query: str) -> List[GroundingChunk]:
        """Placeholder for real API implementation."""
        raise NotImplementedError("Use mock_mode=True for testing or implement API call")
    
    def synthesize_grounded_response(
        self, 
        user_query: str, 
        grounding_chunks: List[GroundingChunk]
    ) -> str:
        """
        Generate response grounded in search results.
        
        Must:
        - Only state facts found in grounding chunks
        - Include inline citations [Source Title]
        - Acknowledge when information is limited
        
        Args:
            user_query: Original question
            grounding_chunks: Retrieved grounding chunks
            
        Returns:
            Grounded response with citations
        """
        if not grounding_chunks:
            return "I couldn't find relevant information to answer this question."
        
        # Extract key facts from snippets
        response_parts = []
        seen_titles = set()
        
        for chunk in grounding_chunks:
            # Avoid duplicate sources
            if chunk.title in seen_titles:
                continue
            seen_titles.add(chunk.title)
            
            # Add fact with citation
            fact = f"{chunk.snippet} [{chunk.title}]"
            response_parts.append(fact)
        
        return " ".join(response_parts)
    
    def calculate_confidence(self, chunks: List[GroundingChunk], query: str) -> float:
        """
        Calculate confidence score based on source quality and relevance.
        
        Args:
            chunks: Retrieved chunks
            query: Original query
            
        Returns:
            Confidence score 0-1
        """
        if not chunks:
            return 0.0
        
        # Factors:
        # 1. Number of sources (more is better, up to a point)
        source_score = min(len(chunks) / 3, 1.0)
        
        # 2. Domain diversity (different domains = more reliable)
        domains = set(c.domain for c in chunks if c.domain)
        diversity_score = min(len(domains) / 2, 1.0)
        
        # 3. Content relevance (simplified: length of snippet)
        relevance_score = min(sum(len(c.snippet) for c in chunks) / 500, 1.0)
        
        # Weighted average
        confidence = (source_score * 0.3 + diversity_score * 0.4 + relevance_score * 0.3)
        return round(confidence, 2)
    
    def answer(self, query: str) -> GroundedResponse:
        """
        Main entry point: grounded answer with metadata.
        
        Args:
            query: User question
            
        Returns:
            GroundedResponse with text, sources, and queries used
        """
        # Extract search queries
        search_queries = self.extract_search_queries(query)
        
        # Perform searches
        all_chunks = []
        for sq in search_queries:
            chunks = self.search(sq)
            all_chunks.extend(chunks)
        
        # Remove duplicates based on URI
        seen_uris = set()
        unique_chunks = []
        for chunk in all_chunks:
            if chunk.uri not in seen_uris:
                seen_uris.add(chunk.uri)
                unique_chunks.append(chunk)
        
        # Generate response
        response_text = self.synthesize_grounded_response(query, unique_chunks)
        
        # Calculate confidence
        confidence = self.calculate_confidence(unique_chunks, query)
        
        return GroundedResponse(
            text=response_text,
            grounding_chunks=unique_chunks,
            search_queries_used=search_queries,
            confidence_score=confidence
        )
```

## Production Implementation

### Real Gemini API Integration

```python
import google.generativeai as genai

class RealGeminiGroundedRAG:
    """Production implementation using real Google AI API."""
    
    def __init__(self, api_key: str):
        genai.configure(api_key=api_key)
        self.model = genai.GenerativeModel("gemini-2.0-flash")
    
    def answer(self, query: str) -> GroundedResponse:
        """
        Get grounded answer using real Gemini API.
        
        Args:
            query: User question
            
        Returns:
            GroundedResponse with real search results
        """
        response = self.model.generate_content(
            query,
            tools=[{
                "google_search_retrieval": {
                    "dynamic_retrieval_config": {
                        "mode": "MODE_DYNAMIC",
                        "dynamic_threshold": 0.3
                    }
                }
            }]
        )
        
        # Extract grounding metadata
        chunks = []
        grounding_metadata = response.candidates[0].grounding_metadata
        
        if grounding_metadata:
            for chunk in grounding_metadata.grounding_chunks:
                chunks.append(GroundingChunk(
                    uri=chunk.web.uri,
                    title=chunk.web.title,
                    snippet=chunk.web.snippet
                ))
        
        return GroundedResponse(
            text=response.text,
            grounding_chunks=chunks,
            search_queries_used=[query],  # Gemini handles query extraction
            confidence_score=0.8 if chunks else 0.0
        )
```

### Rate Limiting

```python
from functools import wraps
import time

class RateLimiter:
    """Simple rate limiter for API calls."""
    
    def __init__(self, max_calls: int, window: int):
        self.max_calls = max_calls
        self.window = window
        self.calls = []
    
    def can_call(self) -> bool:
        now = time.time()
        # Remove old calls
        self.calls = [c for c in self.calls if now - c < self.window]
        return len(self.calls) < self.max_calls
    
    def record_call(self):
        self.calls.append(time.time())

# Usage
limiter = RateLimiter(max_calls=100, window=60)  # 100 calls per minute

def grounded_query(query: str) -> GroundedResponse:
    if not limiter.can_call():
        raise RateLimitError("Too many requests")
    
    limiter.record_call()
    return rag.answer(query)
```
