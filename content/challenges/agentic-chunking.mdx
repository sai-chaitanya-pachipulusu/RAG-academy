## Beyond Rules and Metrics

Semantic chunking uses embedding similarity - a simple metric. But meaning is more nuanced:

```
"Machine learning requires large datasets. For example, GPT was trained on web text."
```

A simple similarity metric might split here. But an LLM would UNDERSTAND that the second sentence is an **example** supporting the first claim.

## The Agentic Insight

What if we could ask an LLM:

> "Should these two passages be in the same chunk?"

The LLM can reason about:

- Continuation ("For example...")
- Contrast ("However...")
- Topic shift ("Moving on to...")
- Support ("This demonstrates...")

## Complexity Analysis

| Operation | Semantic | Agentic |
|-----------|----------|---------|
| Embedding | O(S × d²) | O(S × d²) |
| LLM calls | 0 | O(S) |
| Time | ~100ms | ~10-30s |
| Cost | ~$0.001/doc | ~$0.10/doc |
| Quality | Good | Excellent |

Where S = sentences, d = embedding dim

## Implementation

```python
from typing import List, Dict, Callable, Optional
import re

class AgenticChunker:
    """
    Use LLM reasoning to determine chunk boundaries.
    
    Combines heuristic signals with optional LLM verification
    for high-quality chunking.
    """
    
    # Signals that indicate continuation (same chunk)
    CONTINUE_SIGNALS = [
        "for example", "for instance", "specifically",
        "this shows", "in other words", "that is",
        "namely", "particularly", "especially"
    ]
    
    # Signals that indicate boundaries (new chunk)
    BOUNDARY_SIGNALS = [
        "however", "in contrast", "on the other hand",
        "moving on", "turning to", "next",
        "on another note", "separately", "finally"
    ]
    
    def __init__(
        self,
        embed_fn: Callable[[str], List[float]],
        llm_fn: Optional[Callable[[str], str]] = None,
        similarity_threshold: float = 0.5
    ):
        self.embed_fn = embed_fn
        self.llm_fn = llm_fn
        self.similarity_threshold = similarity_threshold
    
    def should_chunk_here(
        self,
        prev_sentences: List[str],
        current_sentence: str,
        use_llm: bool = False
    ) -> bool:
        """
        Decide if we should start a new chunk before current_sentence.
        
        Args:
            prev_sentences: Sentences in current chunk
            current_sentence: Sentence to evaluate
            use_llm: Whether to use LLM for decision
        
        Returns:
            True if new chunk should start
        """
        current_lower = current_sentence.lower()
        
        # Check boundary signals
        if any(sig in current_lower for sig in self.BOUNDARY_SIGNALS):
            return True
        
        # Check continuation signals
        if any(sig in current_lower for sig in self.CONTINUE_SIGNALS):
            return False
        
        # Use similarity if no clear signals
        if prev_sentences:
            prev_text = ' '.join(prev_sentences[-2:])  # Last 2 sentences
            similarity = self._compute_similarity(prev_text, current_sentence)
            
            if similarity < self.similarity_threshold:
                return True
        
        # Optional: Use LLM for uncertain cases
        if use_llm and self.llm_fn:
            return self._llm_decision(prev_sentences, current_sentence)
        
        return False
    
    def _compute_similarity(self, text1: str, text2: str) -> float:
        """Compute cosine similarity between two texts."""
        import numpy as np
        
        emb1 = self.embed_fn(text1)
        emb2 = self.embed_fn(text2)
        
        return np.dot(emb1, emb2) / (np.linalg.norm(emb1) * np.linalg.norm(emb2) + 1e-8)
    
    def _llm_decision(
        self,
        prev_sentences: List[str],
        current_sentence: str
    ) -> bool:
        """Use LLM to decide on chunk boundary."""
        if not self.llm_fn:
            return False
        
        context = ' '.join(prev_sentences[-3:])  # Last 3 sentences
        
        prompt = f"""Given these sentences from a document:

Previous context:
{context}

Current sentence:
{current_sentence}

Should the current sentence start a new chunk (topic change) or continue the current chunk?

Respond with ONLY "NEW" or "CONTINUE":"""
        
        response = self.llm_fn(prompt).strip().upper()
        return "NEW" in response
    
    def chunk(self, text: str, use_llm: bool = False) -> List[Dict]:
        """
        Chunk text using agentic reasoning.
        
        Args:
            text: Input text
            use_llm: Whether to use LLM for boundary decisions
        
        Returns:
            List of chunks with metadata
        """
        sentences = self._split_sentences(text)
        
        if not sentences:
            return []
        
        chunks = []
        current_chunk = [sentences[0]]
        
        for i in range(1, len(sentences)):
            should_split = self.should_chunk_here(
                current_chunk,
                sentences[i],
                use_llm=use_llm
            )
            
            if should_split:
                # Save current chunk
                chunks.append(self._create_chunk(current_chunk, len(chunks)))
                # Start new chunk
                current_chunk = [sentences[i]]
            else:
                current_chunk.append(sentences[i])
        
        # Add final chunk
        if current_chunk:
            chunks.append(self._create_chunk(current_chunk, len(chunks)))
        
        return chunks
    
    def _split_sentences(self, text: str) -> List[str]:
        """Split text into sentences."""
        sentences = re.split(r'(?<=[.!?])\s+', text)
        return [s.strip() for s in sentences if s.strip()]
    
    def _create_chunk(self, sentences: List[str], index: int) -> Dict:
        """Create a chunk dict from sentences."""
        text = ' '.join(sentences)
        return {
            'text': text,
            'index': index,
            'sentence_count': len(sentences),
            'word_count': len(text.split()),
            'char_count': len(text)
        }
```

## ⚖️ Tradeoffs

### Pros

- ✅ Understands nuanced relationships
- ✅ Handles complex document structures
- ✅ Can provide reasoning for each split

### Cons

- ❌ Expensive (LLM call per boundary decision)
- ❌ Slower (seconds per document vs milliseconds)
- ❌ Requires careful prompt engineering

## When it's worth the cost

- High-value knowledge bases (executive briefings)
- Legal documents (argument structure matters)
- Research papers (methodology sections)

## Key Insight

Agentic chunking teaches us:

> "When rules aren't enough, use reasoning. LLMs can understand document intent."
