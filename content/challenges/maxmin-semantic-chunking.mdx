  # Max-Min Semantic Chunking

  Basic semantic chunking uses arbitrary thresholds. But where exactly should boundaries be? Place them where semantic distance is MAXIMUM between adjacent segments!

  ## The Insight

  - **Max inter-chunk distance**: Clear topic separation between chunks
  - **Min intra-chunk distance**: Coherent content within chunks
  - **Mathematical optimization**: Principled, not arbitrary thresholds

  ## The Algorithm

  1. Compute pairwise cosine distances between adjacent sentence embeddings
  2. Identify positions with MAXIMUM semantic distance
  3. Select top N-1 boundaries for N desired chunks
  4. Respect minimum chunk size constraints

  ## Your Task

  Implement `maxmin_semantic_chunk()` that:
  1. Takes sentences and their embeddings
  2. Finds optimal boundary positions
  3. Creates chunks with maximum inter-chunk separation
  4. Ensures minimum chunk size is respected

  ## Why This Works

  When topics change, the embedding space shows this as increased cosine distance:

  ```
  Topic A sentences → [similar embeddings]
  ↕ LARGE DISTANCE (boundary here!)
  Topic B sentences → [different embeddings]
  ```

  ## Research Background

  This technique comes from Greg Kamradt's semantic chunking research and is implemented in advanced RAG systems like Jina AI's embeddings pipeline.
