# RAPTOR: Recursive Abstractive Processing for Tree-Organized Retrieval

Build a hierarchical tree structure that enables both specific detail queries and broad thematic questions through multi-level summarization and retrieval.

## The Problem

Standard RAG retrieves at one granularity:

```
Query: "What was Acme Corp's Q3 revenue?"
→ Finds: Specific chunk with "Q3 revenue: $10M"

Query: "Summarize Acme Corp's financial performance"
→ Problem: No single chunk contains the full summary
```

**RAPTOR's Solution**: Build a tree of summaries at multiple levels.

## Your Task

Implement a `RAPTORTree` class that builds and queries a hierarchical summary tree:

## Algorithm Details

### Tree Construction

```python
def build_tree(self, chunks: list[str]) -> dict:
    """Build hierarchical summary tree."""
    tree = {
        "levels": {"0": chunks},
        "mappings": {"parent_to_children": {}, "child_to_parent": {}}
    }
    
    current_level = 0
    current_chunks = chunks
    
    while len(current_chunks) > self.cluster_size and current_level < self.max_levels:
        # Get embeddings for current level
        embeddings = self.embedder.encode(current_chunks)
        
        # Determine number of clusters
        n_clusters = max(2, len(current_chunks) // self.cluster_size)
        
        # Cluster chunks
        clusters = self.cluster_chunks(current_chunks, embeddings, n_clusters)
        
        # Summarize each cluster
        summaries = []
        for cluster_id, indices in clusters.items():
            cluster_chunks = [current_chunks[i] for i in indices]
            summary = self.summarize_cluster(cluster_chunks)
            summaries.append(summary)
            
            # Store mappings
            parent_id = f"L{current_level+1}_C{cluster_id}"
            tree["mappings"]["parent_to_children"][parent_id] = [
                f"L{current_level}_C{i}" for i in indices
            ]
        
        current_level += 1
        tree["levels"][str(current_level)] = summaries
        current_chunks = summaries
    
    return tree
```

### Clustering Strategy

```python
def cluster_chunks(self, chunks: list[str], embeddings: np.ndarray,
                   n_clusters: int) -> dict:
    """Cluster chunks using soft clustering."""
    from sklearn.cluster import KMeans
    
    # Use KMeans for simplicity (can use HDBSCAN for soft clustering)
    kmeans = KMeans(n_clusters=n_clusters, random_state=42, n_init=10)
    labels = kmeans.fit_predict(embeddings)
    
    clusters = {}
    for i, label in enumerate(labels):
        if label not in clusters:
            clusters[label] = []
        clusters[label].append(i)
    
    return clusters
```

### Summarization

```python
def summarize_cluster(self, chunks: list[str]) -> str:
    """Generate abstractive summary."""
    combined = "\n\n".join(chunks[:10])  # Limit context
    
    prompt = f"""Create a comprehensive summary of the following text chunks.
    Capture the key themes, facts, and relationships.
    
    Text chunks:
    {combined}
    
    Summary:"""
    
    return self.llm.generate(prompt, max_tokens=500)
```

### Level-Selective Retrieval

```python
def retrieve(self, query: str, k: int = 5, 
             target_level: int = None) -> list[dict]:
    """Retrieve from appropriate tree level."""
    query_embedding = self.embedder.encode([query])[0]
    
    # Auto-select level based on query type
    if target_level is None:
        target_level = self.select_level(query)
    
    # Get nodes at target level
    level_nodes = self.tree["levels"][str(target_level)]
    level_embeddings = [self.get_embedding(node) for node in level_nodes]
    
    # Similarity search
    similarities = cosine_similarity([query_embedding], level_embeddings)[0]
    
    # Get top-k
    top_indices = np.argsort(similarities)[-k:][::-1]
    
    results = []
    for idx in top_indices:
        results.append({
            "content": level_nodes[idx],
            "level": target_level,
            "score": similarities[idx],
            "id": f"L{target_level}_N{idx}"
        })
    
    return results

def select_level(self, query: str) -> int:
    """Heuristic to select appropriate tree level."""
    # Keywords suggesting broad questions → higher levels
    broad_keywords = ["summarize", "overview", "themes", "trends", "compare"]
    
    query_lower = query.lower()
    if any(kw in query_lower for kw in broad_keywords):
        return max(1, self.max_levels - 1)  # Near root
    
    # Specific questions → leaves
    return 0
```

## Complexity Analysis

| Phase | Time | Space |
|-------|------|-------|
| Embedding | O(n × d) | O(n × d) |
| Clustering | O(n × k × i) | O(n) |
| Summarization | O(n/c × L) | O(n/c) |
| Tree Build | O(n log n) | O(n) |
| Retrieval | O(log n) | O(1) |

Where:
- n = number of leaf chunks
- d = embedding dimension
- k = clusters, i = iterations
- c = cluster size
- L = LLM latency

## Production Tips

1. **Cluster size**: 5-10 chunks per cluster works well
2. **Max levels**: 3-4 levels typically sufficient
3. **Soft clustering**: Use HDBSCAN for overlapping clusters
4. **Caching**: Cache embeddings and summaries
5. **UMAP**: Reduce dimensionality before clustering for speed
