## Requirements

1. **Inline citations**: Every factual claim must have `[Source]` citation
2. **Extractable quotes**: Citations should include the source quote
3. **Multi-document**: Answer can cite multiple documents
4. **No hallucination**: Only state facts found in documents

<summary>Hint 1: Passage extraction</summary>

Split documents into paragraphs and score by term overlap:

```python
def find_relevant_passages(self, query: str, max_passages: int = 5):
    query_terms = set(query.lower().split())
    passages = []
    
    for doc in self.documents:
        paragraphs = doc["content"].strip().split("\n\n")
        for para in paragraphs:
            if len(para.strip()) < 20:
                continue
            para_terms = set(para.lower().split())
            score = len(query_terms & para_terms) / len(query_terms)
            if score > 0:
                passages.append({
                    "title": doc["title"],
                    "passage": para.strip(),
                    "relevance": score
                })
    
    passages.sort(key=lambda x: x["relevance"], reverse=True)
    return passages[:max_passages]
```

## Bonus: Real Claude API

If you have an Anthropic API key, try the real implementation:

```python
import anthropic
import base64

def real_claude_citations(pdf_path: str, query: str) -> str:
    client = anthropic.Anthropic()
    
    with open(pdf_path, "rb") as f:
        pdf_b64 = base64.standard_b64encode(f.read()).decode()
    
    response = client.messages.create(
        model="claude-3-5-sonnet-20241022",
        max_tokens=1024,
        messages=[{
            "role": "user",
            "content": [
                {
                    "type": "document",
                    "source": {
                        "type": "base64",
                        "media_type": "application/pdf",
                        "data": pdf_b64,
                    },
                },
                {
                    "type": "text",
                    "text": f"Answer this question with citations: {query}"
                }
            ]
        }]
    )
    
    return response.content[0].text
```
