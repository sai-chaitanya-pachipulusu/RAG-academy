# Claude Native Citations

<Callout title="Goal" variant="info">
  Implement a document Q&A system using Claude's native citation capabilities for automatic, accurate source attribution.
</Callout>

## Why This Matters in Production

Claude 3.5 Sonnet introduced native citation capabilities that eliminate the need for complex citation parsing and validation. This matters because:

- **No vector database required** for simple document Q&A use cases
- **Automatic source attribution** reduces hallucination risk
- **Native integration** means citations are grounded in actual document content
- **Reduced latency** compared to traditional RAG pipelines
- **Better user trust** with visible, clickable citations

### When to Use Native Citations vs Traditional RAG

| Scenario | Native Citations | Traditional RAG |
|----------|-----------------|-----------------|
| Few documents (< 10) | ✅ Perfect | Overkill |
| Many documents (> 100) | ❌ Expensive | ✅ Better |
| Real-time data | ❌ Static docs only | ✅ With live indexing |
| Complex retrieval needs | ❌ Limited | ✅ Full control |
| Quick prototyping | ✅ Fast setup | Requires infra |
| Production at scale | 💰 Costly | ✅ Optimized |

## The Theory

### How Native Citations Work

Claude's citation system uses a **document-aware attention mechanism**:

1. **Document ingestion**: PDFs or text are parsed into structured chunks
2. **Contextual embedding**: Each chunk is embedded with surrounding context
3. **Attention routing**: During generation, attention weights are tracked to source documents
4. **Citation extraction**: Claims are automatically linked to source spans

### Cost Analysis

| Documents | Tokens | Cost per Query | Latency |
|-----------|--------|----------------|---------|
| 1-3 (short) | ~4K | $0.008 | 2s |
| 5-10 (medium) | ~15K | $0.03 | 4s |
| 10+ (long) | ~50K+ | $0.10+ | 8s+ |

**Formula**: Cost = (Input Tokens × $3/M) + (Output Tokens × $15/M)

### Step 2: Citation RAG Implementation

```python
import re
from typing import List, Dict, Tuple

class ClaudeCitationRAG:
    """
    Simulates Claude's native citation behavior.
    In production, this would use the actual Anthropic API.
    """
    
    def __init__(self, documents: List[dict]):
        """
        Initialize with documents to cite from.
        
        Args:
            documents: List of {"title": str, "content": str}
        """
        self.documents = documents
        self.doc_index = {doc["title"]: doc for doc in documents}
    
    def find_relevant_passages(
        self, 
        query: str, 
        max_passages: int = 5
    ) -> List[dict]:
        """
        Find passages relevant to the query using term overlap.
        
        In real Claude API, this is handled automatically by the model.
        
        Args:
            query: User question
            max_passages: Maximum passages to return
            
        Returns:
            List of passages with relevance scores
        """
        query_terms = set(query.lower().split())
        passages = []
        
        for doc in self.documents:
            paragraphs = doc["content"].strip().split("\n\n")
            for i, para in enumerate(paragraphs):
                if len(para.strip()) < 20:
                    continue
                    
                para_terms = set(para.lower().split())
                # Jaccard similarity
                intersection = len(query_terms & para_terms)
                union = len(query_terms | para_terms)
                score = intersection / union if union > 0 else 0
                
                if score > 0.1:  # Minimum relevance threshold
                    passages.append({
                        "title": doc["title"],
                        "passage": para.strip(),
                        "paragraph": i,
                        "relevance": score
                    })
        
        # Sort by relevance and return top passages
        passages.sort(key=lambda x: x["relevance"], reverse=True)
        return passages[:max_passages]
    
    def extract_facts(self, passage: str) -> List[str]:
        """
        Extract factual statements from a passage.
        
        Args:
            passage: Text passage
            
        Returns:
            List of fact strings
        """
        # Simple extraction: split by periods, filter short sentences
        sentences = passage.split('.')
        facts = []
        
        for sent in sentences:
            sent = sent.strip()
            # Keep sentences with numbers or specific keywords
            if len(sent) > 20 and (
                any(c.isdigit() for c in sent) or
                any(kw in sent.lower() for kw in ['revenue', 'growth', 'percent', 'launched', 'policy'])
            ):
                facts.append(sent)
        
        return facts
    
    def generate_cited_answer(
        self, 
        query: str,
        passages: List[dict]
    ) -> str:
        """
        Generate answer with inline citations.
        
        Format: "Claim text [Title, paragraph X]."
        
        Args:
            query: User question
            passages: Relevant passages
            
        Returns:
            Answer string with citations
        """
        if not passages:
            return "I don't have enough information to answer that question."
        
        answer_parts = []
        
        for passage in passages:
            facts = self.extract_facts(passage["passage"])
            
            for fact in facts:
                # Create citation
                citation = f"[{passage['title']}]"
                answer_parts.append(f"{fact} {citation}")
        
        return " ".join(answer_parts)
    
    def answer_with_citations(self, query: str) -> dict:
        """
        Main entry point: answer question with full citation metadata.
        
        Args:
            query: User question
            
        Returns:
            Dictionary with answer and structured citations
        """
        # Find relevant passages
        passages = self.find_relevant_passages(query)
        
        # Generate cited answer
        answer = self.generate_cited_answer(query, passages)
        
        # Extract structured citations
        citations = []
        for passage in passages:
            facts = self.extract_facts(passage["passage"])
            for fact in facts:
                citations.append({
                    "claim": fact,
                    "source": passage["title"],
                    "quote": passage["passage"][:200] + "..."
                })
        
        return {
            "answer": answer,
            "citations": citations,
            "sources_used": list(set(p["title"] for p in passages)),
            "passage_count": len(passages)
        }
```

        {

            "expected_sources": ["Q3 2024 Financial Report", "Product Roadmap 2025"],
            "expected_facts": ["78%", "60%", "SmartFind"]
        },
    ]
    
    for test in test_queries:
        print(f"\n{'='*60}")
        print(f"Query: {test['query']}")
        
        result = rag.answer_with_citations(test["query"])
        
        print(f"Answer: {result['answer'][:200]}...")
        print(f"Citations: {len(result['citations'])}")
        
        # Check expected sources are cited
        cited_sources = set(c["source"] for c in result["citations"])
        expected_sources = set(test["expected_sources"])
        source_coverage = len(cited_sources & expected_sources) / len(expected_sources)
        print(f"Source coverage: {source_coverage:.0%}")
        
        # Check expected facts appear
        answer_lower = result["answer"].lower()
        facts_found = sum(1 for fact in test["expected_facts"] 
                        if fact.lower() in answer_lower)
        fact_coverage = facts_found / len(test["expected_facts"])
        print(f"Fact coverage: {fact_coverage:.0%}")
        
        assert source_coverage >= 0.5, f"Source coverage too low"
        assert fact_coverage >= 0.5, f"Fact coverage too low"
        assert "[" in result["answer"], "Missing inline citations"
    
    print("\n✓ All tests passed!")

test_citation_rag()

## Production Implementation with Real Claude API

```python
import anthropic
import base64
from typing import List, Optional

class RealClaudeCitationRAG:
    """Production implementation using real Anthropic API."""
    
    def __init__(self, api_key: str):
        self.client = anthropic.Anthropic(api_key=api_key)
    
    def answer_with_pdf(self, pdf_path: str, query: str) -> dict:
        """
        Answer questions about a PDF with native citations.
        
        Args:
            pdf_path: Path to PDF file
            query: User question
            
        Returns:
            Answer with citation metadata
        """
        with open(pdf_path, "rb") as f:
            pdf_b64 = base64.standard_b64encode(f.read()).decode()
        
        response = self.client.messages.create(
            model="claude-3-5-sonnet-20241022",
            max_tokens=1024,
            messages=[{
                "role": "user",
                "content": [
                    {
                        "type": "document",
                        "source": {
                            "type": "base64",
                            "media_type": "application/pdf",
                            "data": pdf_b64,
                        },
                    },
                    {
                        "type": "text",
                        "text": f"Answer this question with citations: {query}"
                    }
                ]
            }]
        )
        
        # Extract citations from response (if available in API response)
        return {
            "answer": response.content[0].text,
            "usage": {
                "input_tokens": response.usage.input_tokens,
                "output_tokens": response.usage.output_tokens
            }
        }
```

### Error Handling

```python
class CitationError(Exception):
    """Base class for citation errors."""
    pass

class NoRelevantDocumentsError(CitationError):
    """Raised when no documents match the query."""
    pass

class CitationValidationError(CitationError):
    """Raised when citations fail validation."""
    pass

def safe_answer(rag: ClaudeCitationRAG, query: str) -> dict:
    """Safely get answer with proper error handling."""
    try:
        result = rag.answer_with_citations(query)
        
        if not result["citations"]:
            raise NoRelevantDocumentsError("No relevant documents found")
        
        return result
        
    except Exception as e:
        return {
            "answer": "I apologize, but I couldn't find relevant information to answer your question.",
            "error": str(e),
            "citations": []
        }
```
