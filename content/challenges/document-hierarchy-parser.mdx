# Document Hierarchy Parser

## Overview

Document structure (headings, sections, subsections) provides essential context. This challenge teaches you to parse and preserve hierarchy for section-aware retrieval.

## Why This Matters

- **Context Preservation**: Know which section a chunk comes from
- **Breadcrumb Navigation**: "User Guide > Getting Started > Installation"
- **Improved Chunking**: Respect section boundaries

## Key Concepts

- Heading level detection (H1-H6)
- Nested section building with parent tracking
- Flattening with breadcrumb paths
- Section-aware chunk generation

## Real-World Applications

Notion, Confluence, GitBook, and documentation platforms all leverage hierarchical structure.
