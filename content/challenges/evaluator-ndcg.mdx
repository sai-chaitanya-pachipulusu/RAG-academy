## The "Golden Standard" of Search Evaluation

While Recall and MRR assume binary relevance (correct/incorrect), **nDCG** handles **graded relevance** (e.g., Perfect=3, Good=2, Fair=1, Bad=0).

## The formulas

### DCG (Discounted Cumulative Gain)

```
DCG@K = Σᵢ₌₁ᴷ (relevanceᵢ / log₂(i + 1))
```

The logarithm creates a **position discount**: relevant results at the top matter more than those at the bottom.

### IDCG (Ideal DCG)

The DCG you'd get if results were perfectly sorted by relevance (best first).

### nDCG (Normalized)

```
nDCG@K = DCG@K / IDCG@K
```

This gives a score between 0 and 1, where **1.0 = perfect ranking**.

## Example

| Rank | Relevance   | Discount (log₂(rank+1)) | Contribution |
| ---- | ----------- | ----------------------- | ------------ |
| 1    | 3 (Perfect) | 1.00                    | 3.00         |
| 2    | 2 (Good)    | 1.58                    | 1.26         |
| 3    | 0 (Bad)     | 2.00                    | 0.00         |
| 4    | 1 (Fair)    | 2.32                    | 0.43         |

DCG@4 = 3.00 + 1.26 + 0.00 + 0.43 = **4.69**

## Complexity Analysis

| Operation | Time Complexity | Space Complexity |
|-----------|-----------------|------------------|
| DCG computation | O(K log K) | O(K) |
| IDCG computation | O(K log K) | O(K) |
| nDCG computation | O(K log K) | O(K) |

The log factor comes from sorting for IDCG computation.

## When to use nDCG vs Recall

- **Recall@K**: "Did we find it?" (binary)
- **nDCG@K**: "How well did we rank it?" (graded)

For RAG, use Recall@K for retrieval debugging and nDCG for reranker evaluation.

## Implementation

```python
import math
from typing import List, Dict

def dcg_at_k(relevances: List[float], k: int) -> float:
    """
    Compute DCG@K.
    
    DCG = sum(rel_i / log2(i + 2)) for i in range(k)
    """
    dcg = 0.0
    for i, rel in enumerate(relevances[:k], start=1):
        dcg += rel / math.log2(i + 1)
    return dcg


def ndcg_at_k(retrieved: List[str], relevance: Dict[str, float], k: int) -> float:
    """
    Compute nDCG@K.
    
    Args:
        retrieved: Ordered list of retrieved document IDs
        relevance: Dict mapping doc_id to relevance score
        k: Cutoff position
    
    Returns:
        nDCG score between 0.0 and 1.0
    """
    # Get relevance scores for retrieved docs
    retrieved_relevances = [relevance.get(doc, 0.0) for doc in retrieved[:k]]
    
    # Compute DCG
    actual_dcg = dcg_at_k(retrieved_relevances, k)
    
    # Compute IDCG (ideal DCG)
    ideal_relevances = sorted(relevance.values(), reverse=True)[:k]
    ideal_dcg = dcg_at_k(ideal_relevances, k)
    
    if ideal_dcg == 0:
        return 0.0
    
    return actual_dcg / ideal_dcg
```

```python
import math
from typing import List, Dict

def dcg_at_k(relevances: List[float], k: int) -> float:
    """
    Compute DCG@K.
    
    DCG = sum(rel_i / log2(i + 1)) for i in range(1, k+1)
    """
    dcg = 0.0
    for i, rel in enumerate(relevances[:k], start=1):
        dcg += rel / math.log2(i + 1)
    return dcg


def ndcg_at_k(retrieved: List[str], relevance: Dict[str, float], k: int) -> float:
    """
    Compute nDCG@K.
    
    nDCG = DCG / IDCG
    """
    if k <= 0:
        return 0.0
    
    # Get relevance scores for retrieved docs
    retrieved_relevances = [relevance.get(doc, 0.0) for doc in retrieved[:k]]
    
    # Compute DCG
    actual_dcg = dcg_at_k(retrieved_relevances, k)
    
    # Compute IDCG (ideal DCG with perfect ranking)
    ideal_relevances = sorted(relevance.values(), reverse=True)[:k]
    ideal_dcg = dcg_at_k(ideal_relevances, k)
    
    if ideal_dcg == 0:
        return 0.0
    
    return actual_dcg / ideal_dcg
```
