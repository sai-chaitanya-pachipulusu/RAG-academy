## Metrics you're implementing

### Recall@K
"Did we retrieve any relevant evidence in the top‑K?"

```
Recall@K = |{Relevant docs} ∩ {Top K retrieved}| / |{Relevant docs}|
```

**Use when:** You need to know if the right documents are in the result set at all.

**Complexity:** O(K) time, O(1) space

### MRR@K (Mean Reciprocal Rank)
"How early is the first relevant hit?"

```
MRR@K = 1 / rank_of_first_relevant
```

**Use when:** The position of the first good result matters most.

**Complexity:** O(N) time per query, O(1) space

### nDCG@K (Normalized Discounted Cumulative Gain)
"Is the ranking quality good, including graded relevance?"

```
DCG@K = Σ (2^rel_i - 1) / log2(i + 1)
nDCG@K = DCG@K / IDCG@K
```

**Use when:** You have graded relevance (not just binary) and ranking order matters.

**Complexity:** O(K log K) time, O(K) space

## Metric Comparison Matrix

| Metric | Binary Relevance | Graded Relevance | Position Aware | Best For |
|--------|-----------------|------------------|----------------|----------|
| Recall@K | ✅ | ❌ | ❌ | Finding evidence |
| Precision@K | ✅ | ❌ | ❌ | Context quality |
| F1@K | ✅ | ❌ | ❌ | Balanced evaluation |
| MRR | ✅ | ❌ | ✅ | First result rank |
| MAP | ✅ | ❌ | ✅ | Multi-doc ranking |
| nDCG | ✅ | ✅ | ✅ | Graded ranking |

## Offline vs online

- **Offline**: run these metrics on a golden set of queries + labeled relevant docs.
- **Online**: track proxies + user feedback (but offline is where you debug system changes).

## Common pitfalls

- Dividing by 0 when there are no relevant docs (define a convention; tests may expect 0.0).
- Implementing DCG incorrectly (watch the log base and the +1 offset).
- Not using the same evaluation set when comparing systems.

## Implementation: Complete Metrics Suite

```python
from typing import List, Set, Dict
import math

class RetrievalMetrics:
    """Complete suite of retrieval evaluation metrics."""
    
    @staticmethod
    def recall_at_k(retrieved: List[str], relevant: Set[str], k: int) -> float:
        """Recall@K: Fraction of relevant docs found in top-K."""
        if not relevant:
            return 1.0
        if k <= 0 or not retrieved:
            return 0.0
        
        top_k = set(retrieved[:k])
        return len(top_k & relevant) / len(relevant)
    
    @staticmethod
    def precision_at_k(retrieved: List[str], relevant: Set[str], k: int) -> float:
        """Precision@K: Fraction of top-K that are relevant."""
        if k <= 0 or not retrieved:
            return 0.0
        
        top_k = retrieved[:k]
        relevant_count = sum(1 for doc in top_k if doc in relevant)
        return relevant_count / len(top_k)
    
    @staticmethod
    def f1_at_k(retrieved: List[str], relevant: Set[str], k: int) -> float:
        """F1@K: Harmonic mean of precision and recall."""
        precision = RetrievalMetrics.precision_at_k(retrieved, relevant, k)
        recall = RetrievalMetrics.recall_at_k(retrieved, relevant, k)
        
        if precision + recall == 0:
            return 0.0
        return 2 * precision * recall / (precision + recall)
    
    @staticmethod
    def mrr(retrieved: List[str], relevant: Set[str]) -> float:
        """MRR: Reciprocal rank of first relevant document."""
        for i, doc in enumerate(retrieved, start=1):
            if doc in relevant:
                return 1.0 / i
        return 0.0
    
    @staticmethod
    def dcg_at_k(relevances: List[float], k: int) -> float:
        """DCG@K: Discounted cumulative gain."""
        dcg = 0.0
        for i, rel in enumerate(relevances[:k], start=1):
            dcg += rel / math.log2(i + 1)
        return dcg
    
    @staticmethod
    def ndcg_at_k(retrieved: List[str], relevance: Dict[str, float], k: int) -> float:
        """nDCG@K: Normalized discounted cumulative gain."""
        if k <= 0:
            return 0.0
        
        retrieved_relevances = [relevance.get(doc, 0.0) for doc in retrieved[:k]]
        actual_dcg = RetrievalMetrics.dcg_at_k(retrieved_relevances, k)
        
        ideal_relevances = sorted(relevance.values(), reverse=True)[:k]
        ideal_dcg = RetrievalMetrics.dcg_at_k(ideal_relevances, k)
        
        return actual_dcg / ideal_dcg if ideal_dcg > 0 else 0.0
    
    @staticmethod
    def evaluate_all(
        retrieved: List[str],
        relevant: Set[str],
        relevance_scores: Dict[str, float] = None,
        k: int = 10
    ) -> Dict[str, float]:
        """Compute all metrics at once."""
        results = {
            f"recall@{k}": RetrievalMetrics.recall_at_k(retrieved, relevant, k),
            f"precision@{k}": RetrievalMetrics.precision_at_k(retrieved, relevant, k),
            f"f1@{k}": RetrievalMetrics.f1_at_k(retrieved, relevant, k),
            "mrr": RetrievalMetrics.mrr(retrieved, relevant),
        }
        
        if relevance_scores:
            results[f"ndcg@{k}"] = RetrievalMetrics.ndcg_at_k(
                retrieved, relevance_scores, k
            )
        
        return results
```
