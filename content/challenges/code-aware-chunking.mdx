## Code is NOT Prose

Standard chunking on code is a disaster:

```python
# Fixed-size chunk boundary falls HERE ↓
def calculate_total(items):
    total = 0
    for item in it    # CHUNK BOUNDARY
e ms:                   # New chunk starts mid-word!
        total += item
    return total
```

This chunk is **useless**. It won't compile, can't be understood, and the embedding is nonsense.

## The Insight: Program Structure

Code has **explicit structure**:

- Classes contain methods
- Functions contain logic
- Modules contain functions

These are natural, semantic units. Respect them!

## Mathematical Foundation

### Code Structure Graph

Code can be represented as a hierarchical graph:

$$
G = (N, E, T)
$$

Where:
- $N$ = Code units (functions, classes, modules)
- $E$ = Containment relationships (parent-child)
- $T: N \rightarrow \{\text{function}, \text{class}, \text{method}, \text{module}\}$ = Node type

### Chunk Quality Score

A good code chunk should be:

$$
\text{Quality}(c) = \alpha \cdot \text{Completeness}(c) + \beta \cdot \text{Independence}(c) + \gamma \cdot \text{Coherence}(c)
$$

Where:
- **Completeness**: Does it contain complete syntactic units?
- **Independence**: Can it be understood without external context?
- **Coherence**: Are the elements logically related?

### Optimal Chunk Boundaries

Chunk boundaries should align with:

$$
\text{Boundary} \in \{\text{function\_def}, \text{class\_def}, \text{import\_stmt}, \text{docstring}, \text{comment\_block}\}
$$

## Advanced Techniques

### AST-Based Chunking

```python
import ast
from dataclasses import dataclass
from typing import List, Dict, Optional, Tuple

@dataclass
class CodeChunk:
    content: str
    chunk_type: str  # function, class, method, import, docstring
    name: Optional[str]
    start_line: int
    end_line: int
    parent: Optional[str] = None
    dependencies: List[str] = None
    signature: Optional[str] = None

class ASTChunker:
    """Chunk code using Abstract Syntax Tree analysis."""
    
    def __init__(self, language: str = "python"):
        self.language = language
        self.parsers = {
            "python": self._chunk_python,
            "javascript": self._chunk_javascript,
            "typescript": self._chunk_typescript,
        }
    
    def chunk(self, code: str, language: str) -> List[CodeChunk]:
        """Chunk code in specified language."""
        parser = self.parsers.get(language)
        if not parser:
            raise ValueError(f"Unsupported language: {language}")
        return parser(code)
    
    def _chunk_python(self, code: str) -> List[CodeChunk]:
        """Python-specific chunking using AST."""
        chunks = []
        tree = ast.parse(code)
        lines = code.split('\n')
        
        for node in ast.walk(tree):
            if isinstance(node, (ast.FunctionDef, ast.AsyncFunctionDef)):
                chunk = self._extract_function(node, lines, "function")
                chunks.append(chunk)
            elif isinstance(node, ast.ClassDef):
                chunk = self._extract_class(node, lines)
                chunks.append(chunk)
            elif isinstance(node, ast.Import) or isinstance(node, ast.ImportFrom):
                chunk = self._extract_import(node, lines)
                if not chunks or chunks[-1].chunk_type != "import":
                    chunks.append(chunk)
                else:
                    # Merge consecutive imports
                    chunks[-1] = self._merge_chunks(chunks[-1], chunk)
        
        return sorted(chunks, key=lambda c: c.start_line)
    
    def _extract_function(self, node: ast.FunctionDef, lines: List[str], 
                         func_type: str) -> CodeChunk:
        """Extract a function as a chunk."""
        start_line = node.lineno - 1
        end_line = node.end_lineno
        
        # Get function signature
        signature = lines[start_line].strip()
        
        # Get full content
        content = '\n'.join(lines[start_line:end_line])
        
        # Extract dependencies (function calls)
        dependencies = self._extract_dependencies(node)
        
        return CodeChunk(
            content=content,
            chunk_type=func_type,
            name=node.name,
            start_line=start_line + 1,
            end_line=end_line,
            signature=signature,
            dependencies=dependencies
        )
    
    def _extract_dependencies(self, node: ast.AST) -> List[str]:
        """Extract function calls and imports from a node."""
        dependencies = []
        for child in ast.walk(node):
            if isinstance(child, ast.Call):
                if isinstance(child.func, ast.Name):
                    dependencies.append(child.func.id)
                elif isinstance(child.func, ast.Attribute):
                    dependencies.append(child.func.attr)
        return list(set(dependencies))
```

### Multi-Language Support with Tree-sitter

```python
from tree_sitter import Language, Parser
import tree_sitter_python as tspython
import tree_sitter_javascript as tsjavascript

class UniversalCodeChunker:
    """Multi-language code chunking using Tree-sitter."""
    
    def __init__(self):
        self.parsers = {
            "python": Parser(Language(tspython.language())),
            "javascript": Parser(Language(tsjavascript.language())),
        }
        
        # Query patterns for extracting chunks
        self.queries = {
            "python": """
                (function_definition) @function
                (class_definition) @class
                (import_statement) @import
                (import_from_statement) @import
            """,
            "javascript": """
                (function_declaration) @function
                (class_declaration) @class
                (method_definition) @method
                (import_statement) @import
            """,
        }
    
    def chunk(self, code: str, language: str) -> List[CodeChunk]:
        """Chunk code using Tree-sitter."""
        parser = self.parsers.get(language)
        if not parser:
            raise ValueError(f"Unsupported language: {language}")
        
        tree = parser.parse(bytes(code, "utf8"))
        query = parser.language.query(self.queries[language])
        captures = query.captures(tree.root_node)
        
        chunks = []
        for node, capture_name in captures:
            chunk = self._node_to_chunk(node, code, capture_name)
            if chunk:
                chunks.append(chunk)
        
        return sorted(chunks, key=lambda c: c.start_line)
```

### Context-Aware Chunking

```python
class ContextAwareChunker:
    """Include relevant context with each chunk."""
    
    def __init__(self, max_chunk_size: int = 1000):
        self.max_chunk_size = max_chunk_size
    
    def chunk_with_context(self, code: str, language: str) -> List[Dict]:
        """Create chunks with surrounding context."""
        base_chunks = self._get_base_chunks(code, language)
        enriched_chunks = []
        
        for i, chunk in enumerate(base_chunks):
            # Get imports that this chunk depends on
            relevant_imports = self._get_relevant_imports(chunk, base_chunks[:i])
            
            # Get class context if this is a method
            class_context = self._get_class_context(chunk, base_chunks)
            
            # Get docstring
            docstring = self._extract_docstring(chunk)
            
            # Build enriched chunk
            enriched = {
                "content": chunk.content,
                "type": chunk.chunk_type,
                "name": chunk.name,
                "context": {
                    "imports": relevant_imports,
                    "class": class_context,
                    "docstring": docstring,
                },
                "metadata": {
                    "language": language,
                    "line_range": (chunk.start_line, chunk.end_line),
                    "dependencies": chunk.dependencies,
                }
            }
            
            enriched_chunks.append(enriched)
        
        return enriched_chunks
    
    def _get_relevant_imports(self, chunk: CodeChunk, 
                              previous_chunks: List[CodeChunk]) -> List[str]:
        """Find imports that this chunk's dependencies need."""
        imports = []
        for prev in previous_chunks:
            if prev.chunk_type == "import":
                # Check if any dependency matches this import
                for dep in chunk.dependencies or []:
                    if dep in prev.content:
                        imports.append(prev.content)
                        break
        return imports
```

## Common Pitfalls

1. **Splitting Multi-line Strings**: Breaking docstrings or string literals
2. **Losing Import Context**: Functions without their imports
3. **Nested Structure Issues**: Methods separated from their class
4. **Decorators Detached**: @decorator separated from function
5. **Comments Orphaned**: Comments separated from relevant code

## Interview Questions

**Q1: How would you handle a function that exceeds your chunk size limit?**

*Answer:*
- Extract signature + docstring as overview chunk
- Split body into logical blocks (if/else branches, loops)
- Include "continued" markers
- Maintain cross-references between chunks
- Consider refactoring suggestion

**Q2: Design a chunking strategy for a codebase with 1M lines of code.**

*Answer:*
- Parse at module level first
- Chunk by class/function within modules
- Build dependency graph for cross-references
- Index with hierarchical structure
- Cache parsed ASTs
- Incremental updates on file changes

**Q3: How do you ensure related functions stay together?**

*Answer:*
- Call graph analysis to find clusters
- Cohesion metrics (shared variables, calls)
- Semantic similarity of docstrings
- File/module boundaries
- User-defined grouping (e.g., @group decorator)
