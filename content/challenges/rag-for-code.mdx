## Code RAG Challenges

Code is different from prose:

- **Structured**: Functions, classes, imports
- **Interdependent**: References across files
- **Precise**: Syntax errors break everything
- **Multi-language**: Python, JS, SQL, etc.

## Code-Aware Chunking

### Function-Level Chunking

```python
import ast
from dataclasses import dataclass

@dataclass
class CodeChunk:
    content: str
    chunk_type: str  # function, class, module
    name: str
    file_path: str
    start_line: int
    end_line: int
    dependencies: list[str]

def chunk_python_file(file_path: str, code: str) -> list[CodeChunk]:
    """Chunk Python code at function/class level."""
    tree = ast.parse(code)
    chunks = []

    for node in ast.walk(tree):
        if isinstance(node, ast.FunctionDef):
            chunk = CodeChunk(
                content=ast.get_source_segment(code, node),
                chunk_type="function",
                name=node.name,
                file_path=file_path,
                start_line=node.lineno,
                end_line=node.end_lineno,
                dependencies=extract_dependencies(node)
            )
            chunks.append(chunk)

        elif isinstance(node, ast.ClassDef):
            chunk = CodeChunk(
                content=ast.get_source_segment(code, node),
                chunk_type="class",
                name=node.name,
                file_path=file_path,
                start_line=node.lineno,
                end_line=node.end_lineno,
                dependencies=extract_dependencies(node)
            )
            chunks.append(chunk)

    return chunks

def extract_dependencies(node) -> list[str]:
    """Extract imported names and function calls."""
    deps = []
    for child in ast.walk(node):
        if isinstance(child, ast.Name):
            deps.append(child.id)
        elif isinstance(child, ast.Attribute):
            deps.append(child.attr)
    return list(set(deps))
```

### Tree-Sitter for Multiple Languages

```python
from tree_sitter import Language, Parser

class UniversalCodeChunker:
    def __init__(self):
        self.parsers = {
            "python": Parser(Language("python")),
            "javascript": Parser(Language("javascript")),
            "typescript": Parser(Language("typescript")),
            "go": Parser(Language("go")),
        }

        self.chunk_queries = {
            "python": "(function_definition) @func (class_definition) @class",
            "javascript": "(function_declaration) @func (class_declaration) @class",
            "typescript": "(function_declaration) @func (class_declaration) @class",
            "go": "(function_declaration) @func (method_declaration) @method",
        }

    def chunk(self, code: str, language: str) -> list[CodeChunk]:
        """Chunk code using tree-sitter."""
        parser = self.parsers[language]
        tree = parser.parse(bytes(code, "utf-8"))
```

## Mathematical Foundation

### Code Retrieval Scoring

Code retrieval combines multiple signals:

$$
\text{Score}(q, c) = \alpha \cdot \text{semantic\_sim}(q, c) + \beta \cdot \text{syntax\_match}(q, c) + \gamma \cdot \text{importance}(c)
$$

Where:
- $\text{semantic\_sim}$ = Embedding similarity between query and code
- $\text{syntax\_match}$ = AST pattern matching score
- $\text{importance}(c)$ = PageRank-style importance in codebase

### Code Embeddings

Code embeddings should capture:

$$
\text{CodeEmbed}(c) = f_{\text{encoder}}(\text{AST}(c) + \text{Docstring}(c) + \text{Context}(c))
$$

Specialized code embedding models (CodeBERT, GraphCodeBERT, CodeT5) are trained on:
- Code-to-code similarity
- Code-to-text alignment
- Code execution semantics

### Dependency Graph

Code dependencies form a directed graph:

$$
G = (F, D)
$$

Where:
- $F$ = Set of functions/files
- $D$ = Dependency edges (imports, calls, inheritance)

The importance of a code unit can be computed using PageRank:

$$
\text{Importance}(f) = \frac{1-d}{|F|} + d \sum_{f' \in \text{In}(f)} \frac{\text{Importance}(f')}{|\text{Out}(f')|}
$$

## Complexity Analysis

| Operation | Time Complexity | Space Complexity |
|-----------|-----------------|------------------|
| AST parsing | O(n) | O(n) |
| Dependency extraction | O(n × d) | O(d) |
| Code embedding | O(n) | O(e) |
| Graph construction | O(f²) | O(f²) |
| Retrieval | O(f log f) | O(k) |

Where:
- n = code size in tokens
- d = average dependencies per unit
- e = embedding dimension
- f = number of code units (functions/files)
- k = top-k results

## Common Pitfalls

1. **Syntax-Agnostic Chunking**: Splitting code mid-function
2. **Missing Context**: Retrieving functions without their imports
3. **Language Confusion**: Mixing language-specific patterns
4. **Version Mismatch**: Code from different API versions
5. **Test vs Production**: Retrieving test code for production queries

## Advanced Techniques

### Cross-File Context

```python
class CrossFileRAG:
    """RAG that understands cross-file dependencies."""
    
    def __init__(self, codebase_path: str):
        self.codebase_path = codebase_path
        self.dependency_graph = self._build_dependency_graph()
        self.chunk_index = self._index_chunks()
    
    def retrieve_with_context(self, query: str, file_path: str) -> list[dict]:
        """Retrieve code with cross-file context."""
        # Get initial results
        base_results = self.chunk_index.search(query, k=5)
        
        # Expand with dependencies
        expanded = []
        for result in base_results:
            expanded.append(result)
            
            # Add imported modules
            for dep in result.get("dependencies", []):
                dep_chunk = self._find_definition(dep)
                if dep_chunk:
                    expanded.append(dep_chunk)
            
            # Add callers (who uses this function)
            callers = self.dependency_graph.get_callers(result["name"])
            for caller in callers[:2]:  # Limit to top 2
                expanded.append(self._get_chunk(caller))
        
        return expanded
    
    def _build_dependency_graph(self) -> nx.DiGraph:
        """Build import/call dependency graph."""
        G = nx.DiGraph()
        
        for file_path in self._get_all_files():
            chunks = self._parse_file(file_path)
            for chunk in chunks:
                G.add_node(chunk["name"], chunk=chunk)
                
                for dep in chunk.get("dependencies", []):
                    G.add_edge(chunk["name"], dep)
        
        return G
```

### Type-Aware Retrieval

```python
class TypeAwareRetriever:
    """Use type information to improve code retrieval."""
    
    def __init__(self):
        self.type_index = {}
    
    def index_types(self, code_chunks: list[dict]):
        """Extract and index type signatures."""
        for chunk in code_chunks:
            if chunk["type"] == "function":
                signature = self._extract_signature(chunk["content"])
                self.type_index[chunk["name"]] = signature
    
    def retrieve_by_types(self, query_types: dict) -> list[dict]:
        """Find functions matching type constraints."""
        matches = []
        
        for name, signature in self.type_index.items():
            score = self._type_match_score(query_types, signature)
            if score > 0.7:
                matches.append({"name": name, "score": score})
        
        return sorted(matches, key=lambda x: x["score"], reverse=True)
    
    def _extract_signature(self, code: str) -> dict:
        """Extract function signature with types."""
        # Parse: def func(arg1: Type1, arg2: Type2) -> ReturnType
        pattern = r'def\s+(\w+)\s*\((.*?)\)\s*(?:->\s*(\w+))?'
        match = re.search(pattern, code)
        
        if match:
            return {
                "name": match.group(1),
                "args": self._parse_args(match.group(2)),
                "return": match.group(3) or "Any"
            }
        return {}
```

### Execution-Aware Retrieval

```python
class ExecutionAwareRAG:
    """Use code execution traces for better retrieval."""
    
    def __init__(self):
        self.execution_traces = []
    
    def capture_trace(self, code: str, test_cases: list):
        """Capture execution trace for code."""
        trace = []
        
        # Instrument code
        instrumented = self._instrument_code(code)
        
        for test in test_cases:
            # Run with tracing
            result = self._run_with_trace(instrumented, test)
            trace.append(result)
        
        self.execution_traces.append({
            "code": code,
            "trace": trace
        })
    
    def retrieve_by_behavior(self, desired_behavior: str) -> list[dict]:
        """Find code with similar execution patterns."""
        # Embed execution traces
        trace_embeddings = [
            self._embed_trace(t["trace"]) 
            for t in self.execution_traces
        ]
        
        # Find similar behaviors
        query_emb = self.embed(desired_behavior)
        similarities = cosine_similarity([query_emb], trace_embeddings)[0]
        
        # Return top matches
        indices = np.argsort(similarities)[::-1][:5]
        return [self.execution_traces[i] for i in indices]
```

## Interview Questions

**Q1: How would you handle a query about a design pattern across multiple languages?**

*Answer:*
- Extract pattern semantics from query
- Retrieve examples in target language
- Cross-reference with canonical implementations
- Show language-specific idioms
- Include anti-patterns to avoid

**Q2: Design a system that explains code changes (diffs) using RAG.**

*Answer:*
- Index codebase at multiple versions
- Retrieve context for changed lines
- Use diff to identify semantic changes
- Generate explanation of what changed and why
- Link to related documentation/tests

**Q3: How do you prevent retrieving outdated code patterns?**

*Answer:*
- Index with version metadata
- Prioritize recent code in ranking
- Filter by deprecation status
- Use temporal embeddings
- Flag potentially outdated patterns
