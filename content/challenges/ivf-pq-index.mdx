## The Scale Problem

HNSW is excellent, but at **1 billion vectors × 1536 dimensions × 4 bytes** = **6 TB of RAM**. That's not feasible for most teams.

**IVF-PQ** trades some accuracy for **10-50x memory reduction**.

## How IVF-PQ Works

### Step 1: IVF (Inverted File Index)

1. Cluster all vectors into `nlist` centroids (typically √N to 4√N)
2. At query time, find the `nprobe` closest centroids
3. Only search vectors within those clusters

```
Corpus: 1M vectors, nlist=1000, nprobe=10
→ Search only ~10K vectors instead of 1M (100x speedup)
```

### Step 2: PQ (Product Quantization)

1. Split each 1536-dim vector into `M` subspaces (e.g., M=48, each 32-dim)
2. Cluster each subspace into 256 centroids (1 byte each)
3. Store only the centroid IDs (48 bytes instead of 6144 bytes = **128x compression**)

## The Algorithm

```python
import numpy as np
from typing import List, Tuple

class IVFPQIndex:
    """
    Inverted File Index with Product Quantization.
    
    Time Complexity:
    - Indexing: O(N × nlist × d) for IVF + PQ training
    - Search: O(nprobe × (N/nlist) × M) for PQ distance lookup
    
    Space Complexity: O(N × M) for codes + O(nlist × d) for centroids + PQ codebooks
    """
    
    def __init__(self, dim: int, nlist: int = 100, m: int = 8, nbits: int = 8):
        self.dim = dim
        self.nlist = nlist  # IVF clusters
        self.m = m  # Number of subquantizers
        self.nbits = nbits  # Bits per code (usually 8 = 256 centroids)
        self.nprobe = 10
        
        assert dim % m == 0, "dim must be divisible by m"
        self.sub_dim = dim // m
        
        self.coarse_centroids = None
        self.pq_codebooks = None  # m × 256 × sub_dim
        self.inverted_lists = {}  # centroid_id -> [(vector_id, pq_codes)]
    
    def _train_pq(self, vectors: np.ndarray):
        """Train PQ codebooks for each subspace."""
        self.pq_codebooks = []
        
        for i in range(self.m):
            # Extract subspace
            sub_vectors = vectors[:, i * self.sub_dim:(i + 1) * self.sub_dim]
            
            # K-means with 256 centroids
            from sklearn.cluster import KMeans
            kmeans = KMeans(n_clusters=256, random_state=42, n_init=10)
            kmeans.fit(sub_vectors)
            
            self.pq_codebooks.append(kmeans.cluster_centers_)
    
    def _encode_pq(self, vector: np.ndarray) -> List[int]:
        """Encode vector to PQ codes."""
        codes = []
        for i in range(self.m):
            sub_vec = vector[i * self.sub_dim:(i + 1) * self.sub_dim]
            # Find nearest centroid in subspace
            distances = np.linalg.norm(self.pq_codebooks[i] - sub_vec, axis=1)
            codes.append(int(np.argmin(distances)))
        return codes
    
    def _pq_distance(self, query: np.ndarray, codes: List[int]) -> float:
        """Compute approximate distance using PQ codes."""
        distance = 0.0
        for i, code in enumerate(codes):
            sub_query = query[i * self.sub_dim:(i + 1) * self.sub_dim]
            centroid = self.pq_codebooks[i][code]
            distance += np.linalg.norm(sub_query - centroid) ** 2
        return distance ** 0.5
    
    def train(self, vectors: List[List[float]]):
        """Train IVF centroids and PQ codebooks."""
        vectors_np = np.array(vectors)
        
        # Train coarse quantizer (IVF)
        from sklearn.cluster import KMeans
        kmeans = KMeans(n_clusters=self.nlist, random_state=42, n_init=10)
        kmeans.fit(vectors_np)
        self.coarse_centroids = kmeans.cluster_centers_
        
        # Train PQ codebooks
        self._train_pq(vectors_np)
    
    def add(self, vectors: List[List[float]], ids: List[int] = None):
        """Add vectors to the index."""
        if ids is None:
            ids = list(range(len(vectors)))
        
        for vid, vec in zip(ids, vectors):
            vec_np = np.array(vec)
            
            # Assign to coarse centroid
            distances = np.linalg.norm(self.coarse_centroids - vec_np, axis=1)
            coarse_id = int(np.argmin(distances))
            
            # Encode with PQ
            pq_codes = self._encode_pq(vec_np)
            
            # Add to inverted list
            if coarse_id not in self.inverted_lists:
                self.inverted_lists[coarse_id] = []
            self.inverted_lists[coarse_id].append((vid, pq_codes))
    
    def search(self, query: List[float], k: int = 10) -> List[Tuple[int, float]]:
        """Search for k nearest neighbors."""
        query_np = np.array(query)
        
        # Find nprobe nearest coarse centroids
        coarse_distances = np.linalg.norm(self.coarse_centroids - query_np, axis=1)
        nearest_coarse = np.argsort(coarse_distances)[:self.nprobe]
        
        # Search in selected clusters using PQ distances
        candidates = []
        for cid in nearest_coarse:
            for vid, pq_codes in self.inverted_lists.get(cid, []):
                dist = self._pq_distance(query_np, pq_codes)
                candidates.append((vid, dist))
        
        # Return top k
        candidates.sort(key=lambda x: x[1])
        return candidates[:k]
```

## Complexity Analysis

| Aspect | Complexity | Notes |
|--------|------------|-------|
| Training | O(N × nlist × d + N × M × 256 × sub_dim) | IVF + PQ |
| Indexing | O(N × nlist × d + N × M × 256) | Assign + encode |
| Search | O(nprobe × (N/nlist) × M) | PQ lookup |
| Space | O(N × M + nlist × d + M × 256 × sub_dim) | Compressed |

## IVF-PQ vs HNSW Comparison

| Aspect            | HNSW                      | IVF-PQ                 | IVF-HNSW-PQ        |
| ----------------- | ------------------------- | ---------------------- | ------------------ |
| **Memory**        | ~1.2x raw vectors         | ~0.1x raw vectors      | ~0.15x raw vectors |
| **Build time**    | Slow (graph construction) | Fast (clustering)      | Medium             |
| **Query latency** | ~1-5ms                    | ~5-20ms                | ~2-10ms            |
| **Recall@10**     | 95-99%                    | 85-95%                 | 90-97%             |
| **Update cost**   | Expensive                 | Cheap                  | Medium             |
| **Best for**      | <100M, latency-critical   | >100M, memory-critical | Balance            |

## FAISS Index Types Cheat Sheet

### For Development/Prototyping

```python
# Exact search (slow but 100% accurate)
index = faiss.IndexFlatL2(dim)  # or IndexFlatIP for cosine
```

### For Production (<10M vectors)

```python
# HNSW — best recall/latency tradeoff
index = faiss.IndexHNSWFlat(dim, M=32)  # M=16-64
index.hnsw.efConstruction = 200  # build quality
index.hnsw.efSearch = 64  # query quality
```

### For Scale (10M-1B vectors)

```python
# IVF-PQ — memory efficient
nlist = int(np.sqrt(n_vectors))  # number of clusters
m = 48  # subquantizers (dim must be divisible by m)
quantizer = faiss.IndexFlatL2(dim)
index = faiss.IndexIVFPQ(quantizer, dim, nlist, m, 8)
index.nprobe = 10  # clusters to search (higher = better recall)
```

### For Scale + Quality

```python
# IVF-HNSW-PQ — best of both worlds
quantizer = faiss.IndexHNSWFlat(dim, 32)
index = faiss.IndexIVFPQ(quantizer, dim, nlist, m, 8)
```

## Tuning Parameters

### IVF Parameters

| Parameter | Values     | Effect                             |
| --------- | ---------- | ---------------------------------- |
| `nlist`   | √N to 4√N  | More = better recall, slower build |
| `nprobe`  | 1 to nlist | More = better recall, slower query |

**Rule of thumb**: `nprobe = nlist / 10` for 90%+ recall

### PQ Parameters

| Parameter           | Values            | Effect                              |
| ------------------- | ----------------- | ----------------------------------- |
| `m` (subquantizers) | 8, 16, 32, 48, 64 | More = better accuracy, more memory |
| `nbits`             | 8 (256 centroids) | Standard, rarely changed            |

## Recall vs Memory Tradeoff (1B vectors, 768-dim)

| Index Type    | Memory | Recall@10 | QPS  |
| ------------- | ------ | --------- | ---- |
| Flat          | 3 TB   | 100%      | 1    |
| HNSW          | 3.6 TB | 98%       | 1000 |
| IVF-PQ (m=32) | 40 GB  | 88%       | 500  |
