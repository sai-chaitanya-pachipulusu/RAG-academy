# Challenge: Context Recall Calculator

Implement the **Context Recall** metric from the RAGAS framework. Context recall measures how well the retrieved context covers the ground truth answer.

## Formula

$$\text{Context Recall} = \frac{|\text{GT sentences attributable to context}|}{|\text{Total sentences in GT}|}$$

## Task

1. Splits the ground truth into individual statements

```python
def simple_checker(stmt, ctx):
    """Check if statement keywords appear in context."""
    keywords = [w.lower() for w in stmt.split() if len(w) > 3]
    ctx_lower = ctx.lower()
    return sum(1 for k in keywords if k in ctx_lower) >= len(keywords) * 0.5

# Test 1: Perfect recall
context1 = "France is in Western Europe. Paris is its capital city."
gt1 = "France is in Western Europe. Its capital is Paris."
assert abs(context_recall(context1, gt1, simple_checker) - 1.0) < 0.01

# Test 2: Partial recall
context2 = "France is in Western Europe. Known for wine and cheese."
gt2 = "France is in Western Europe. Its capital is Paris."
assert abs(context_recall(context2, gt2, simple_checker) - 0.5) < 0.01

# Test 3: Zero recall
context3 = "Germany is in Central Europe. Berlin is its capital."

# Test 4: Empty ground truth
context4 = "Some context here."
gt4 = ""
assert context_recall(context4, gt4, simple_checker) == 0.0
```
