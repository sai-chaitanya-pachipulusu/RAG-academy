## Key Concepts

### BEIR Dataset Format

```python
from dataclasses import dataclass
from typing import Dict

@dataclass
class BEIRDataset:
    name: str
    queries: Dict[str, str]        # query_id -> query_text
    corpus: Dict[str, str]         # doc_id -> doc_text
    qrels: Dict[str, Dict[str, int]]  # query_id -> {doc_id: relevance}
```

### Standard Metrics

| Metric | Description | Target |
|--------|-------------|--------|
| **nDCG@10** | Primary ranking metric | > 0.40 |
| **Recall@10** | Coverage of relevant documents | > 0.70 |
| **Precision@10** | Accuracy of top results | > 0.30 |
| **MRR** | Position of first relevant result | > 0.60 |

## Complexity Analysis

| Operation | Time Complexity | Space Complexity |
|-----------|-----------------|------------------|
| Dataset loading | O(D + Q + R) | O(D + Q + R) |
| Evaluation per query | O(K × log D) | O(K) |
| Full benchmark | O(Q × K × log D) | O(D) |

Where D = documents, Q = queries, R = relevance judgments, K = cutoff

## Implementation

```python
from typing import Dict, List, Set, Tuple
from dataclasses import dataclass
import json

@dataclass
class BEIRDataset:
    """BEIR dataset structure."""
    name: str
    queries: Dict[str, str]
    corpus: Dict[str, str]
    qrels: Dict[str, Dict[str, int]]


class BEIREvaluator:
    """Evaluate retrievers on BEIR datasets."""
    
    def __init__(self, dataset: BEIRDataset):
        self.dataset = dataset
    
    def evaluate(
        self,
        retriever_fn,
        k: int = 10,
        metrics: List[str] = None
    ) -> Dict[str, float]:
        """
        Evaluate a retriever on the BEIR dataset.
        
        Args:
            retriever_fn: Function(query) -> List[doc_id]
            k: Cutoff for metrics
            metrics: List of metric names to compute
        
        Returns:
            Dictionary of metric names to scores
        """
        if metrics is None:
            metrics = ["ndcg@10", "map@10", "recall@10", "precision@10"]
        
        results = {metric: [] for metric in metrics}
        
        for query_id, query_text in self.dataset.queries.items():
            # Retrieve documents
            retrieved = retriever_fn(query_text)[:k]
            
            # Get ground truth
            relevant = self.dataset.qrels.get(query_id, {})
            relevant_set = {doc_id for doc_id, rel in relevant.items() if rel > 0}
            
            # Compute metrics
            if "recall@10" in metrics:
                results["recall@10"].append(
                    self._recall_at_k(retrieved, relevant_set, k)
                )
            if "precision@10" in metrics:
                results["precision@10"].append(
                    self._precision_at_k(retrieved, relevant_set, k)
                )
            # ... other metrics
        
        # Average across queries
        return {metric: sum(scores) / len(scores) 
                for metric, scores in results.items()}
    
    def _recall_at_k(self, retrieved: List[str], relevant: Set[str], k: int) -> float:
        """Compute Recall@K."""
        if not relevant:
            return 1.0
        top_k = set(retrieved[:k])
        return len(top_k & relevant) / len(relevant)
    
    def _precision_at_k(self, retrieved: List[str], relevant: Set[str], k: int) -> float:
        """Compute Precision@K."""
        if not retrieved:
            return 0.0
        top_k = retrieved[:k]
        relevant_count = sum(1 for doc in top_k if doc in relevant)
        return relevant_count / len(top_k)
```

```python
from typing import Dict, List, Set
from dataclasses import dataclass

@dataclass
class BEIRDataset:
    """BEIR dataset structure."""
    name: str
    queries: Dict[str, str]
    corpus: Dict[str, str]
    qrels: Dict[str, Dict[str, int]]


class BEIREvaluator:
    """Evaluate retrievers on BEIR datasets."""
    
    def __init__(self, dataset: BEIRDataset):
        self.dataset = dataset
    
    def evaluate(self, retriever_fn, k: int = 10) -> Dict[str, float]:
        """Evaluate a retriever on the BEIR dataset."""
        recall_scores = []
        precision_scores = []
        
        for query_id, query_text in self.dataset.queries.items():
            # Retrieve documents
            retrieved = retriever_fn(query_text)[:k]
            
            # Get ground truth
            relevant = self.dataset.qrels.get(query_id, {})
            relevant_set = {doc_id for doc_id, rel in relevant.items() if rel > 0}
            
            # Compute metrics
            recall_scores.append(
                self._recall_at_k(retrieved, relevant_set, k)
            )
            precision_scores.append(
                self._precision_at_k(retrieved, relevant_set, k)
            )
        
        return {
            f"recall@{k}": sum(recall_scores) / len(recall_scores),
            f"precision@{k}": sum(precision_scores) / len(precision_scores)
        }
    
    def _recall_at_k(self, retrieved: List[str], relevant: Set[str], k: int) -> float:
        """Compute Recall@K."""
        if not relevant:
            return 1.0
        top_k = set(retrieved[:k])
        return len(top_k & relevant) / len(relevant)
    
    def _precision_at_k(self, retrieved: List[str], relevant: Set[str], k: int) -> float:
        """Compute Precision@K."""
        if not retrieved:
            return 0.0
        top_k = retrieved[:k]
```

## Production Tips

1. **Start small**: Test on SciFact or NFCorpus before running on MS MARCO
2. **Cache embeddings**: Pre-compute and cache document embeddings
3. **Parallelize**: Use multiprocessing for query evaluation
4. **Track variance**: Report mean ± std across multiple runs
5. **Compare baselines**: Always include BM25 as a baseline
