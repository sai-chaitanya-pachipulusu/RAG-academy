# Reasoning RAG Implementation

Traditional RAG retrieves once and generates. This fails for complex questions that require connecting information from multiple sources.

**Your task**: Build a Reasoning RAG system that thinks, retrieves iteratively, and verifies its answers.

## Requirements

1. **Multi-hop retrieval**: Must retrieve from multiple documents when needed
2. **Reasoning trace**: Return full trace of thinking steps
3. **Verification**: Check that answer is supported by retrieved docs
4. **Citations**: Include source document IDs in final answer

<summary>Hint 1: Simple retrieval</summary>

For this exercise, use keyword matching:

```python
def retrieve(self, query: str, k: int = 3) -> List[Document]:
    query_terms = set(query.lower().split())
    scores = []
    for doc in self.documents:
        doc_terms = set(doc.content.lower().split())
        overlap = len(query_terms & doc_terms)
        scores.append((doc, overlap))
    scores.sort(key=lambda x: x[1], reverse=True)
    return [doc for doc, score in scores[:k] if score > 0]
```

Use a simple state machine:

```python
def plan_next_step(self, question: str, steps: List[ReasoningStep]):
    # No steps yet → start with retrieval
    if not steps:
        return ReasoningStep("Need initial information", "retrieve", question)
    
    # Just retrieved → reason about what we have
    if steps[-1].action == "retrieve":
        return ReasoningStep("Analyze gathered info", "reason")
    
    # Just reasoned → check if we have gaps
    if steps[-1].action == "reason":
        if "missing" in steps[-1].result.lower():
```

## Test Your Solution

```python
def test_reasoning_rag():
    rag = ReasoningRAG(DOCUMENTS)
    
    for test in TEST_QUESTIONS:
        print(f"\n{'='*60}")
        print(f"Question: {test['question']}")
        
        trace = rag.answer(test['question'])
        
        print(f"\nReasoning Steps: {len(trace.steps)}")
        for i, step in enumerate(trace.steps):
            print(f"  {i+1}. [{step.action}] {step.thought}")
        
        print(f"\nDocuments used: {trace.documents_used}")
        print(f"Answer: {trace.final_answer[:200]}...")
        
        # Check required docs were retrieved
        required = set(test['requires'])
        retrieved = set(trace.documents_used)
        coverage = len(required & retrieved) / len(required)
        print(f"Document coverage: {coverage:.0%}")
        
        # Check expected facts are in answer
        facts_found = sum(1 for fact in test['expected_facts'] 
                        if fact.lower() in trace.final_answer.lower())
        fact_coverage = facts_found / len(test['expected_facts'])
        print(f"Fact coverage: {fact_coverage:.0%}")
        
        assert coverage >= 0.6, f"Document coverage {coverage:.0%} too low"
        assert fact_coverage >= 0.5, f"Fact coverage {fact_coverage:.0%} too low"
    
    print("\n✓ All tests passed!")

test_reasoning_rag()
```
