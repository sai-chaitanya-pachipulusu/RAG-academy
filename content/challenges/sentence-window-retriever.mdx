# Challenge: Sentence Window Retriever

Implement a **Sentence-Window Retriever** that embeds individual sentences but returns surrounding context windows during retrieval.

## Concept

The key insight: Small chunks (sentences) embed more precisely, but lack context for the LLM. The solution is to **embed small, retrieve big**.

```
Document: "A. B. C. D. E."  (5 sentences)

Ingestion:
  - Embed "A." → v1
  - Embed "B." → v2
  - etc.

Retrieval (window_size=1):
  - Query matches "C."
  - Return: "B. C. D."  (1 before + match + 1 after)
```

```python
import numpy as np

def simple_embed(text: str) -> np.ndarray:
    """Simple embedding: hash-based for deterministic testing."""
    np.random.seed(hash(text) % (2**32))
    return np.random.randn(64)

# Test 1: Basic indexing
retriever = SentenceWindowRetriever(simple_embed, window_size=1)
count = retriever.add_document("doc1", "First sentence. Second sentence. Third sentence.")
assert count == 3

# Test 2: Window retrieval
retriever2 = SentenceWindowRetriever(simple_embed, window_size=1)
retriever2.add_document("doc1", "A. B. C. D. E.")
windows = retriever2.retrieve("C", top_k=1)
assert len(windows) == 1
# Window should contain surrounding sentences
assert "C" in windows[0]

# Test 3: Window at document start (no left context)
retriever3 = SentenceWindowRetriever(simple_embed, window_size=2)
retriever3.add_document("doc1", "Start. Middle. End.")
windows3 = retriever3.retrieve("Start", top_k=1)
# Should not crash, should contain "Start"
assert "Start" in windows3[0]

# Test 4: Window at document end (no right context)
windows4 = retriever3.retrieve("End", top_k=1)
assert "End" in windows4[0]

# Test 5: Multi-document
retriever5 = SentenceWindowRetriever(simple_embed, window_size=1)
retriever5.add_document("doc1", "Doc one content. More doc one.")
retriever5.add_document("doc2", "Doc two here. And more two.")
assert len(retriever5.sentence_embeddings) == 4
```
