## Why this matters in production

Most embedding retrieval uses cosine similarity, but Euclidean distance is the cleanest way to build intuition:

- distance 0 means identical vectors
- larger distance means less similar

Some vector DBs can operate in Euclidean/L2 space, and many ANN indexes support it directly.

## What you're implementing

```
L2(a,b) = sqrt(Σ(a_i - b_i)²)
```

Rules:

- mismatched lengths → `ValueError`
- `distance([], []) == 0.0`

## The Algorithm

```python
import math

def euclidean_distance(a: list[float], b: list[float]) -> float:
    """
    Compute Euclidean (L2) distance between two vectors.
    
    Time Complexity: O(N) where N = vector dimension
    Space Complexity: O(1) additional
    
    Args:
        a: First vector
        b: Second vector
        
    Returns:
        Euclidean distance (>= 0)
        
    Raises:
        ValueError: If vectors have different lengths
    """
    if len(a) != len(b):
        raise ValueError(f"Vector length mismatch: {len(a)} vs {len(b)}")
    
    return math.sqrt(sum((x - y) ** 2 for x, y in zip(a, b)))
```

## Complexity Analysis

| Aspect | Complexity | Notes |
|--------|------------|-------|
| Time | O(N) | Single pass with subtraction and squaring |
| Space | O(1) | No additional storage |
| Range | [0, ∞) | 0 = identical, larger = more different |

## Real-World Applications

| Use Case | Why Euclidean? |
|----------|----------------|
| **Geospatial search** (Uber, Google Maps) | Physical distance matters |
| **K-Means clustering** | Minimizes within-cluster variance |
| **Anomaly detection** | Outliers have large distances from centroids |
| **Image similarity** | Pixel-level differences matter |

## When to Use Which Metric

| Scenario | Recommended Metric |
|----------|-------------------|
| Semantic text similarity | Cosine similarity |
| Geospatial/physical distance | Euclidean distance |
| Normalized embeddings | Dot product (fastest) |
| Clustering | Euclidean or Cosine |
| Recommendation systems | Cosine or Pearson correlation |

## Relationship to Cosine Similarity

For **normalized vectors** (unit length):

```
||a - b||² = 2 - 2 × cos(θ)
```

This means:
- Euclidean distance and cosine are monotonically related for normalized vectors
- Minimizing Euclidean distance = Maximizing cosine similarity
- Use dot product for speed when vectors are normalized

## Common pitfalls

- Forgetting the final square root.
- Using absolute differences instead of squared differences.
- Not handling the empty vector case.
