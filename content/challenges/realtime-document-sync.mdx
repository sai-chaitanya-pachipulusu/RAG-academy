# Real-Time Document Sync

Traditional RAG systems re-index documents in batches, leading to stale knowledge. Production systems need real-time updates.

**Your task**: Build an event-driven system that keeps the vector index in sync with document changes.

## Why Real-Time Sync Matters

| Use Case | Without Sync | With Real-Time Sync |
|----------|--------------|---------------------|
| Support tickets | 5-15 min delay | < 1 second |
| Knowledge base | Hourly batch | Instant updates |
| News RAG | Daily refresh | Streaming updates |
| Code changes | Nightly build | Commit-driven |

### Event Sources

- **Database CDC**: PostgreSQL logical replication, MySQL binlog
- **File systems**: iNotify, S3 events
- **Webhooks**: Stripe, GitHub, Notion API
- **Message queues**: Kafka, RabbitMQ, SQS

## Requirements

1. **Stable Chunking**: Same text → same chunk ID (deterministic hashing)
2. **Deduplication**: Skip processing if content hasn't changed
3. **Event Types**: Handle create, update, delete events
4. **Async Processing**: Non-blocking event queue
5. **Efficient Updates**: Only re-embed changed chunks

```python
def chunk_document(self, doc_id: str, content: str) -> List[Chunk]:
    chunks = []
    for i in range(0, len(content), self.chunk_size):
        text = content[i:i + self.chunk_size]
        # Stable ID based on doc_id and content position
        chunk_id = f"{doc_id}_{hashlib.md5(text.encode()).hexdigest()[:12]}"
        
        chunks.append(Chunk(
            id=chunk_id,
            doc_id=doc_id,
            text=text,
            embedding=mock_embed([text])[0],
            metadata={"position": i}
        ))
    return chunks
```

```python
async def process_event(self, event: DocumentEvent) -> bool:
    # Deduplication check
    content_hash = self.compute_content_hash(event.content or "")
    
    if event.doc_id in self.doc_versions:
        if self.doc_versions[event.doc_id] == content_hash:
            return False  # No change
    
    # Route to handler
    if event.type == "created":
        return await self.handle_create(event)
    elif event.type == "updated":
        return await self.handle_update(event)
    elif event.type == "deleted":
        return await self.handle_delete(event)
    
    return False
```

## Production Considerations

### Rate Limiting

```python
class RateLimitedSync(RealTimeRAGSync):
    def __init__(self, *args, max_embeddings_per_min=1000, **kwargs):
        super().__init__(*args, **kwargs)
        self.token_bucket = TokenBucket(max_embeddings_per_min)
    
    async def process_event(self, event):
        chunks = self.chunk_document(event.doc_id, event.content)
        
        if not await self.token_bucket.consume(len(chunks)):
            # Delay processing
            await asyncio.sleep(60)
            return await self.process_event(event)
        
        return await super().process_event(event)
```

### Error Handling

```python
class RobustSync(RealTimeRAGSync):
    def __init__(self, *args, retry_config=None, **kwargs):
        super().__init__(*args, **kwargs)
        self.retry_config = retry_config or RetryConfig(
            max_retries=3,
            backoff=ExponentialBackoff()
        )
        self.dlq = DeadLetterQueue()
    
    async def process_event(self, event):
        try:
            return await super().process_event(event)
        except Exception as e:
            if self.retry_config.should_retry(event, e):
                await self.retry(event)
            else:
                await self.dlq.enqueue(event, error=str(e))
```
