## Why this matters in production

LRU caches are everywhere: embedding caches, API caches, query result caches. Understanding this data structure helps you optimize RAG latency and cost.

## What you're implementing

- Get: retrieve value, mark as recently used.
- Set: add value, evict LRU if at capacity.
- Efficient O(1) operations using Map (preserves insertion order).

## Common pitfalls

- Not updating recency on get().
- Evicting wrong item (newest instead of oldest).
