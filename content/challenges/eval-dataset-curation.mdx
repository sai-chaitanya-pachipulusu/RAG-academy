## The Problem

A biased evaluation set gives misleading metrics. If all your test questions are easy, your RAG looks great—until it fails in production.

```
Eval Set: 100 questions about "API key rotation"
Result: 95% accuracy!
Reality: Model fails on 70% of other topics.
```

## Stratified Sampling

Sample equally from each category:

- **Topics**: Tech, Finance, HR, Legal...
- **Difficulty**: Easy, Medium, Hard.
- **Format**: Factoid, Multi-hop, Comparison...

## Diversity Measurement

**Type-Token Ratio**: `unique_words / total_words`

A diverse eval set has many unique words; a repetitive one doesn't.

## Complexity Analysis

| Operation | Time Complexity | Space Complexity |
|-----------|-----------------|------------------|
| Stratified sampling | O(N) | O(N) |
| Diversity calculation | O(T) | O(U) |
| Coverage analysis | O(N × C) | O(C) |

Where N = samples, T = total tokens, U = unique tokens, C = categories

## Implementation

```python
from typing import List, Dict, Any
from collections import defaultdict
import random

class DatasetCurator:
    """Curate diverse evaluation datasets."""
    
    def __init__(self, items: List[Dict[str, Any]]):
        """
        Initialize with candidate items.
        
        Args:
            items: List of dicts with 'category', 'difficulty', etc.
        """
        self.items = items
    
    def stratified_sample(
        self,
        n_per_stratum: int,
        stratify_by: str = "category"
    ) -> List[Dict[str, Any]]:
        """
        Sample equally from each stratum.
        
        Args:
            n_per_stratum: Number of samples per stratum
            stratify_by: Key to stratify by
        
        Returns:
            Stratified sample
        """
        # Group by stratum
        strata = defaultdict(list)
        for item in self.items:
            key = item.get(stratify_by, "unknown")
            strata[key].append(item)
        
        # Sample from each stratum
        sampled = []
        for stratum, items in strata.items():
            n = min(n_per_stratum, len(items))
            sampled.extend(random.sample(items, n))
        
        return sampled
    
    def compute_diversity(self, text_key: str = "text") -> Dict[str, float]:
        """
        Compute lexical diversity metrics.
        
        Returns:
            Dict with type-token ratio and other metrics
        """
        all_words = []
        for item in self.items:
            text = item.get(text_key, "")
            words = text.lower().split()
            all_words.extend(words)
        
        total_tokens = len(all_words)
        unique_tokens = len(set(all_words))
        
        return {
            "type_token_ratio": unique_tokens / total_tokens if total_tokens else 0,
            "total_tokens": total_tokens,
            "unique_tokens": unique_tokens
        }
    
    def analyze_coverage(self, key: str = "category") -> Dict[str, int]:
        """
        Analyze coverage across categories.
        
        Returns:
            Dict mapping category to count
        """
        coverage = defaultdict(int)
        for item in self.items:
            category = item.get(key, "unknown")
            coverage[category] += 1
        return dict(coverage)
    
    def balance_dataset(
        self,
        target_per_category: int,
        category_key: str = "category"
    ) -> List[Dict[str, Any]]:
        """
        Balance dataset by oversampling or undersampling.
        
        Args:
            target_per_category: Target samples per category
            category_key: Key for category
        
        Returns:
            Balanced dataset
        """
        # Group by category
        by_category = defaultdict(list)
        for item in self.items:
            cat = item.get(category_key, "unknown")
            by_category[cat].append(item)
        
        balanced = []
        for cat, items in by_category.items():
            if len(items) >= target_per_category:
                # Undersample
                balanced.extend(random.sample(items, target_per_category))
            else:
                # Oversample with replacement
                balanced.extend(
                    random.choices(items, k=target_per_category)
                )
        
        return balanced
```

## Why It Matters

Biased eval = false confidence → production failures → unhappy users.

### Best Practices

1. **Define strata upfront**: Know your categories before sampling
2. **Monitor diversity**: Track type-token ratio over time
3. **Validate coverage**: Ensure all categories represented
4. **Review edge cases**: Include hard examples intentionally
5. **Iterate**: Update eval set based on production failures
