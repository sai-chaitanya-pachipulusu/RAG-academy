# User Profile RAG

Generic RAG treats all users the same. A CEO and an intern asking "What's our sales performance?" should get different responses—executive summary vs. detailed explanation.

**Your task**: Build a RAG system that personalizes both retrieval and generation based on user profiles.

3. **Expertise adaptation**: Technical depth matches user level
4. **Relevance boosting**: Prioritize user's department and recent topics

def filter_accessible_documents(self, user: UserProfile, documents: List[Document]):
    accessible = []
    for doc in documents:
        # Check visibility
        if doc.metadata.get("visibility") == "all":
            accessible.append(doc)
            continue
        
        # Check department access
        doc_dept = doc.metadata.get("department")
        if doc_dept in user.accessible_departments:
            accessible.append(doc)
    
    return accessible

```python
def personalized_retrieve(self, user_id: str, query: str, k: int = 5):
    user = self.get_user_profile(user_id)
    
    # Filter accessible
    accessible = self.filter_accessible_documents(user, self.documents)
    
    # Score documents
    scored = []
    for doc in accessible:
        # Base relevance (keyword match)
        query_terms = set(query.lower().split())
        doc_terms = set(doc.content.lower().split())
        relevance = len(query_terms & doc_terms) / max(len(query_terms), 1)
        
        # Boost user's department
        if doc.metadata.get("department") == user.department:
            relevance *= 1.5
        
        # Boost recent topics
        for topic in user.recent_topics:
            if topic.lower() in doc.content.lower():
                relevance *= 1.2
                break
        
        scored.append((doc, relevance))
    
    scored.sort(key=lambda x: x[1], reverse=True)
    return [doc for doc, score in scored[:k]]
```

def build_system_prompt(self, user: UserProfile) -> str:
    # Style instructions
    style_map = {
        ResponseStyle.CONCISE: "Be brief. Use bullet points. No fluff.",
        ResponseStyle.DETAILED: "Provide thorough explanations with examples.",
        ResponseStyle.CONVERSATIONAL: "Be friendly and approachable."
    }
    
    # Expertise instructions
    expertise_map = {
        ExpertiseLevel.BEGINNER: "Explain technical terms. Use simple language.",
        ExpertiseLevel.INTERMEDIATE: "Assume basic knowledge. Define advanced terms.",
        ExpertiseLevel.EXPERT: "Use technical language freely. Skip basics."
    }
    
    return f"""You are an assistant for {user.name} ({user.role}).

Style: {style_map[user.preferred_style]}
Expertise: {expertise_map[user.expertise_level]}

Adapt your response to their role and expertise level."""
