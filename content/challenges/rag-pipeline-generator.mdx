## Stage 4: The Generator

The final step of the RAG (Retrieval-Augmented Generation) loop is the **Generation**. This is where you feed the retrieved chunks and the user query into an LLM to get a human-readable answer.

## Task

Implement the `generate` and the final `run` methods. The `run` method should coordinate the entire flow:
`Input Text -> Chunk -> Embed -> (Query) -> Retrieve -> Context -> Generate`.
