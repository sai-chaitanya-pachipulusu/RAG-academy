# Graph-O1 Reasoning

Implement a reasoning system that builds and traverses a graph of intermediate reasoning steps, enabling complex multi-hop problem solving with backtracking and hypothesis exploration.

## The Problem

Standard chain-of-thought (CoT) reasoning follows a single linear path:

```
Query → Step 1 → Step 2 → Step 3 → Answer
```

But complex problems require:
- **Exploring multiple hypotheses** (branching)
- **Recovering from errors** (backtracking)
- **Combining partial solutions** (convergence)
- **Verifying each step** (validation)

## Your Task

Implement a `GraphReasoner` class that performs graph-based reasoning:

## Algorithm Details

### Query Decomposition

```python
def decompose_query(self, query: str) -> list[str]:
    """Break complex query into manageable sub-questions."""
    prompt = f"""Decompose this complex query into 2-4 sub-questions 
    that need to be answered to solve the main problem.
    
    Query: {query}
    
    Output as JSON list of sub-questions."""
    
    response = self.llm.generate(prompt)
    sub_questions = json.loads(response)
    return sub_questions
```

### Graph Construction

```python
def build_reasoning_graph(self, query: str) -> dict:
    """Build graph by iteratively expanding nodes."""
    # Initialize with query node
    graph = {
        "nodes": [{"id": "root", "content": query, "type": "question"}],
        "edges": []
    }
    
    # Decompose into sub-questions
    sub_questions = self.decompose_query(query)
    
    for i, sq in enumerate(sub_questions):
        node_id = f"q_{i}"
        graph["nodes"].append({
            "id": node_id,
            "content": sq,
            "type": "question"
        })
        graph["edges"].append({
            "source": "root",
            "target": node_id,
            "relation": "decomposes_to"
        })
        
        # Retrieve evidence for each sub-question
        evidence = self.retriever.retrieve(sq, k=3)
        for j, doc in enumerate(evidence):
            ev_id = f"e_{i}_{j}"
            graph["nodes"].append({
                "id": ev_id,
                "content": doc,
                "type": "evidence"
            })
            graph["edges"].append({
                "source": node_id,
                "target": ev_id,
                "relation": "supported_by"
            })
    
    return graph
```

### Best-First Graph Traversal

```python
def traverse_best_first(self, graph: dict, query: str) -> list:
    """Use best-first search to find optimal reasoning path."""
    import heapq
    
    # Priority queue: (negative_score, node_id, path)
    pq = [(0, "root", ["root"])]
    visited = set()
    best_path = None
    best_score = float('-inf')
    
    while pq:
        score, node_id, path = heapq.heappop(pq)
        score = -score  # Negated for min-heap
        
        if node_id in visited:
            continue
        visited.add(node_id)
        
        node = self.get_node(graph, node_id)
        
        # Score this node
        node_score = self.score_node(node, query)
        total_score = score + node_score
        
        # Check if this is an answer node
        if node["type"] == "conclusion":
            if total_score > best_score:
                best_score = total_score
                best_path = path
            continue
        
        # Add neighbors to queue
        for edge in graph["edges"]:
            if edge["source"] == node_id:
                neighbor_id = edge["target"]
                if neighbor_id not in visited:
                    new_path = path + [neighbor_id]
                    heapq.heappush(pq, (-total_score, neighbor_id, new_path))
    
    return best_path
```

### Verification at Each Step

```python
def verify_step(self, step: dict, context: list[str]) -> dict:

    prompt = f"""Verify this reasoning step. Is the conclusion

    Evidence: {context}

    {{
        "valid": bool,
        "confidence": float (0-1),
        "issues": list[str]
    }}"""
    
    response = self.llm.generate(prompt)
```

## Reasoning Graph Structure

```
                    [Query Node]
                         |
        +----------------+----------------+
        |                |                |
   [Sub-Q 1]       [Sub-Q 2]        [Sub-Q 3]
        |                |                |
   +----+----+      +----+----+      +----+----+
   |         |      |         |      |         |
[Ev 1.1] [Ev 1.2] [Ev 2.1] [Ev 2.2] [Ev 3.1] [Ev 3.2]
   |         |      |         |      |         |
   +----+----+      +----+----+      +----+----+
        |                |                |
   [Conclusion 1]   [Conclusion 2]   [Conclusion 3]
        |                |                |
        +----------------+----------------+
                         |
                   [Final Answer]
```

## Evaluation Criteria

Your implementation will be tested on:

1. **Correctness**: Reaches correct conclusions
2. **Completeness**: Explores relevant reasoning paths
3. **Efficiency**: Prunes low-value branches
4. **Verifiability**: Each step can be validated

## Complexity Analysis

| Aspect | Complexity | Notes |
|--------|-----------|-------|
| Graph Construction | O(k × r × d) | k=sub-questions, r=retrievals, d=docs |
| Traversal | O(b^d) | b=branching factor, d=depth |
| Verification | O(n × c) | n=nodes, c=cost per verification |
| Total | O(b^d + n × c) | Dominated by graph exploration |

## Comparison: Linear CoT vs Graph-O1

| Feature | Linear CoT | Graph-O1 |
|---------|-----------|----------|
| Branching | ❌ No | ✅ Yes |
| Backtracking | ❌ No | ✅ Yes |
| Convergence | ❌ No | ✅ Yes |
| Verification | ⚠️ Limited | ✅ Per-node |
| Latency | ⚡ Fast | 🐢 Slower |
| Cost | 💰 Low | 💰💰 Higher |

## Production Considerations

1. **Beam width**: Limit concurrent branches to control cost
2. **Early stopping**: Stop when confidence threshold reached
3. **Caching**: Cache reasoning graphs for similar queries
4. **Human review**: Flag low-confidence paths for review
