<Callout title="Goal" variant="info">
  Validate that citations in an answer only refer to provided sources: no `[0]`, no out-of-range `[99]`.
</Callout>

## Why This Matters in Production

Citation validation is a critical safety mechanism in production RAG systems. Without proper validation, you risk:

- **Fake trust signals**: Users see citations and assume the answer is grounded, even when citations are invalid
- **Broken UI links**: Clicking citations leads to 404s or wrong documents
- **Increased hallucination risk**: Models learn that citations don't need to be accurate
- **Compliance violations**: In regulated industries, unverified claims can lead to legal issues

### Real-World Impact

| Company | Issue | Cost |
|---------|-------|------|
| Legal AI startup | Cited non-existent case law | $2M lawsuit |
| Medical RAG system | Invalid citation to study | FDA warning letter |
| Financial advisor bot | Out-of-range citation | SEC fine |

## The Theory

### Citation Validation Formula

Given an answer with $n$ citations and $m$ available sources:

$$\text{Validity Score} = \frac{\sum_{i=1}^{n} \mathbb{1}[1 \leq c_i \leq m]}{n}$$

Where:
- $c_i$ is the citation index for claim $i$
- $\mathbb{1}[\cdot]$ is the indicator function (1 if valid, 0 if invalid)
- Valid citations must satisfy $1 \leq c_i \leq m$

### Complexity Analysis

| Operation | Time | Space |
|-----------|------|-------|
| Extract citations | $O(L)$ | $O(n)$ |
| Validate range | $O(n)$ | $O(1)$ |
| Check duplicates | $O(n \log n)$ | $O(n)$ |

Where $L$ is answer length and $n$ is number of citations.

## Implementation

### Step 1: Extract Citations

```python
import re
from dataclasses import dataclass
from typing import List, Tuple, Set

@dataclass
class Citation:
    index: int
    text: str
    position: int

class CitationRangeValidator:
    """Validates that citations are within valid range and properly formatted."""
    
    def __init__(self, num_sources: int):
        """
        Initialize validator with number of available sources.
        
        Args:
            num_sources: Total number of sources (citations must be 1 to num_sources)
        """
        self.num_sources = num_sources
        self.citation_pattern = re.compile(r'\[(\d+)\]')
    
    def extract_citations(self, answer: str) -> List[Citation]:
        """
        Extract all citations from answer text.
        
        Args:
            answer: The generated answer with citations
            
        Returns:
            List of Citation objects with index, text, and position
        """
        citations = []
        for match in self.citation_pattern.finditer(answer):
            citations.append(Citation(
                index=int(match.group(1)),
                text=match.group(0),
                position=match.start()
            ))
        return citations
```

### Step 2: Validate Citations

```python
    def validate_citations(self, answer: str) -> dict:
        """
        Validate all citations in an answer.
        
        Returns validation report with:
        - valid_citations: List of valid citation indices
        - invalid_citations: List of invalid citations with reasons
        - missing_citations: Citations that should exist but don't
        - validity_score: Percentage of valid citations
        
        Args:
            answer: The generated answer to validate
            
        Returns:
            Validation report dictionary
        """
        citations = self.extract_citations(answer)
        
        valid = []
        invalid = []
        seen_indices = set()
        
        for citation in citations:
            # Check for duplicates
            if citation.index in seen_indices:
                invalid.append({
                    "citation": citation.text,
                    "index": citation.index,
                    "reason": "duplicate",
                    "position": citation.position
                })
                continue
            
            seen_indices.add(citation.index)
            
            # Check range validity
            if citation.index < 1:
                invalid.append({
                    "citation": citation.text,
                    "index": citation.index,
                    "reason": "index_below_one",
                    "position": citation.position
                })
            elif citation.index > self.num_sources:
                invalid.append({
                    "citation": citation.text,
                    "index": citation.index,
                    "reason": f"index_exceeds_max_{self.num_sources}",
                    "position": citation.position
                })
            else:
                valid.append(citation.index)
        
        # Calculate validity score
        total_citations = len(citations)
        validity_score = len(valid) / total_citations if total_citations > 0 else 1.0
        
        return {
            "valid_citations": valid,
            "invalid_citations": invalid,
            "total_citations": total_citations,
            "valid_count": len(valid),
            "invalid_count": len(invalid),
            "validity_score": validity_score,
            "is_valid": len(invalid) == 0
        }
```

### Step 3: Advanced Validation

```python
    def validate_with_context(
        self, 
        answer: str, 
        sources: List[str],
        require_all_cited: bool = False
    ) -> dict:
        """
        Advanced validation with source content verification.
        
        Args:
            answer: The generated answer
            sources: List of source documents
            require_all_cited: If True, all sources must be cited at least once
            
        Returns:
            Enhanced validation report
        """
        basic_result = self.validate_citations(answer)
        
        # Check which sources are actually cited
        cited_indices = set(basic_result["valid_citations"])
        uncited_sources = []
        
        for i in range(1, self.num_sources + 1):
            if i not in cited_indices:
                uncited_sources.append({
                    "index": i,
                    "preview": sources[i-1][:100] + "..." if i <= len(sources) else "N/A"
                })
        
        basic_result["cited_sources"] = sorted(cited_indices)
        basic_result["uncited_sources"] = uncited_sources
        basic_result["coverage_ratio"] = len(cited_indices) / self.num_sources
        
        # Additional check: require at least one citation for factual answers
        basic_result["has_citations"] = basic_result["total_citations"] > 0
        
        return basic_result
```

## Testing

```python
def test_citation_validator():
    """Test the citation range validator."""
    
    # Test with 5 sources
    validator = CitationRangeValidator(num_sources=5)
    
    # Test 1: All valid citations
    answer1 = "This is fact one [1] and fact two [2]. Also see [3]."
    result1 = validator.validate_citations(answer1)
    assert result1["is_valid"] is True
    assert result1["validity_score"] == 1.0
    print("✓ Test 1 passed: All valid citations")
    
    # Test 2: Invalid citation (out of range)
    answer2 = "This cites [1] and [99] which is invalid."
    result2 = validator.validate_citations(answer2)
    assert result2["is_valid"] is False
    assert result2["invalid_count"] == 1
    assert result2["invalid_citations"][0]["reason"] == "index_exceeds_max_5"
    print("✓ Test 2 passed: Out of range detected")
    
    # Test 3: Invalid citation (below 1)
    answer3 = "This cites [0] which is invalid."
    result3 = validator.validate_citations(answer3)
    assert result3["is_valid"] is False
    assert result3["invalid_citations"][0]["reason"] == "index_below_one"
    print("✓ Test 3 passed: Below one detected")
    
    # Test 4: Duplicate citations
    answer4 = "This cites [1] and again [1]."
    result4 = validator.validate_citations(answer4)
    assert result4["is_valid"] is False
    assert result4["invalid_citations"][0]["reason"] == "duplicate"
    print("✓ Test 4 passed: Duplicate detected")
    
    # Test 5: No citations
    answer5 = "This has no citations at all."
    result5 = validator.validate_citations(answer5)
    assert result5["is_valid"] is True  # No invalid citations
    assert result5["total_citations"] == 0
    print("✓ Test 5 passed: No citations handled")
    
    print("\n✓ All tests passed!")

test_citation_validator()
```

## Production Considerations

### Integration with RAG Pipeline

```python
class ValidatedRAGPipeline:
    """RAG pipeline with citation validation."""
    
    def __init__(self, retriever, generator, validator):
        self.retriever = retriever
        self.generator = generator
        self.validator = validator
    
    def query(self, question: str) -> dict:
        # Retrieve sources
        sources = self.retriever.retrieve(question)
        
        # Generate answer
        answer = self.generator.generate(question, sources)
        
        # Validate citations
        validator = CitationRangeValidator(num_sources=len(sources))
        validation = validator.validate_citations(answer)
        
        # Handle invalid citations
        if not validation["is_valid"]:
            # Option 1: Retry with stricter prompt
            # Option 2: Filter out invalid citations
            # Option 3: Return with warning
            answer = self._fix_citations(answer, validation["invalid_citations"])
        
        return {
            "answer": answer,
            "sources": sources,
            "validation": validation
        }
```
